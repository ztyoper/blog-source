# 3、远程调用

## 1.RPC（<span style="color: rgb(18, 18, 18)">Remote Procedure Call</span>）：远程过程调用

![image.png](https://pub-ccd5622eabb54b4a81678003778ddce1.r2.dev/PicGo/f48a2aead2a74d96f4cb4c72ab2ce15c73549950ac90e26a946b3e7b370a7c63.png)

**本地过程调用**： a()； b()； a() { b()；}： 不同方法都在**同一个JVM运行**

**远程过程调用**：

- 需要服务提供者
- 需要服务消费者
- 通过连接对方服务器进行请求\响应交互，来实现调用效果

API/SDK的区别是什么？

- api：接口（ Application Programming Interface ）

- 大多时候是远程提供功能；

- sdk：工具包（ Software Development Kit ）

- 导入jar包，直接调用功能即可

### 2.3.WeatherController

```java
@RestController
public class WeatherController {
    @Autowired
    WeatherService weatherService;

    @GetMapping("/weather")
    public Mono<String> weather(@RequestParam("city") String city){
        //查询天气
        Mono<String> weather = weatherService.weather(city);
        return weather;
    }
    //这里也可以用/weather/{city}和@PathVariable("city")
}
```

### 2.4.WeatherService

```java
@Service
public class WeatherService {

    private Mono<String> weather(String city) {
        //1、创建WebClient（HTTP客户端或者叫web客户端）
        //这种是直接写死url,如果是GET请求要在url中添加参数，则直接定义第二种空参创建方式。
//       WebClient client = WebClient.create("https://ali-weather.showapi.com/area-to-weather-date");
        WebClient client = WebClient.create();

        //2、准备数据（Map的params是给".uri"里面赋值参数使用）
        Map<String,String> params = new HashMap<>();
        params.put("area", city);
        //3、定义发请求行为  CompletableFuture
        Mono<String> mono = client.get()
                //定义url中的参数
                .uri("https://ali-weather.showapi.com/area-to-weather-date?area={area}", params)
                //定义响应的内容类型
                .accept(MediaType.APPLICATION_JSON)
                //设置请求头参数
                .header("Authorization", "APPCODE aa64f3a5570640959cc32a39ee5e7d05") //定义请求头
                //发送请求
                .retrieve()
                //将响应体中的内容以String类型赋值给Mono,Mono是响应web中的类型，Mono是发布者，谁想要该内容就将该内容发送给它。
                .bodyToMono(String.class);
        //.block() 这种手动让它阻塞的方式不适用了，只能异步
        return mono;
    }
}
```

## 3.HTTP Interface

> <span style="color: rgb(48, 54, 63)">Spring 允许我们通过定义接口的方式，给任意位置发送 http 请求，实现远程调用，可以用来简化 HTTP 远程访问。需要</span><span style="color: rgb(213, 97, 97)">webflux</span><span style="color: rgb(48, 54, 63)">场景才可</span>

### 3.1.导入依赖

```xml
<dependency>
  <groupId>org.springframework.boot</groupId>
  <artifactId>spring-boot-starter-webflux</artifactId>
</dependency>
```

### 3.2.WeatherController

> 该`Controller`除了处理`Weather`业务，这里面还添加了一个查询物流`Express`业务。

```java
@RestController
public class WeatherController {

    @Autowired
    WeatherInterface weatherInterface;

    @Autowired
    ExpressInterface expressInterface;

    @GetMapping("/weather")
    public Mono<String> weather(@RequestParam("city") String city){
        //查询天气
        Mono<String> weather = weatherService.weather(city);

        return weather;
    }

    @GetMapping("/express")
    public Mono<String> express(@RequestParam("number") String number){

        //获取物流
        return expressInterface.getExpress(number);
    }
}
```

### 3.3.Interface

> 定义WeatherInterface接口和ExpressInterface接口

```java
public interface WeatherInterface {
    @GetExchange(url = "https://ali-weather.showapi.com/area-to-weather-date",accept = "application/json")
    Mono<String> getWeather(@RequestParam("area") String city);
}
```

```java
public interface ExpressInterface {
    @GetExchange(url = "https://express3.market.alicloudapi.com/express3",accept = "application/json")
    Mono<String> getExpress(@RequestParam("number") String number);
}
```

> `@GetExchange`注解表示，当调用该接口的实现类时，例如`WeatherInterface`接口的实现类调用`getWeather("成都")`方法，"成都"就会作为请求参数拼接在`url`后面。
> 为什么没有拼接请求头`@RequestHeader("Authorization") APPCODE +code`:
> 1. 因为已经抽取出来了。看后面就知道了。

### 3.4.AliyunConfiguration

> 通过`AliyunConfiguration`配置类，注册`httpServiceProxyFactory`工厂，注册`WeatherInterface`和`ExpressInterface`的代理实现类。

```java
@Configuration //最好起名为 AliyunApiConfiguration
public class AliyunApiConfiguration {
	//注册httpServiceProxyFactory工厂
    @Bean
    HttpServiceProxyFactory httpServiceProxyFactory(@Value("${aliyun.appcode}") String appCode){
        //1、创建客户端
        WebClient client = WebClient.builder()
                //抽取请求头@RequestHeader("Authorization") APPCODE +code作为默认的请求头
                //appCode直接在配置文件中设置。
                .defaultHeader("Authorization","APPCODE "+appCode)
                .codecs(clientCodecConfigurer -> {
                    clientCodecConfigurer
                            .defaultCodecs()
                            .maxInMemorySize(256*1024*1024);
                    //响应数据量太大有可能会超出BufferSize，所以这里设置的大一点//这个保持默认就行，视频没介绍
                })
                .build();
        //2、创建工厂
        HttpServiceProxyFactory factory = HttpServiceProxyFactory
                .builder(WebClientAdapter.forClient(client)).build();
        return factory;
    }
	//注册WeatherInterface的代理实现类。
    @Bean
    WeatherInterface weatherInterface(HttpServiceProxyFactory httpServiceProxyFactory){
        //3、获取代理对象
        WeatherInterface weatherInterface = httpServiceProxyFactory.createClient(WeatherInterface.class);
        return weatherInterface;
    }
    //注册ExpressInterface的代理实现类。
    @Bean
    ExpressInterface expressInterface(HttpServiceProxyFactory httpServiceProxyFactory){
        ExpressInterface client = httpServiceProxyFactory.createClient(ExpressInterface.class);
        return client;
    }
}
```

> 这样就可以在需要`WeatherInterface`和`ExpressInterface`这两个接口的地方，使用`@Autowire`自动注入然后调用接口方法即可。而且是响应式异步的喔。吞吐量可以很大。
