### **四、编码实现**

具体实现步骤如下所示。

**（1）修改ChatBox.vue**

ChatBox.vue是聊天页面的核心，主要是在ChatBox.vue中添加在输入框中输入@符号的核心逻辑。源码详见：src/components/chat/ChatBox.vue。

```go
onEditorInput(e) {
    // 如果触发 @
    if (this.chat.type == "GROUP" && !this.zhLock) {
        if (e.data == '@') {
            // 打开选择弹窗
            this.showAtBox(e);
        } else {
            let selection = window.getSelection()
            let range = selection.getRangeAt(0)
            this.focusNode = selection.focusNode;
            // 截取@后面的名称作为过滤条件
            let stIdx = this.focusNode.textContent.lastIndexOf('@');
            this.atSearchText = this.focusNode.textContent.substring(stIdx + 1);
        }
    }
},
```

**（2）修改ChatItem.vue**

ChatItem.vue是聊天会话的条目样式，主要是在ChatItem.vue中添加[有人@我]和[@全体成员]的样式。源码详见：src/components/chat/ChatItem.vue。

```go
computed: {
    showTime() {
        return this.$date.toTimeText(this.chat.lastSendTime, true)
    },
    atText() {
        if (this.chat.atMe) {
            return "[有人@我]"
        } else if (this.chat.atAll) {
            return "[@全体成员]"
        }
        return "";
    }
}
```
