用户需要注册一个账号并且登录分布式IM即时通讯系统后，才能体验分布式IM即时通讯系统的功能。所以，在开发分布式IM即时通讯系统的大前端UI页面时，第一步就是要设计和实现注册登录的流程。

### **一、前言**

在前面的文章中，我们已经搭建了研发大前端UI的基础环境，并且搭建了项目工程，也对通用的基础功能进行了设计和实现，为开发大前端UI页面做好了准备。接下来，我们就从最简单的注册登录功能开始设计和研发。

### **二、本节诉求**

对于大前端UI的注册与登录流程进行设计和实现，设计并开发注册登录的前端页面，并能够正常调用后端接口完成数据的交互过程，掌握VUE调用后端接口的方式方法，并能够将其灵活应用到自身实际项目中。

### **三、前端UI设计**

对于注册和登录页面来说，我们也是保留了最基础最核心的功能，没有太多冗余复杂的功能。我们希望打开页面链接时，如果没有登录系统，首先出现的是登录页面，输入账号和密码就可以登录系统。如果此时没有账号的话，就可以点击“没有账号，前往注册”跳转到注册页面来注册账号，从注册页面也可以点击“已有账号，前往登录”跳转到登录页面。

#### **3.1 登录页面的设计**

对于登录页面来说，我们简化了复杂冗余的登录流程，只需要输入用户名和密码，点击登录按钮即可登录系统，并且如果此时用户没有账号的话，可以点击“没有账号，前往注册”跳转到注册页面来注册自己的账号，登录页面的设计如图3-1所示。

![](https://pub-ccd5622eabb54b4a81678003778ddce1.r2.dev/PicGo/e0f80529731dbb3383f27d632ec5ebf4b91c9dc9e23ba9f45c2d2472e691c828.png)

#### **3.2 注册页面的设计**

对于注册页面来说，我们同样简化了复杂冗余的注册流程，只需要输入用户名、昵称、密码和确认密码，点击注册按钮即可注册账号，如果此时已有登录账号的话，可以点击“已有账号，前往登录”跳转到登录页面。注册页面的整体设计如图3-2所示。

![](https://pub-ccd5622eabb54b4a81678003778ddce1.r2.dev/PicGo/1c1488fe4601211bb901d2c7cddc260b474585c1b24103b5671b9b83eec2db0a.png)

#### **4.3 配置导出路由**

完成注册和登录页面的开发后，需要将注册和登录的页面配置导出路由，此时需要修改src/router目录下的index.js文件，在index.js文件中导入注册和登录的vue文件，并在将其导出到路由表中。具体代码如下所示。

```go
import Vue from 'vue'
import VueRouter from 'vue-router'
import Login from '../view/Login'
import Register from '../view/Register'
// 安装路由
Vue.use(VueRouter);
​
// 配置导出路由
export default new VueRouter({
 routes: [{
   path: "/",
   redirect: "/login"
   },
   {
   name: "Login",
   path: '/login',
   component: Login
   },
   {
   name: "Register",
   path: '/register',
   component: Register
   }
  ]
});
```

配置导出路由的核心源码如下所示。


可以看到，在分布式IM即时通讯系统的前端页面中，将登录页面设置成了打开链接的默认页面。

### **五、启动运行项目**

为了更好的演示项目，这里，我们启动大后端平台的用户微服务和前端页面来验证用户的登录和注册功能。

#### **5.1 启动用户微服务**

在启动用户微服务之前，需要安装好MySQL数据库，导入数据库sql文件，启动Nacos、启动Redis以及启动RocketMQ，随后启动用户微服务。

这里，大家可以参见《[分布式IM即时通讯系统](https://articles.zsxq.com/id_i652r0adp3gu.html)》前面的文章和视频启动相关的中间件和微服务即可。

#### **5.2 启动前端页面**

打开系统命令行终端，将命令行终端所在的目录切换到bh-im-front项目所在的目录，依次输入如下命令启动vue项目。

```go
npm install
npm run serve
```

项目启动成功，会输出类似如下的信息。

```go
App running at:
- Local: http://localhost:8080/
- Network: http://192.168.1.3:8080/
```

如图3-3所示。
