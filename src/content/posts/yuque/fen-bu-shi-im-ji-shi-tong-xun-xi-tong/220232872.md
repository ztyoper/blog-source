### **四、编码实现**

这里，我们使用WebRTC实现视频通话，具体实现步骤如下所示。

**（1）新增WebrtcService接口**

WebrtcService接口是基于WebRTC实现视频通话的接口，在WebrtcService接口中定义了视频呼叫的方法。

源码详见：bh-im-platform-message-application工程下的io.binghe.im.platform.message.application.service.WebrtcService。

```go
public interface WebrtcService {
  void call(Long uid, String offer);
}
```

**（2）新增WebrtcServiceImpl类**

WebrtcServiceImpl类是基于WebRTC实现视频通话的实现类，WebrtcServiceImpl类实现了WebrtcService接口，并实现了WebrtcService接口中的方法。

源码详见：bh-im-platform-message-application工程下的io.binghe.im.platform.message.application.service.impl.WebrtcServiceImpl。

```go
@Service
public class WebrtcServiceImpl implements WebrtcService {
  @Autowired
  private IMClient imClient;
  @Autowired
  private DistributedCacheService distributedCacheService;
  @Autowired
  private ICEServerConfig iceServerConfig;
​
  @Override
  public void call(Long uid, String offer) {
    UserSession session = SessionContext.getSession();
    if (!imClient.isOnline(uid)) {
      throw new IMException("对方目前不在线");
     }
    // 创建webrtc会话
    WebrtcSession webrtcSession = new WebrtcSession();
    webrtcSession.setCallerId(session.getUserId());
    webrtcSession.setCallerTerminal(session.getTerminal());
    String key = getSessionKey(session.getUserId(), uid);
    distributedCacheService.set(key, webrtcSession, IMPlatformConstants.WEBRTC_SESSION_CACHE_EXPIRE, TimeUnit.HOURS);
    // 向对方所有终端发起呼叫
    PrivateMessageVO messageInfo = new PrivateMessageVO();
    messageInfo.setType(MessageType.RTC_CALL.code());
    messageInfo.setRecvId(uid);
    messageInfo.setSendId(session.getUserId());
    messageInfo.setContent(offer);
​
    IMPrivateMessage<PrivateMessageVO> sendMessage = new IMPrivateMessage<>();
    sendMessage.setSender(new IMUserInfo(session.getUserId(),session.getTerminal()));
    sendMessage.setReceiveId(uid);
    sendMessage.setSendToSelf(false);
    sendMessage.setSendResult(false);
    sendMessage.setData(messageInfo);
    imClient.sendPrivateMessage(sendMessage);
   }
​
  private String getSessionKey(Long id1, Long id2) {
    Long minId = id1 > id2 ? id2 : id1;
    Long maxId = id1 > id2 ? id1 : id2;
    return String.join(IMConstants.REDIS_KEY_SPLIT, IMConstants.IM_WEBRTC_SESSION, minId.toString(), maxId.toString());
   }
}
```

可以看到，视频呼叫的核心逻辑实现还是比较简单的。

**（3）新增WebrtcController类**

WebrtcController类是视频消息对外提供的接口类，主要新增呼叫视频通话的接口。

源码详见：bh-im-platform-message-interfaces工程下的io.binghe.im.platform.message.controller.WebrtcController。

```go
@Api(tags = "webrtc视频通话")
@RestController
@RequestMapping("/webrtc/private")
public class WebrtcController {
​
  @Autowired
  private WebrtcService webrtcService;
​
  @ApiOperation(httpMethod = "POST", value = "呼叫视频通话")
  @PostMapping("/call")
  public ResponseMessage<String> call(@RequestParam Long uid, @RequestBody String offer) {
    webrtcService.call(uid,offer);
    return ResponseMessageFactory.getSuccessResponseMessage();
   }
}
```
