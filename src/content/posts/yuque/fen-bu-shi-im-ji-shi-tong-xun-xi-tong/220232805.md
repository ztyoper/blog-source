### **一、前言**

对于分布式IM即时通讯系统来说，在设计上支持的消息类型涵盖：**文字、图片、文件、语音、视频**，也就是说，在我们实现的分布式IM即时通讯系统中，可以**发送文字、图片、文件、语音、视频**。目前，我们已经实现了文字消息的发送、拉取、未读、已读和撤回功能。那图片、文件、语音、视频类型的消息如何处理呢？

### **二、功能描述**

文字消息比较简单，目前我们已经在分布式IM即时通讯系统中实现了文字消息的流转过程，也就是说，你可以在分布式IM即时通讯系统中顺畅的发送和撤回文字消息了。

对与其他类型的消息来说，我们可以将图片、文件、语音归为一类，这类消息在实现时，我们可以将图片、文件、语音上传到Minio文件系统，随后图片、文件和语音的链接随消息进行流转，当用户收到图片、文件和语音类型的消息时，从Minio文件系统中拉取消息即可。

而视频类型的消息，则需要通过实时推送和接收视频流来实现。

### **四、编码实现**

具体实现步骤如下所示。

**（1）新增MinioService接口**

MinioService接口是上传文件到Minio系统的接口，在MinioService接口中定义了查看存储bucket是否存在、创建存储bucket、设置bucket权限为public和上传文件的方法。

源码详见：bh-im-platform-message-application工程下的io.binghe.im.platform.message.application.minio.MinioService。

```go
public interface MinioService {
  Boolean bucketExists(String bucketName);
  void makeBucket(String bucketName);
  void setBucketPublic(String bucketName);
  String upload(String bucketName, String path, MultipartFile file);
  String upload(String bucketName,String path,String name,byte[] fileByte,String contentType);
  boolean remove(String bucketName,String path,String fileName);
}
```

**（2）新增MinioServiceImpl类**

MinioServiceImpl类是上传文件到Minio接口的实现类，主要实现了MinioService接口，并实现了MinioService接口中定义的查看存储bucket是否存在、创建存储bucket、设置bucket权限为public和上传文件的方法。

源码详见：bh-im-platform-message-application工程下的io.binghe.im.platform.message.application.minio.impl.MinioServiceImpl。

**注意：这里不再粘贴MinioServiceImpl类的源码，大家到本节对应的源码分支进行查看即可。**

**（3）新增FileService接口**

FileService接口是业务层面上传文件的接口，在FileService接口中定义了上传图片的方法。

源码详见：bh-im-platform-message-application工程下的io.binghe.im.platform.message.application.service.FileService。

```go
public interface FileService {
  String uploadFile(MultipartFile file);
  UploadImageVO uploadImage(MultipartFile file);
```

**（5）新增FileController类**

FileController类的功能比较简单，就是提供上传文件的接口。

```go
@RestController

  @Autowired

​
```
