### **四、编码实现**

本节的代码实现比较简单，主要是在Group.vue中添加退出群组的页面展示和JS代码，源码详见：src/view/Group.vue。具体步骤如下所示。

**（1）添加退出群组的页面展示**

```go
 <el-button type="danger" v-show="!isOwner" @click="onQuit()">退出群聊</el-button>
```

可以看到，不是群主，只是普通群成员时，才会显示退出群聊按钮。

**（2）添加退出群组的JS代码**

```go
onQuit() {
 this.$confirm('退出群聊后将不再接受群里的消息，确认退出吗？', '确认退出?', {
    confirmButtonText: '确定',
    cancelButtonText: '取消',
    type: 'warning'
  }).then(() => {
    this.$http({
     url: `/group-server/group/quit/${this.activeGroup.id}`,
     method: 'delete'
    }).then(() => {
     this.$store.commit("removeGroup", this.activeGroup.id);
     this.$store.commit("removeGroupChat", this.activeGroup.id);
     this.$message.success('已成功退出群聊');
     this.reset();
    });
  })
}
```

**注意：这里只给出了最核心的源码实现，其他细节部分，大家自行查看本节对应的源码分支，这里不再赘述。**
