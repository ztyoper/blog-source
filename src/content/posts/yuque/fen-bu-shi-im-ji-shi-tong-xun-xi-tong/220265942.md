### **四、编码实现**

整体编码过程也比较简单，这里我们分别从创建群组和展示群组两个方面进行编码实现。

#### **4.1 创建群组**

主要是在Group.vue中添加创建群组的按钮逻辑与绑定关系。源码详见：src/view/Group.vue。

```go
<el-button plain icon="el-icon-plus" style="border: none; padding: 12px; font-size: 20px;color: black;" title="创建群聊" @click="onCreateGroup()"></el-button>
```

其中，创建群组的js方法如下所示。

```go
methods: {
 onCreateGroup() {
    this.$prompt('请输入群聊名称', '创建群聊', {
     confirmButtonText: '确定',
     cancelButtonText: '取消',
     inputPattern: /\S/,
     inputErrorMessage: '请输入群聊名称'
    }).then((o) => {
     let userInfo = this.$store.state.userStore.userInfo;
     let data = {
        name: o.value,
        remark: o.value,
        aliasName: userInfo.name,
        ownerId: userInfo.id
      }
     this.$http({
        url: `/group-server/group/create?groupName=${o.value}`,
        method: 'post',
        data: data
      }).then((group) => {
        this.$store.commit("addGroup", group);
      })
    })
  }
```
