### **三、规则链设计**

在分布式IM即时通讯系统的大后端平台中，我们基于责任链模式实现了多重拦截校验规则，预留了大量扩展点。在设计和研发秒杀系统的过程中，也跟大家说过，一上来就设计和实现一个非常完善的系统是不可能的。

在设计和实现拦截校验规则时，我们要做到高度可扩展、可编排和可配置，随时可以扩展其他的校验规则，也能够随时对这些校验规则进行编排，同时，能够随时配置校验的具体规则。

大后端平台的拦截器规则链的执行流程如图4-1所示。

![](https://pub-ccd5622eabb54b4a81678003778ddce1.r2.dev/PicGo/89ee24b8164396082295ba8132b7fb051f9e28c0a59e76d9543c367a0fdc833f.png)

可以看到，客户端访问目标资源时，拦截器会拦截客户端发出的请求，在拦截器中，会提供统一的规则接口，规则接口下会有多个规则实现类，当请求到达拦截器时，会依次调用各个规则实现类组成的规则链，只有规则链中各个具体的规则校验都通过后，请求才会发往目标资源。只要有一个具体的规则校验不通过，则请求不再向后发送，直接返回具体的状态码。

### **五、编码实现**

具体的实现步骤如下所示。

**（1）实现RuleChainService接口**

RuleChainService接口是规则链服务接口，提供具体的规则校验方法和具体规则的排序方法。

源码详见：io.binghe.im.platform.common.risk.rule.service.RuleChainService。

```java
public interface RuleChainService {
    HttpCode execute(HttpServletRequest request, Object handler);
    int getOrder();
}
```

**（2）实现BaseRuleChainService类**

BaseRuleChainService类是规则链服务的基础抽象类，实现了RuleChainService接口。

源码详见：io.binghe.im.platform.common.risk.rule.service.base.BaseRuleChainService。

```java
public abstract class BaseRuleChainService {

    private final Logger logger = LoggerFactory.getLogger(BaseRuleChainService.class);
    ​
    public BaseRuleChainService(){
        logger.info("IMBaseRuleChainService|当前规则服务|{}", this.getServiceName());

    ​
    protected String getIp(ServerHttpRequest request){
        HttpHeaders headers = request.getHeaders();
        String ip = headers.getFirst("x-forwarded-for");
        if (ip != null && ip.length() != 0 && !"unknown".equalsIgnoreCase(ip)) {
            // 多次反向代理后会有多个ip值，第一个ip才是真实ip
            if (ip.indexOf(",") != -1) {
                ip = ip.split(",")[0];
            }
        }
        if (ip == null || ip.length() == 0 || "unknown".equalsIgnoreCase(ip)) {
            ip = headers.getFirst("Proxy-Client-IP");
        }
        if (ip == null || ip.length() == 0 || "unknown".equalsIgnoreCase(ip)) {
            ip = headers.getFirst("WL-Proxy-Client-IP");
        }
        if (ip == null || ip.length() == 0 || "unknown".equalsIgnoreCase(ip)) {
            ip = headers.getFirst("HTTP_CLIENT_IP");
        }
        if (ip == null || ip.length() == 0 || "unknown".equalsIgnoreCase(ip)) {
            ip = headers.getFirst("HTTP_X_FORWARDED_FOR");
        }
        if (ip == null || ip.length() == 0 || "unknown".equalsIgnoreCase(ip)) {
            ip = headers.getFirst("X-Real-IP");
        }
        if (ip == null || ip.length() == 0 || "unknown".equalsIgnoreCase(ip)) {
            ip = request.getRemoteAddress().getAddress().getHostAddress();
        }
```

**（3）实现BaseInterceptor类**

BaseInterceptor类是基础的拦截器抽象类，实现了Spring中的HandlerInterceptor拦截器接口。

源码详见：io.binghe.im.platform.common.interceptor.base.BaseInterceptor。

```java
public abstract class BaseInterceptor implements HandlerInterceptor {
    @Autowired
    private List<RuleChainService> ruleChainServices;
    ​
    protected List<RuleChainService> getRuleChainServices(){
        if (CollectionUtil.isEmpty(ruleChainServices)){
            return Collections.emptyList();
        }
        return ruleChainServices.stream().sorted(Comparator.comparing(RuleChainService::getOrder)).collect(Collectors.toList());
    }
}
```

**（4）实现IMInterceptor类**

IMInterceptor类是通用的拦截器实现类，继承自BaseInterceptor类。在IMInterceptor类中会获取到编排好的规则服务链，并循环调用规则服务链中的每个规则服务的execute()方法来校验规则。

源码详见：io.binghe.im.platform.common.interceptor.IMInterceptor。

```java
@Component
public class IMInterceptor extends BaseInterceptor {
    @Override
    public boolean preHandle(HttpServletRequest request, HttpServletResponse response, Object handler) throws Exception {
        //获取排好序的规则链
        List<RuleChainService> ruleChainServices = this.getRuleChainServices();
        //遍历规则链
        for (RuleChainService ruleChainService : ruleChainServices){
            HttpCode httpCode = ruleChainService.execute(request, handler);
            if (!HttpCode.SUCCESS.getCode().equals(httpCode.getCode())){
                throw new IMException(httpCode);
            }
        }
        return true;
    }
}
```

### **六、使用规则**

通用的拦截器规则服务链已经设计和实现完毕，那在具体项目中要如何使用呢？

使用方式也比较简单，实现一个Spring的配置类，并实现WebMvcConfigurer接口，通过@Autowired注解注入IMInterceptor类型的对象imInterceptor，并在实现的addInterceptors()方法中将imInterceptor对象添加到拦截器链中即可。

例如，如下代码片段所示。

```java
@Configuration
public class MvcConfig implements WebMvcConfigurer {
    @Autowired
    private IMInterceptor imInterceptor;
    @Override
    public void addInterceptors(InterceptorRegistry registry) {
        registry.addInterceptor(imInterceptor)
        .addPathPatterns("/**");
    }
}
```
