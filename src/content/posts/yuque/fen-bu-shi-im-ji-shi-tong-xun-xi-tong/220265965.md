### **四、编码实现**

本节的代码实现比较简单，主要是在Group.vue中添加解散群组的页面展示和JS代码，源码详见：src/view/Group.vue。具体步骤如下所示。

**（1）添加解散群组的页面展示**

```go
<el-button type="danger" v-show="isOwner" @click="onDissolve()">解散群聊</el-button>
```

**（2）添加解散群聊的JS代码**

```go
onDissolve() {
 this.$confirm('确认要解散群聊吗?', '确认解散?', {
    confirmButtonText: '确定',
    cancelButtonText: '取消',
    type: 'warning'
  }).then(() => {
    this.$http({
     url: `/group-server/group/delete/${this.activeGroup.id}`,
     method: 'delete'
    }).then(() => {
     this.$message.success(`群聊'${this.activeGroup.name}'已解散`);
     this.$store.commit("removeGroup", this.activeGroup.id);
     this.$store.commit("removeGroupChat", this.activeGroup.id);
     this.reset();
    });
  })
}
```

**注意：这里只给出了最核心的源码实现，其他细节部分，大家自行查看本节对应的源码分支，这里不再赘述。**
