### **四、基础功能开发**

在正式开发大前端UI的业务功能之前，我们先对前端的通用基础功能进行设计和研发，具体实现步骤如下所示。

**（1）配置vue.config.js**

vue.config.js文件位于项目的根本目录下，具体代码如下所示。

```go
module.exports = {
 devServer: {
  proxy: {
   '/api': {
    target: 'http://127.0.0.1:10010',
    changeOrigin: true,
    ws: false,
    pathRewrite: {
     '^/api': ''
     }
    }
   }
  }
}
```

**（2）配置访问环境**

项目根目录下新建.env.development文件和.env.production文件来标识项目的环境信息，.env.development文件是开发环境，.env.production文件是生产环境，文件的具体内容如下所示。

1. .env.development文件

```go
ENV = 'development'
# app名称
VUE_APP_NAME = "冰河IM"
# 接口请求地址
VUE_APP_BASE_API = '/api'
# ws地址
VUE_APP_WS_URL = 'ws://localhost:10011/im'
```

1. .env.production文件

```go
ENV = 'production'
# app名称
VUE_APP_NAME = "冰河IM"
# 接口地址
VUE_APP_BASE_API = 'https://binghe.net.cn/api'
# ws地址
VUE_APP_WS_URL = 'wss://binghe.net.cn:10011/im'
```
