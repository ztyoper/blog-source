### **四、编码实现**

本节总体编码实现比较简单，需要注意的点就是我们需要在分布式IM即时通讯系统中单独创建一个用户，其他用户加这个用户为好友，向这个指定的用户发送消息时，就触发接入OpenAI的流程。在分布式IM即时通讯系统中，指定的用户id为10000000001，用户名为binghe。

主要就是修改bh-im-platform-message-application工程下的IMPrivateMessageRocketMQEventConsumer类，在IMPrivateMessageRocketMQEventConsumer类中，主要是增加对接binghe用户的实现逻辑。也就是说，如果消息的接收者id为10000000001，用户名为binghe，则触发对接OpenAI的流程。

源码详见：bh-im-platform-message-application工程下的io.binghe.im.platform.message.application.consumer.IMPrivateMessageRocketMQEventConsumer。

具体实现步骤如下。

**（1）新增成员变量**

在IMPrivateMessageRocketMQEventConsumer类中，新增读取配置的成员变量和注入OpenAI加入服务的Dubbo接口对象，如下所示。

```go
@Value("${bh.im.openai.userid:10000000001}")
private Long openAiUserId;
​
@Value("${bh.im.openai.username:binghe}")
private String openAiUserName;
​
@DubboReference(version = IMPlatformConstants.DEFAULT_DUBBO_VERSION, check = false)
private OpenAIDubboService openAIDubboService;
```

**（2）整合对接OpenAI的流程**

在单聊消息中，消息接收者id为10000000001，用户名为binghe时，就会触发接入OpenAI的流程。在IMPrivateMessageRocketMQEventConsumer类中新增sendOpenAiMessage()方法，如下所示。

```go
private void sendOpenAiMessage(PrivateMessageVO privateMessageVO, Integer terminal){
    // 不是对接OpenAI的账号
    Long recvId = privateMessageVO.getRecvId();
    if (!IMPlatformConstants.OPENAI_USER_ID.equals(recvId)){
        return;
    }
    try {
        logger.info("发送OpenAI消息开始");
        String openAIMessage = openAIDubboService.sendMessage(privateMessageVO.getContent());
        privateMessageVO.setSendTime(new Date());
        privateMessageVO.setContent(openAIMessage);
        IMPrivateMessage<PrivateMessageVO> sendMessage = new IMPrivateMessage<>();
        sendMessage.setSender(new IMUserInfo(privateMessageVO.getRecvId(), terminal));
        sendMessage.setReceiveId(privateMessageVO.getSendId());
        sendMessage.setSendToSelf(true);
        sendMessage.setData(privateMessageVO);
        imClient.sendPrivateMessage(sendMessage);
        logger.info("发送OpenAI消息结束");
    } catch (IOException e) {
        logger.error("对接OpenAI大模型消息异常: ", e);
    }
}
```

在sendOpenAiMessage()方法中，首先判断消息接收者的id是否是指定的用户id，这里就是10000000001。如果不是10000000001，则直接返回，不再向下执行逻辑。否则，调用OpenAI接入服务的接口，调用OpenAI大模型返回结果后，将OpenAI大模型返回的结果数据推送出去。

**（3）调用新增方法**

最后，在IMPrivateMessageRocketMQEventConsumer类的onMessage()方法中，调用sendOpenAiMessage()方法，如下所示。

```go
@Override
public void onMessage(String message) {
    /************其他代码省略***********/
    // 发送大模型消息
    this.sendOpenAiMessage(privateMessageVO, imPrivateMessageTxEvent.getTerminal());
}
```

**（4）配置ChatGPT**

在bh-im-openai项目的bh-im-openai-starter工程下的application.yml配置文件中，配置自己调用ChatGPT的SecretKey，如下所示。

```go
bh-im-openai:
  type: chatgpt
  chatgpt:
    key: xxxxxxxx
    api: https://open.aiproxy.xyz/v1/completions #如果访问不通，使用备用地址：open.aiproxy.xyz、open2.aiproxy.xyz api.openai.com
```
