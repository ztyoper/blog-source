#### **3.2 Windows系统npm配置**

npm其实是nodejs的模块管理工具，我们可以先配置npm的全局模块存放路径和cache的存放路径。

**（1）新建目录**

在nodejs的安装目录下新建**node****_****cache**和**node****_****global**目录。

![](https://pub-ccd5622eabb54b4a81678003778ddce1.r2.dev/PicGo/054a8880de7607a5f4b437dd6fb974aa8bdeff0c32dc7b075cc77bc646dfdf3a.png)

**（2）命令行配置**

在命令行输入如下命令进行配置。

```go
npm config set prefix "D:\nodejs\18.19.0\node_global"
npm config set cache "D:\nodejs\18.19.0\node_cache"
```

![](https://pub-ccd5622eabb54b4a81678003778ddce1.r2.dev/PicGo/a54d15730124c9ac60063ae4872202c0a99eedc3a27c315723ae196b32147ab6.png)

随后，在命令行输入npm list -global命令即可查看到global目录的变化。

![](https://pub-ccd5622eabb54b4a81678003778ddce1.r2.dev/PicGo/59424a27607aa6b8a6ab90f65448af8016155fd434d265027247e8bd26ced44f.png)

**（3）配置环境变量**

进入环境变量对话框，新建NODE_PATH环境变量。

![](https://pub-ccd5622eabb54b4a81678003778ddce1.r2.dev/PicGo/d81b86609913a1b22e9dc5c1321a6f84d849039d54ccec97d4fab3945535cd03.png)

新建NODE_GLOBAL环境变量。

![](https://pub-ccd5622eabb54b4a81678003778ddce1.r2.dev/PicGo/a40a98b0a10bba6bf519d3d0f5643cd37e665585a1cb8df54e7fd0c1c817b857.png)

在PATH系统变量中，添加%NODE_GLOBAL%。

**（4）安装cnpm**

通过命令行配置nodejs淘宝镜像加速器（cnpm）。

```go
npm config set registry https://registry.npmmirror.com
```

![](https://pub-ccd5622eabb54b4a81678003778ddce1.r2.dev/PicGo/a31934c4392c3799eeafd5cfaeb0b37b0a5bb4560e8d08ef81f4a6140e1ea700.png)

**（5）检查配置路径**

在命令行输入npm config list。

![](https://pub-ccd5622eabb54b4a81678003778ddce1.r2.dev/PicGo/d2471f9dcac37597b47d82bfe03f7ea01c7ba6d58f303665aa884c6e28809ee4.png)

可以看到，前面的配置已经生效。

**（6）再次查看淘宝镜像源**

输入 npm config get registry 命令查看淘宝镜像源是否生效。

![](https://pub-ccd5622eabb54b4a81678003778ddce1.r2.dev/PicGo/0a75d57c82931384f23f4e75338b2637c7b15186a73754b62f8fc8702fb1f846.png)

**（7）安装cnpm**

输入如下命令通过淘宝镜像源安装cnpm。

```go
npm install -g cnpm --registry=https://registry.npmmirror.com
```

或者输入如下命令。

```go
# -g 就是全局安装
npm install cnpm -g
# 或使用如下语句解决 npm 速度慢的问题
npm install --registry=https://registry.npmmirror.com
```

**（8）查看cnpm安装结果**

![](https://pub-ccd5622eabb54b4a81678003778ddce1.r2.dev/PicGo/747eceab5a18b8345e26ea8dc0b562f03fa03807913017608ae5ee25e79d8dfe.png)

好了，至此，基于Windows操作系统的nodejs环境搭建成功。
