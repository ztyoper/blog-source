#### 3、从字节流(raw bytes)中创建ndarray数组

```python
import numpy as np

# 假设有一个字节流
byte_stream = b'abcdefg'

# 使用 frombuffer 函数创建数组
array = np.frombuffer(byte_stream, dtype=np.uint8)

# 打印数组
print(array)
```

> 你可以指定 dtype 参数以匹配你期望的数据类型。请确保字节流的长度和数据类型与数组的维度相匹配。
