# 4.线性规划和整数规划模型

## 0.序言

> <span style="color: black">在工程技术、经济管理、科学研究、军事作战训练及日常生产生活等众多领域中，人们常常会遇到各种优化问题。例如，在生产经营中，我们总是希望制订最优的生产计划，充分利用已有的人力、物力资源，获得最大的经济效益；在运输问题中，我们总是希望设计最优的运输方案，在完成运输任务的前提下，力求运输成本最小等。针对优化问题的数学建模问题也是数学建模竞赛中一类比较常见的问题，这样的问题常常可以使用数学规划模型进行研究。</span>

## 1.线性规划模型

> <span style="color: black">数学规划是运筹学的一个重要分支，而线性规划又是数学规划中的一部分主要内容。很多实际问题都可以归结为“线性规划”问题。线性规划（Linear Programming，简记为LP）有比较完善的理论基础和有效的求解方法，在实际问题中有极其广泛的应用。特别是随着计算机技术的飞速发展，线性规划的应用在深度和广度上有了极大的提高。</span>

> **<span style="color: red">问题分析</span><span style="color: #333333">：该问题是在企业的生产经营中经常面临的一个问题：如何制订一个最优的生产计划？因为原材料和加工时间的可用数量是有限的，这也就构成了该问题的约束条件，而解决该问题也就是在满足上述约束条件的前提下，确定三种产品的产量，使得产品销售后所获得的利润达到最大值。</span>**
> **<span style="color: red">模型假设</span><span style="color: #333333">：假设该企业的产品不存在积压，即产量等于销量。</span>**
> **<span style="color: red">符号说明</span>****<span style="color: #333333">：设</span>**$x_i$**<span style="color: #333333">表示产品</span>**$P_i$**<span style="color: #333333">每天的产量，</span>**$i = 1,2,3$**<span style="color: #333333">。通常称</span>**$x_i$**<span style="color: #333333">为决策变量。</span>**
> **<span style="color: red">模型建立</span>****<span style="color: #333333">：该问题的目标是使得总利润</span>**$z = 70x_i + 50x_2 + 60x_3$**<span style="color: #333333">达到最大值。通常称该利润函数为目标函数。</span>**
> **<span style="color: #333333">产品的产量应受到某些条件的限制。首先，两种原材料每天的实际消耗量不能超过可用数量，因此有</span>**
> $2x_1 + 4x_2 + 3x_3 \le 150$
> $3x_1 + x_2 + 35x_3 \le 160$
> **<span style="color: #333333">其次，生产两种产品时所花费的加工时间也不能超过该企业每天的最大可用加工时间，即</span>**$7x_1 + 3x_2 + 5x_3 <= 200$**<span style="color: #333333">。最后，三种产品的产量还应该满足非负约束，即</span>**$x_i \ge 0, i = 1,2,3$**。****<span style="color: #333333">由限制条件所确定的上述不等式，通常称为约束条件。</span>**
> **<span style="color: #333333">综上，可以建立该问题的数学模型为</span>**
> <span style="color: #333333">max</span>$z = 70x_1 + 50x_2 + 60x_3$

#### 2.建立线性规划模型的一般步骤

> **<span style="color: #333333">由前面的引例可知，规划问题的数学模型由三个要素组成：</span>**
> **<span style="color: #333333">（</span><span style="color: #333333">1</span><span style="color: #333333">）决策变量，是问题中要确定的未知量，用于表明规划问题中的用数量表示的方案、措施等，可由决策者决定和控制；</span>**
> **<span style="color: #333333">（</span><span style="color: #333333">2</span><span style="color: #333333">）目标函数，是决策变量的函数，优化目标通常是求该函数的最大值或最小值；</span>**
> **<span style="color: #333333">（3）约束条件，是决策变量的取值所受到的约束和限制条件，通常用含有决策变量的等式或不等式表示。</span>**
> **<span style="color: #333333">建立线性规划模型通常需要以下三个步骤：</span>**
> **<span style="color: #333333">第一步：分析问题，找出决策变量。</span>**
> **<span style="color: #333333">第二步：根据问题所给条件，找出决策变量必须满足的一组线性等式或者不等式约束，即为约束条件。</span>**
> **<span style="color: #333333">第三步：根据问题的目标，构造关于决策变量的一个线性函数，即为目标函数。</span>**

#### 1.例题1（续 引例）

![image.png](https://pub-ccd5622eabb54b4a81678003778ddce1.r2.dev/PicGo/a43c51cdef4ff52f62b5ab8adf8cfd9b7e6eccee406dd05c727f94f2c6da7674.png)

```python
#程序文件ex4_2.py
import cvxpy as cp
from numpy import array
# 只能使用 numpy 的数组 不能使用python的数组，不然虽然不报错，但是结果不对
c = array([70, 50, 60])  #定义目标向量
a = array([[2, 4, 3], [3, 1, 5], [7, 3, 5]])  #定义约束矩阵
b = array([150, 160, 200])  #定义约束条件的右边向量
x = cp.Variable(3, pos=True)  #定义3个决策变量
obj = cp.Maximize(c@x)    #构造目标函数
# a@x 是(3,)矩阵 ，b也是(3,)矩阵 因此会在 "<= "下一一对应，形成列表
cons = [a@x <=b]     #构造约束条件
prob = cp.Problem(obj, cons)
# GLPK_MI 是一种求解器，比较通用。winpython 已经 pip install 好了，不过自己执行安装命令时，发现找不到，只好使用spyder了。
# 其他的 求解器 可以使用 dir(cp)查看。例如：CPLEX
prob.solve(solver='GLPK_MI')   #求解问题
print('最优解为：', x.value)
print('最优值为：', prob.value)
```

```python
# 程序文件ex4_3.py
import cvxpy as cp
x = cp.Variable((5, 4), pos=True)
obj = cp.Maximize(1.15*x[3, 0]+1.40*x[1, 2]+1.25*x[2, 1]+1.06*x[4, 3])
cons = [x[0, 0]+x[0, 3] == 100000,
        x[1, 0]+x[1, 2]+x[1, 3] == 1.06*x[0, 3],
        x[2, 0]+x[2, 1]+x[2, 3] == 1.15*x[0, 0]+1.06*x[1, 3],
        x[3, 0]+x[3, 3] == 1.15*x[1, 0]+1.06*x[2, 3],
        x[4, 3] == 1.15*x[2, 0]+1.06*x[3, 3],
        x[2, 1] <= 40000, x[1, 2] <= 30000]
prob = cp.Problem(obj, cons)
prob.solve(solver='GLPK_MI')
print("最优值为：", prob.value)
print("最优解为：", x.value)
```

> ![image.png](https://pub-ccd5622eabb54b4a81678003778ddce1.r2.dev/PicGo/a6ba20a48cdc41944bee39fe060339c357d1dbe14f5c6a63f68fb0d7f1034aa8.png)![image.png](https://pub-ccd5622eabb54b4a81678003778ddce1.r2.dev/PicGo/9c92787c91b031a8081067f4532ada2d4c32ad283a96cc89f7a44a93ef1cd6c4.png)![image.png](https://pub-ccd5622eabb54b4a81678003778ddce1.r2.dev/PicGo/2ca54ba0e2eb9d0a1d91f70d2224a2896f6c7148ee1c42466b1dadc82a5a5286.png)
> 表格中展示的是租赁每一个单位的仓库的合同信息。因此$x_{11} +x_{12} + x_{13} + x_{14} \ge 15$中的$x_{ij}$表示租赁多少个的单位仓库。
> ![image.png](https://pub-ccd5622eabb54b4a81678003778ddce1.r2.dev/PicGo/15ccb21e4ea928683cd292af1357116c5600130e5e297f0a5c149f11cfebcb9c.png)

```python
# 程序文件ex4_4.py
import cvxpy as cp

x = cp.Variable((4, 4), pos=True)
obj = cp.Minimize(2800*sum(x[:, 0])+4500*sum(x[:3, 1]) +
                  6000*sum(x[:2, 2])+7300*x[0, 3])
cons = [sum(x[0, :]) >= 15,
        sum(x[0, 1:])+sum(x[2, :3]) >= 10,
        sum(x[0, 2:])+sum(x[1, 1:3])+sum(x[2, :2]) >= 20,
        x[0, 3]+x[1, 2]+x[2, 1]+[3, 0] >= 12]
prob = cp.Problem(obj, cons)
prob.solve(solver='GLPK_MI')
print("最优值为：", prob.value)
print("最优解为：\n", x.value)
```
