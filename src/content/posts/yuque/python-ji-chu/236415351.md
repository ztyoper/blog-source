# 自注意机制

```plain
首先一个序列 x1,x2,x3,,,xn ，对于每一个元素xi 都是长度为 d 的向量，之前rnn d = vocab_size -> embed_size 这里就是使用的d
其次自注意就是 query ， key, value都是自己 如图中公式
```

![tmp9741.png](https://pub-ccd5622eabb54b4a81678003778ddce1.r2.dev/PicGo/b255a55f0dadddf653ed5c8f2e53bce33834682a91e2ef109fac179d7f42b255.png)

xi 作为 query, 其余 x1~n 都是 key,这样就学习全部信息前后的全部信息

但是这样的复杂度如下是平方关系，不是线性关系，对算力要求高

![image.png](https://pub-ccd5622eabb54b4a81678003778ddce1.r2.dev/PicGo/971ce388b0d96f6fd26f3fb0a3376c5cf862b4e51fecd965844bc658dbbd6a11.png)

对于并行度，因为计算序列中 n 个元素，自注意都不需要获取其他元素的 f 输出,因此直接并行

最长路径，自注意力，意思就是当前元素找到一个以前元素信息所需要的路径最长长度

对于 cnn 而言，k 线性卷积核大小 ，每次将序列中 k 个元素转化为 1 个，因此当前元素到以前元素的最长就是 n / k 因为有 n/k 层

但是又有一个问题就是自注意没有每个元素之间的位置信息，比如替换序列中每个元素的位置后，不改变最后训练出来的模型权重，这是不行的。
因此使用位置编码，不同于二进制位置编码，该编码变化范围是-1~1 的实数，而不是整数 0，1。其次最先的几个 d 中维度是变化频率最快的，看热力图可知。
其次使用位置编码可以通过映射矩阵的转换来表示一个序列中两个相对位置大小为 delta 的位置编码信息。从而避免了序列中每个元素拥有绝对编码这种没用东西的问题（因为绝对编码，替换了序列中的元素也看不出对序列的变化，我们要的是序列中两个相对位置大小的元素不管放在序列中的哪两个位置，都能通过映射矩阵进行转换，这也是为什么要选 sin ,cos , 1/10000^2j / d 这样的参数的原因。）
