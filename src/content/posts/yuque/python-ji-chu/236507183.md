# Transformers

![image.png](https://pub-ccd5622eabb54b4a81678003778ddce1.r2.dev/PicGo/10f5e7846963d9c93f16612be8aa4556c236c521647730e6e733bf9c01f7613a.png)

len ： x1 x2 x3 ,,, xn 一个序列的 n 个元素。看图时把每一个序列中的 xi 作为一个样本来看，就非常好理解。![tmpDAA6.png](https://pub-ccd5622eabb54b4a81678003778ddce1.r2.dev/PicGo/3d21898b803d82969edbbfbf2e643582f1010761a1fc0267315f85cf33c7eedf.png)![tmp7C68.png](https://pub-ccd5622eabb54b4a81678003778ddce1.r2.dev/PicGo/b4e05bd10d589539ba7b0fec8a3fef275d264bb3ca4b3ef9922ad5dfac7d1928.png)

batch norm 在预测时，使用训练出来的全局均值与方差，用在预测长句子时，不是那么适合。batch norm 我的理解就是对于图中画出的多个序列中的每一个 xi 进行训练出一个针对某一个特征的全局均值与方差。然后使用到新的要预测的序列所有的 xi 上对应那一个特征上面

layer norm 没有保存全局均值与方差，每个序列使用自己的均值与方差。相对来说比较独立。
