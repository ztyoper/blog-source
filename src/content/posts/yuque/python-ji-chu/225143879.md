### 3.Q3

```plain
# 等待页面加载完成，15s内加载完毕即可继续执行，如果使用time.sleep就必须等待一定时间才能继续执行。
print("等待页面加载...")
WebDriverWait(browser, 15).until(
    lambda driver: driver.execute_script('return document.readyState') == 'complete'
)
```
