### 1.解释器

python.exe执行文件就是解释器。

1. cmd中输入python,相当于执行python.exe，然后进入 `>>>` ，在 `>>>` 中执行python源代码，依次执行每一行源代码时，是边执行 `解释` ，因此 `python` 是解释型语言， `java` 也是解释型语言。

#### 2.字符串拼接

```python
# 字符串字面量和字符串变量的拼接
name = "黑马程序员"
address = "建材城东路9号院"
tel = 4006189090
print("我是：" + name + ",我的地址是：" + address + ",我的电话是：" + tel) # TypeError: can only concatenate str (not "int") to str 只能将 str（而不是 "int"）连接到 str
print("我是：", name, ",我的地址是：", address, ",我的电话是：", tel)
```

**结论：**

- 第一种拼接非字符串要报错，更习惯使用第二种

#### 9.startwith() endwith()

> **<span style="color: red">startswith()、endswith()</span>**
> **这两个方法用来判断字符串是否以指定字符串开始或结束，可以接收两个整数参数来限定字符串的检测范围。**

```python

print(text.endswith("Python"))  # 输出: False
```


### 3.自定义模块

##### 1.第一点

```python
from my_module1 import test
```

```python
def test(x, y):
    print(x + y)
# test(1,2)
if __name__ == '__main__':
    test(1, 2)
```

**结论：**自定义模块时，本身有`test(1,2)`这一行测试，但在`main.py`中导入该方法时，也会自动执行`test(1,2)`测试代码，为了能保留测试代码的同时，不会导入方法就执行`test(1,2)`，我们使用`if __name__ == '__main__':`作为`test(1,2)`的判断条件，因为`__name__`是该模块文件内置的变量，执行该文件是会将`name`置为`main`
