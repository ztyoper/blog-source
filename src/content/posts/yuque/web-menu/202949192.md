```plain
<plugin>
    <groupId>org.apache.maven.plugins</groupId>
    <artifactId>maven-compiler-plugin</artifactId>
    <configuration>
        <annotationProcessorPaths>
            <path>
                <groupId>org.projectlombok</groupId>
                <artifactId>lombok</artifactId>
            </path>
        </annotationProcessorPaths>
        <source>10</source>
        <target>10</target>
    </configuration>
</plugin>
```

```plain

```

### 5.Q5

> java: 已在类 com.ztyoper.menu.pojo.Dish中定义了构造器 Dish()
> 使用lombok 的 @NoArgsConstructor ，注意父类如果有 无参数构造器的话，子类如果要重写就重写，不重写，也继承了父类的无参数构造器。不需要@NoArgsConstructor，只要@AllArgsConstructor即可。我们保证父类一直有@NoArgsConstructor ，@AllArgsConstructor两个构造器。

### 7.Q7

> 在`docker-compose.yml`中，你将 MySQL 容器的端口从`3306`映射到`33061`：
> 这意味着你可以通过宿主机的`33061`端口访问 MySQL 容器的`3306`端口，但是**容器内部的服务仍然使用容器内部的端口**`3306`。因此，**Nacos**容器使用`MYSQL_SERVICE_PORT=33061`来连接数据库时，会尝试连接宿主机的`33061`端口，而不是 MySQL 容器内部的`3306`端口。
> 在 Docker 容器间的通信中，不应使用宿主机的端口（即宿主机的`33061`）。应使用容器的**服务名称 mysql-menu 作为 IP**,**容器端口 保持 3306**。

### 10.Q10

> @Value（${}）中的配置只适合，字符串，数值，布尔。其他太复杂的 ，如List&lt;Dish&gt; 就无法绑定。搭配使用@Refreshscope 进行 热更新。这个和属性类的绑定不一样。属性类在设置了nacos热更新后即可（默认是true）
