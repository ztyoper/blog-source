# 1、基础知识

## 1、JS的导入导出

### 1、以前

```javascript
//简单的展示信息
function simpleMessage(msg){
    console.log(msg)
}

//复杂的展示信息
function complexMessage(msg){
    console.log(new Date()+": "+msg)
}
```

```html
<body>
  <div id="app">
    <button id="btn">点我展示信息</button>
  </div>
  <!-- 导入showMessage.js文件的全部内容 -->
  <script src="showMessage.js"></script>

  <script>
    document.getElementById("btn").onclick = function(){
      complexMessage('bbbbb');
    }
  </script>

</body>
```

> 上述是以前的写法，会导入showMessage.js文件的**全部**内容，包括我们不用的simpleMessage方法。

### 2、按需导入导出 JS

```javascript
//简单的展示信息
export function simpleMessage(msg){
    console.log(msg)
}

//复杂的展示信息
export function complexMessage(msg){
    console.log(new Date()+": "+msg)
}
```

```html
<body>
  <div id="app">
    <button id="btn">点我展示信息</button>
  </div>
  <!-- 导入showMessage.js文件中添加了export修饰并且默认导出的内容，必须是module -->
  <script type = "module">
    /* 只导入complexMessage方法 */
    import { complexMessage } from './showMessage.js'
    document.getElementById("btn").onclick = function(){
      complexMessage('bbbbb');
    }
  </script>

</body>
```

> 现在这样写，就只会导入js文件中添加了export修饰的方法，但是如果一个JS方法中有上千个方法都有可能被使用到，如果再再方法前面添加 export 修饰，就比较麻烦，而且不利于我们观察哪些方法进行了导出，因此我们采用批量导出的方式。

### 3、批量导入导出 JS

```javascript
//简单的展示信息
function simpleMessage(msg){
  console.log(msg)
}

//复杂的展示信息
function complexMessage(msg){
  console.log(new Date()+": "+msg)
}
export {complexMessage, simpleMessage}
```

```javascript
<body>
    <div id="app">
        <button id="btn">点我展示信息</button>
    </div>
  
    <script type = "module">
        /* 只导入complexMessage方法 */
        import { complexMessage } from './showMessage.js'
        document.getElementById("btn").onclick = function(){
            complexMessage('bbbbb');
        }
    </script>
    
</body>
```

> 导入时`import { complexMessage as cm} from './showMessage.js'`可以使用别名，导出时也可以使用别名
> 但这种方法可能出现`import { complexMessage as cm,.......} from './showMessage.js'`过长的情况。因此我们使用批量默认导出

### 4、批量默认导入导出 JS

```javascript
//简单的展示信息
function simpleMessage(msg){
  console.log(msg)
}

//复杂的展示信息
function complexMessage(msg){
  console.log(new Date()+": "+msg)
}
export default {complexMessage, simpleMessage}
//如果像下面这样写，messageMethods就是方法complexMessage，点不出来任何东西，只能执行messageMethods(msg)方法，相当于执行complexMessage(msg)方法，但是我们一般在导出时都要添加花括号。
export default complexMessage
```

```html
<body>
    <div id="app">
        <button id="btn">点我展示信息</button>
    </div>
    <script type = "module">
        /* messageMethods是随便取的名字，表示模块名，里面包括所有默认导出的内容 */
        import messageMethods from './showMessage.js'
        document.getElementById("btn").onclick = function(){
            messageMethods.complexMessage('bbbbb');
        }
    </script>
    
</body>
```

#### 5、v-model

> 数据与视图的双向绑定。一个发生变化，另一个也会变化。
> 不同于v-bind 绑定元素的属性值取值， v-model是用在表单元素，如 input 这些需要填写内容的元素上。v-model不能为元素的属性值进行绑定。

#### 6、model与bind

> 发布状态: &lt;input type="text" v-model="searchCondition.state" /&gt; 其中能使用 v-bind:value="searchCondition.state"代替 v-model="searchCondition.state"吗
> 不行，因为：
> #### 1.`v-model`的作用
> `v-model`是 Vue 中的双向数据绑定指令，它会在输入框（或其他表单元素）与 Vue 实例中的数据之间创建双向绑定。当用户在输入框中输入内容时，`searchCondition.state`的值会自动更新；反过来，当`searchCondition.state`的值发生变化时，输入框的内容也会自动更新。
> #### 2.`v-bind`的作用
> `v-bind`用于绑定一个属性的值，而`v-bind:content`并不是一个标准的 HTML 属性，所以不适用于这种情况。你可以用`v-bind`来绑定其他有效的 HTML 属性，例如`v-bind:value="searchCondition.state"`，这将把`searchCondition.state`的值绑定到`value`属性上，但这只是单向绑定。当`searchCondition.state`变化时，`input`元素的值会更新，但用户在输入框中输入内容时，并不会影响`searchCondition.state`。
> #### 3. 使用`v-bind`和`v-model`的区别
> - `v-bind` 是单向绑定，只会将数据传递给视图。
> - `v-model` 是双向绑定，会同时更新数据和视图。

> - **<span style="color: rgb(44, 44, 54)">axios.get()</span>** : 这是 axios 库中用于发送 GET 请求的方法。axios 是一个基于 promise 的 HTTP 客户端，用于浏览器和 node.js 中发起网络请求。
> - **<span style="color: rgb(44, 44, 54)">'</span>** http://localhost:8080/article/search **<span style="color: rgb(44, 44, 54)">'</span>** : 这是请求的目标 URL。这里是在向本地运行的服务的 /article/search 路径发送请求。
> - **<span style="color: rgb(44, 44, 54)">{ params: { ...searchConditions.value } }</span>** : 这是请求配置对象，其中 params 属性用于指定查询字符串参数。查询字符串参数是 URL 后面跟问号 (?) 和键值对的形式附加的参数，例如 ?key=value 。
> <span style="color: rgb(44, 44, 54)">{ ...searchConditions.value }</span><span style="color: rgb(44, 44, 54)">: 这里的</span><span style="color: rgb(44, 44, 54)">...</span><span style="color: rgb(44, 44, 54)">是扩展运算符（spread operator），它会将</span><span style="color: rgb(44, 44, 54)">searchConditions.value</span><span style="color: rgb(44, 44, 54)">对象的所有可枚举属性展开为一系列键值对。这意味着如果</span><span style="color: rgb(44, 44, 54)">searchConditions.value</span><span style="color: rgb(44, 44, 54)">包含多个属性，如</span><span style="color: rgb(44, 44, 54)">{ key1: 'value1', key2: 'value2' }</span><span style="color: rgb(44, 44, 54)">，那么它会被转换成</span><span style="color: rgb(44, 44, 54)">params: { key1: 'value1', key2: 'value2' }</span><span style="color: rgb(44, 44, 54)">，并最终附加到 URL 的查询字符串上。</span>
> <span style="color: rgb(44, 44, 54)">例如，如果</span><span style="color: rgb(44, 44, 54)">searchConditions.value</span><span style="color: rgb(44, 44, 54)">是</span><span style="color: rgb(44, 44, 54)">{ title: 'Vue.js', author: 'John Doe' }</span><span style="color: rgb(44, 44, 54)">，则最终的 URL 可能会变成</span><span style="color: rgb(44, 44, 54)">http://localhost:8080/article/search?title=Vue.js&author=John%20Doe</span><span style="color: rgb(44, 44, 54)">。</span>
> - **<span style="color: rgb(44, 44, 54)">.then(result =&gt; {...})</span>** : 这是一个 Promise 的 then 方法，用于处理成功的响应。 result 参数包含了服务器返回的数据，你可以从中访问响应体 result.data 。
> - **<span style="color: rgb(44, 44, 54)">.catch(err =&gt; {...})</span>** : 这是一个 Promise 的 catch 方法，用于处理错误。如果请求失败， err 将包含错误信息。
> <span style="color: rgb(44, 44, 54)">总之，这段代码的作用是根据</span><span style="color: rgb(44, 44, 54)">searchConditions.value</span><span style="color: rgb(44, 44, 54)">对象的内容动态构造查询参数，并发送一个 GET 请求到服务器，然后处理服务器返回的结果或捕获任何可能发生的错误。</span>

    return Promise.reject(err);
