在系统中，一般会分为核心业务和非核心业务，对于核心业务来说，我们需要保证业务的可靠性与稳定性，对于非核心业务来说，当系统并发量达到一定程度时，我们可以将同步调用降级为异步调用，实现异步调用的最常见的方式之一就是将请求放入消息队列，非核心业务从消息队列中消费请求数据进行处理。这就是典型的生产者消费者模式。除此之外，也可以根据具体的业务场景进行分析，采用半同步半异步模式进行处理。

### **一、故事背景**

小菜按照需求开发的在用户下单并成功支付后，向用户的手机发送短信，告知用户支付系统余额的消费情况，以及当前的余额的的功能性能很差，在老王的指导下，小菜明白了性能差的原因，并且知道了这种场景可以使用半同步半异步模式提升性能，同时，在老王的耐心讲解下，小菜也同样明白了到底什么是半同步半异步模式。那如何基于半同步半异步模式优化支付系统呢？

对于这个问题，小菜又开始犯难了，明白什么是半同步半异步模式是一回事儿，真正落地到项目中又是另一回事。哎，没办法，奈何自己功力不够，看来还是要寻求老王的帮助才行。最终，在老王的耐心指导下，小菜终于基于半同步半异步模式优化好了支付系统的逻辑。

### **四、编码实现**

基于半同步半异步模式优化后的代码实现步骤如下所示。

**（1）实现AsyncTask类**

AsyncTask类是实现半同步半异步模式的核心抽象类。

源码详见：[io.binghe.concurrent.design.half.sync.async.right.AsyncTask](http://io.binghe.concurrent.design.half.sync.async.right.AsyncTask)。

```go
public abstract class AsyncTask<T> {
​
  //用于执行异步任务
  private volatile Executor executor;
  private static final ExecutorService DEFAULT_EXECUTOR;
​
  static {
    DEFAULT_EXECUTOR = new ThreadPoolExecutor(1,1,60,TimeUnit.SECONDS, new ArrayBlockingQueue<>(1024),(r) -> {
          Thread t = new Thread(r, "thread-half-sync-async");
          t.setDaemon(true);
          return t;
         },new ThreadPoolExecutor.CallerRunsPolicy());
   }
​
  public AsyncTask() {
    this(DEFAULT_EXECUTOR);
   }
​
  public AsyncTask(Executor executor) {
    this.executor = executor;
   }
​
  public void setExecutor(Executor executor) {
    this.executor = executor;
   }
​
  /**
* 交给子类实现，默认什么都不执行
* @param params 调用dispatch()方法传递的参数
*/
  protected void doPreExecute(Object ... params){
​
   }
​
  /**
* 交给子类实现，默认什么都不执行
* @param result 同步任务的执行结果
*/
  protected void doPostExecute(T result){
​
   }
​
  protected void doExeception(Exception e){
    e.printStackTrace();
   }
​
  /**
* 留给子类实现
* @param params 调用dispatch()方法传递的参数
* @return 同步任务的执行结果
*/
  protected abstract T doExecute(Object ... params);
​
  /**
* 对外暴露的方法
*/
  protected Future<T> dispatch(final Object ... params){
    //初步处理数据，主要是异步层执行
    doPreExecute(params);
    // 同步层回调任务
    Callable<T> callable = () -> doExecute(params);
    FutureTask<T> futureTask = new FutureTask<T>(callable){
      @Override
      protected void done() {
        try {
          doPostExecute(this.get());
         } catch (InterruptedException e) {
          doExeception(e);
         } catch (ExecutionException e) {
          doExeception(e);
         }
       }
     };
    executor.execute(futureTask);
    return futureTask;
   }
}
```

可以看到，在AsyncTask抽象类中，提供了多个由子类实现的方法，并且在dispatch()方法中会按照一定的顺序来调用这些由子类实现的方法。

**（2）实现SimpleAsyncTask类**

SimpleAsyncTask类继承了AsyncTask类。

源码详见：[io.binghe.concurrent.design.half.sync.async.right.SimpleAsyncTask](http://io.binghe.concurrent.design.half.sync.async.right.SimpleAsyncTask)。

```go
public class SimpleAsyncTask extends AsyncTask<String> {
  @Override
  protected String doExecute(Object... params) {
    System.out.println("发送短信，传递的手机号为：" + params[0]);
    return "send sms success...";
   }
​
  @Override
  protected void doPreExecute(Object... params) {
    System.out.println("准备发送短信，传递的手机号为：" + params[0]);
   }
​
  public Future<String> execute(String phone){
    if (phone == null || phone.isEmpty()){
      throw new IllegalArgumentException("手机号不能为空");
     }
    return this.dispatch(phone);
   }
}
```

可以看到，在SimpleAsyncTask类中实现了父类的doExecute()方法和doPreExecute()方法，并对外提供了execute()方法。

**（4）实现PayServiceImpl类**

PayServiceImpl类实现了PayService接口，并模拟实现了支付成功发送短信的逻辑。

源码详见：[io.binghe.concurrent.design.half.sync.async.right.PayServiceImpl](http://io.binghe.concurrent.design.half.sync.async.right.PayServiceImpl)。

```go
public class PayServiceImpl implements PayService{
  private SimpleAsyncTask simpleAsyncTask;
  public PayServiceImpl() {
    this.simpleAsyncTask = new SimpleAsyncTask();
   }
  @Override
  public void pay(BigDecimal money) {
    System.out.println("执行支付逻辑开始");
    long payStartTime = System.currentTimeMillis();
    try {
      Thread.sleep(2000);
     } catch (InterruptedException e) {
      throw new RuntimeException(e);
     }
    System.out.println("支付逻辑执行完毕，支付的金额为：" + money);
    System.out.println("支付逻辑执行结束，耗时：" + (System.currentTimeMillis() - payStartTime) + "ms");
​
    System.out.println("执行发短信的逻辑开始");
    long smsStartTime = System.currentTimeMillis();
    //采用半同步半异步方式发送短信，将短信放入队列由后续的同步任务层处理，这样能够提高系统接收请求的并发度和吞吐量，提升系统的响应性能
    Future<String> execute = simpleAsyncTask.execute("13312345678");
    try {
      System.out.println(execute.get());
     } catch (Exception e) {
      e.printStackTrace();
     }
    System.out.println("执行发短信的逻辑结束，耗时：" + (System.currentTimeMillis() - smsStartTime) + "ms");
   }
}
```

可以看到，在PayServiceImpl类实现的pay()方法中，当模拟支付成功后，会调用simpleAsyncTask的execute()方法来发送短信。

至此，基于半同步半异步模式优化支付系统的逻辑实现完毕。
