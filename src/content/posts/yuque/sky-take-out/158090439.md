## 2、代码开发

### 1、根据id查询套餐

#### 1、Controller

```java
/**
     * 根据setmealId查询套餐
     * @param id
     * @return
     */
    @GetMapping("/{id}")
    @ApiOperation("根据setmealId查询套餐")
    public Result<SetmealVO> getBySetmealId(@PathVariable Long id){
        log.info("根据setmealId查询套餐");
        SetmealVO setmealVO = setmealService.getBySetmealId(id);
        return Result.success(setmealVO);
    }
```

#### 2、Service

```java
/**
     * 根据setmealId查询套餐
     * @param id
     * @return
     */
    @Override
    public SetmealVO getBySetmealId(Long id) {
        //获取套餐
        SetmealVO setmealVO = setmealMapper.getBySetmealId(id);

        //获取套餐下的菜品ids
        List<SetmealDish> setmealDishes = setmealDishMapper.getDishIdsBySetmealId(id);
        setmealVO.setSetmealDishes(setmealDishes);

        return setmealVO;
    }
```

### 2、修改套餐

#### 1、Controller

```java
/**
     * 修改套餐
     * @param setmealDTO
     * @return
     */
    @PutMapping
    @ApiOperation("修改菜品")
    public Result update(@RequestBody  SetmealDTO setmealDTO){
        log.info("修改菜品:{}",setmealDTO);
        setmealService.update(setmealDTO);
        return Result.success();
    }
```

#### 2、Service

```java
/**
     * 修改套餐
     *
     * @param setmealDTO
     * @return
     */
    @Transactional
    public void update(SetmealDTO setmealDTO) {
        Setmeal setmeal = new Setmeal();
        BeanUtils.copyProperties(setmealDTO, setmeal);
        Long setmealId = setmeal.getId();

        setmealMapper.update(setmeal);

        //删除setmeal与Dish的对应关系
        setmealDishMapper.deleteBatch(Collections.singletonList(setmealId));

        //新增setmeal与Dish的对应关系
        List<SetmealDish> setmealDish = setmealDTO.getSetmealDishes();
        if (setmealDish != null && setmealDish.size() > 0) {
            //给这几个setmealDish的setmealId赋值
            setmealDish.forEach(iter -> iter.setSetmealId(setmealId));
            setmealDishMapper.insertBatch(setmealDish);
        }
    }
```

#### 3、Mapper

```java
/**
     * 更新套餐信息
     * @param setmeal
     */
    @AutoFill(value = OperationType.UPDATE)
    void update(Setmeal setmeal);
```

```java
/**
     * 根据setmealIds批量删除setmealDish对应关系
     * @param ids

/**
     * 添加新套餐下的菜品
     * @param setmealDishes
     */
    void insertBatch(List<SetmealDish> setmealDishes);
```
