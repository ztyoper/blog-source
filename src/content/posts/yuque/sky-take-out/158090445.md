# 新增套餐

先要明白的一件事：套餐是在分类里面。和菜品分类在一个category分类表。例如：人气套餐，商务套餐，蜀味特色，特色蒸菜.....。套餐分类和菜品分类用category表的一个字段表示：0：菜品分类；1：套餐分类。

### 1、产品原型

> 业务规则：
> 1. 套餐名称唯一
> 2. 套餐必须属于某个分类
> 3. 套餐必须包含菜品
> 4. 名称、分类、价格、图片为必填项
> 5. 添加菜品窗口需要根据分类类型来展示菜品
> 6. 新增的套餐默认为停售状态

### 2、接口设计

> 接口设计（共涉及到4个接口）：
> 1. 根据类型查询分类（已完成）
> 2. 根据分类id查询菜品
> 3. 图片上传（已完成）
> 4. 新增套餐

## 2、代码开发

### 1、根据分类id查询菜品

#### 1、Controller

```java
    /**
     * 根据categoryId查询菜品不要带上口味
     * @return
     */
    @GetMapping("/list")
    @ApiOperation("根据dishId查询菜品不要带上口味")
    public Result<List<Dish>> getByCategoryIdWithoutFlavors(Long categoryId){
        log.info("根据dishId查询菜品不要带上口味:{}", categoryId);
        List<Dish> dishes  = dishService.getByCategoryIdWithoutFlavors(categoryId);
        return Result.success(dishes);
    }
```

#### 2、Service

```java
/**
     * 根据categoryId查询菜品不要带上口味
     * @return
     */
    @Override
    public List<Dish> getByCategoryIdWithoutFlavors(Long categoryId) {
        // select * from dish where category_id = ?
        List<Dish> dishes = dishMapper.getByCategoryId(categoryId);
        return dishes;
    }
```

#### 3、Mapper

```java
    <select id="getByCategoryId" resultType="com.sky.entity.Dish">
        select * from dish where category_id = #{categoryId}
    </select>
```

### 2、新增套餐

#### 1、Controller

```java
    /**
     * 添加一种新套餐
     * @param setmealDTO
     * @return
     */
    @PostMapping
    @ApiOperation("添加一种新套餐")
    public Result save(@RequestBody SetmealDTO setmealDTO){
        log.info("添加一种新套餐:{}", setmealDTO);
        setmealService.save(setmealDTO);
        return Result.success();

    }
```

1. GetMapping不能使用@RequestBody来获取参数。因为参数不是在请求体中。而是拼接到url中。

#### 2、Service

```java
/**
     * 添加一种新套餐
     * @param setmealDTO
     * @return
     */
    @Transactional
    @Override
    public void save(SetmealDTO setmealDTO) {
        //添加一个套餐
        Setmeal setmeal = new Setmeal();

        BeanUtils.copyProperties(setmealDTO, setmeal);

        setmealMapper.insert(setmeal);

        List<SetmealDish> setmealDish = setmealDTO.getSetmealDishes();
        if (setmealDish != null && setmealDish.size() > 0) {
            //给这几个setmealDish的setmealId赋值
            setmealDish.forEach(iter -> iter.setSetmealId(setmeal.getId()));

            //添加套餐菜品关系
            setmealDishMapper.insert(setmealDTO.getSetmealDishes());
        }
    }
```

#### 3、Mapper

```java
 <insert id="insert" useGeneratedKeys="true" keyProperty="id">
        insert into setmeal (category_id, name, price, status, description, image, create_time, update_time,
                             create_user, update_user)
        values (#{categoryId}, #{name} , #{price}, #{status} , #{description}, #{image}, #{createTime}, #{updateTime},#{createUser},#{updateUser})
    </insert>
```

1. `@AutoFill(value = OperationType.INSERT)` 要添加。

```java
<insert id="insert" parameterType="setmealDish">
        insert into setmeal_dish (setmeal_id, dish_id, name, price, copies)
        VALUES
        <foreach collection="setmealDishes" item="iter" separator=","> 
            (#{iter.setmealId}, #{iter.dishId}, #{iter.name}, #{iter.price}, #{iter.copies})
        </foreach>
    </insert>
```

1. `separator` 不能忘记！！·
