# 缓存套餐

## 1、问题说明

![tmpA008.png](https://pub-ccd5622eabb54b4a81678003778ddce1.r2.dev/PicGo/ccac0787cba87c740ea53e26967e3d2970f6b147ee88c39ba195d87bc6eaa34f.png)

> 我们获取不同分类的菜品列表是向服务端发送请求。每次切换分类都要重新发一次请求给服务端来获取菜品列表。如果人多。那么就卡。我们就利用缓存来解决这一问题。

## 2、实现思路

1. 导入Spring Cache和Redis相关maven坐标
2. 在启动类上加入@EnableCaching注解，开启缓存注解功能
3. 在用户端接口SetmealController的list方法上加入@Cacheable注解
4. 在管理端接口SetmealController的save、delete、update、startOrStop等方法上加入CacheEvict注解

## 3、代码开发

### 1、实现缓存

#### 1、Controller

```java
/**
     * 条件查询
     *
     * @param categoryId
     * @return
     */
    @GetMapping("/list")
    @ApiOperation("根据分类id查询套餐")
    @Cacheable(cacheNames = "setmealCache", key = "#categoryId")// key: setmealCache
    public Result<List<Setmeal>> list(Long categoryId) {
        Setmeal setmeal = new Setmeal();
        setmeal.setCategoryId(categoryId);
        setmeal.setStatus(StatusConstant.ENABLE);

        List<Setmeal> list = setmealService.list(setmeal);
        return Result.success(list);
    }
```

> 要在启动程序上标注：@EnableCaching

#### 2、RedisConfiguration

```java
@Configuration
@Slf4j
public class RedisConfiguration {

    @Bean
    public RedisTemplate redisTemplate(RedisConnectionFactory redisConnectionFactory){
        log.info("开始创建redis模板类...");
        RedisTemplate<Object, Object> redisTemplate = new RedisTemplate<>();
        //设置redis的连接工厂对象
        redisTemplate.setConnectionFactory(redisConnectionFactory);
        //设置key的序列化器，默认为JdkSerializationRedisSerializer
        redisTemplate.setKeySerializer(new StringRedisSerializer());

        return redisTemplate;

    }
}
```

> 发现一个bug,就是反序列化value得到店铺状态时会报错，因为不是List.class而是Integer.class。所以对于Value最好使用默认的序列化器。如果真想将某个分类的多有菜品都已json格式存储到redis中，而又不影响店铺状态，可以使用两个redistemplate来进行数据缓存。

### 2、清除缓存

```java
@Slf4j
@RestController
@Api(tags = "套餐管理")
@RequestMapping("/admin/setmeal")
public class SetmealController {

    @Autowired
    private SetmealService setmealService;

    /**
     * 添加一种新套餐
     * @param setmealDTO
     * @return
     */
    //清除当前分类的菜品的缓存
    //新增不需要进行清除操作，因为新增后默认是禁用，不会出现在微信列表。启用时清除就行了。
    //@Cacheable
    @PostMapping
    @ApiOperation("添加一种新套餐")
    public Result save(@RequestBody SetmealDTO setmealDTO){
        log.info("添加一种新套餐:{}", setmealDTO);
        setmealService.save(setmealDTO);
        return Result.success();

    }

    /**
     * 套餐分页查询
     * @param setmealPageQueryDTO
     * @return
     */
    @GetMapping("/page")
    @ApiOperation("套餐分页查询")
    public Result<PageResult> pageQuery(SetmealPageQueryDTO setmealPageQueryDTO){
        log.info("套餐分页查询：{}",setmealPageQueryDTO);
        PageResult pageResult= setmealService.pageQuery(setmealPageQueryDTO);
        return Result.success(pageResult);
    }

    /**
     * 删除套餐
     * @param ids
     * @return
     */
    //清除所有缓存
    //删除时不需要清除操作。因为删除前必须将菜品禁用，禁用后就已经不在微信列表中了。
    @DeleteMapping
    @ApiOperation("删除套餐")
    public Result delete(@RequestParam List<Long> ids){
        log.info("删除套餐:{}", ids);
        setmealService.deleteBatch(ids);
        return Result.success();
    }

    /**
     * 根据setmealId查询套餐
     * @param id
     * @return
     */
    @GetMapping("/{id}")
    @ApiOperation("根据setmealId查询套餐")
    public Result<SetmealVO> getBySetmealId(@PathVariable Long id){
        log.info("根据setmealId查询套餐");
        SetmealVO setmealVO = setmealService.getBySetmealId(id);
        return Result.success(setmealVO);
    }
    /**
     * 修改套餐
     * @param setmealDTO
     * @return
     */
    //清除所有缓存
    //因为修改，可能会修改所属的分类，这样就要涉及多个分类（例如套餐如果包含该菜品，套餐也会受到影响）。我们直接清除全部缓存
    @CacheEvict(cacheNames = "setmealCache",allEntries = true)// key: setmealCache
    @PutMapping
    @ApiOperation("修改菜品")
    public Result update(@RequestBody  SetmealDTO setmealDTO){
        log.info("修改菜品:{}",setmealDTO);
        setmealService.update(setmealDTO);
        return Result.success();
    }

    /**
     * 启售，停售套餐
     * @param status
     * @param id
     * @return
     */
    @PostMapping("/status/{status}")
    @ApiOperation("启售，停售套餐")
    //本来想根据mealId找到对应的分类i，然后精确清除该套餐分类的菜品缓存，但是如何确定缓存中key的值呢？不好确定，我们只能删除所有缓存。。。
    @CacheEvict(cacheNames = "setmealCache", allEntries = true)
    public Result startOrStopSetmeal(@PathVariable Integer status , Long id ){
        log.info("启售，停售套餐:{},{}",status , id);
        setmealService.startOrStopDish(status, id);
        return Result.success();
    }
}
```
