## 2、代码开发

### 1、**<span style="color: rgb(38, 38, 38)">销量排名Top10</span>**

#### 1、Controller

```java
/**
     * 销量前十展示
     * @param begin
     * @param end
     * @return
     */
    @GetMapping("/top10")
    @ApiOperation("销量前十展示")
    public Result<SalesTop10ReportVO> saleTop10Report(
            @DateTimeFormat(pattern = "yyyy-MM-dd") LocalDate begin,
            @DateTimeFormat(pattern = "yyyy-MM-dd") LocalDate end){

        log.info("销量前十展示：{}，{}",begin, end);
        SalesTop10ReportVO salesTop10ReportVO  = reportService.getSaleTop10Report(begin, end);
        return Result.success(salesTop10ReportVO);
    }
```

#### 2、Service

```java
/**
     * 销量前十展示
     * @param begin
     * @param end
     * @return
     */
    @Override
    public SalesTop10ReportVO getSaleTop10Report(LocalDate begin, LocalDate end) {
        LocalDateTime beginTime = LocalDateTime.of(begin, LocalTime.MIN);
        LocalDateTime endTime = LocalDateTime.of(end, LocalTime.MAX);

        List<GoodsSalesDTO> salesTop10 = orderMapper.getSaleTop10(beginTime, endTime);
        List<String> names = salesTop10.stream().map(GoodsSalesDTO::getName).collect(Collectors.toList());
        String nameList = StringUtils.join(names, ",");

        List<Integer> numbers = salesTop10.stream().map(GoodsSalesDTO::getNumber).collect(Collectors.toList());
        String numberList = StringUtils.join(numbers, ",");

        return SalesTop10ReportVO.builder()
                .nameList(nameList)
                .numberList(numberList)
                .build();
    }
```

#### 3、Mapper
