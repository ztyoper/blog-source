## 2、代码开发

### 1、Controller

```java
/**
     * 修改菜品
     * @param dishDTO
     * @return
     */
    @PutMapping
    @ApiOperation("修改菜品")
    public Result update(@RequestBody  DishDTO dishDTO){
        log.info("修改菜品:{}", dishDTO);
        dishService.update(dishDTO);
        return Result.success();
    }
```

1. GetMapping不能使用@RequestBody来获取参数。因为参数不是在请求体中。而是拼接到url中。

### 2、Service

```java
/**
     * 修改菜品
     *
     * @param dishDTO
     * @return
     */
    @Override
    @Transactional
    public void update(DishDTO dishDTO) {
//        //删除菜品
//        dishMapper.deleteBatch(Collections.singletonList(dishDTO.getId()));
//
//        //新增菜品
//        Dish dish = new Dish();
//        BeanUtils.copyProperties(dishDTO, dish);
//        dishMapper.insert(dish);
        //不用上面的方式，上面的方式相当于要改变当前修改的菜品的id。会造成不可知的影响，减弱健壮性
        Dish dish = new Dish();
        BeanUtils.copyProperties(dishDTO, dish);
        Long dishId = dish.getId();

        dishMapper.update(dish);

        //删除口味
        dishFlavorMapper.deleteFlavorsByDishIds(Collections.singletonList(dishId));

        //新增口味
        List<DishFlavor> flavors = dishDTO.getFlavors();
        if (flavors != null && flavors.size() > 0) {
            //给这几个flavor的dishId赋值
            flavors.forEach(dishFlavor -> dishFlavor.setDishId(dishId));
            dishFlavorMapper.insertBatch(flavors);

        }
    }
```

## 3、功能测试
