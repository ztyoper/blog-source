## 1、需水分析和设计

### 1、产品原型

![tmp6035.png](https://pub-ccd5622eabb54b4a81678003778ddce1.r2.dev/PicGo/c339da02c802f349e8198c6f080f8cf0c6552d51238a0fdcdbb1bdb310d9027a.png)

> 业务规则：
> - 可以对状态为起售的套餐进行停售操作，可以对状态为停售的套餐进行起售操作
> - 起售的套餐可以展示在用户端，停售的套餐不能展示在用户端
> - 起售套餐时，如果套餐内包含停售的菜品，则不能起售

### 1、启售停售套餐

#### 1、Controller

```java
/**
     * 启售，停售套餐
     * @param status
     * @param id
     * @return
     */
    @PostMapping("/status/{status}")
    @ApiOperation("启售，停售套餐")
    public Result startOrStopDish(@PathVariable Integer status , Long id ){
        log.info("启售，停售套餐:{},{}",status , id);
        setmealService.startOrStopDish(status, id);
        return Result.success();
    }
```

#### 2、Service

```java
/**
     * 启售，停售套餐
     *
     * @param status
     * @param id
     * @return
     */
    @Override
    public void startOrStopDish(Integer status, Long id) {
        Setmeal setmeal = Setmeal.builder()
                .status(status)
                .id(id)
                .build();
        //套餐status 0-->1.判断该套餐内的菜品是否都启售
        List<Long> dishIds = setmealDishMapper.getDishIdsBySetmealId(id);
        List<Integer> statuses = dishMapper.queryStatusByDishIds(dishIds);
        for(Integer dishStatus : statuses){
            if(dishStatus == StatusConstant.DISABLE){
                throw new SetmealEnableFailedException(MessageConstant.SETMEAL_ENABLE_FAILED);
            }
        }
        //套餐status 1-->0
        //无需判断可以，直接执行

        setmealMapper.update(setmeal);
    }
```

### 2、修改套餐

#### 1、Controller

```java
/**
     * 修改套餐
     * @param setmealDTO
     * @return
     */
    @PutMapping
    @ApiOperation("修改菜品")
    public Result update(@RequestBody  SetmealDTO setmealDTO){
        log.info("修改菜品:{}",setmealDTO);
        setmealService.update(setmealDTO);
        return Result.success();
    }
```

#### 2、Service

```java
/**
     * 修改套餐
     *
     * @param setmealDTO
     * @return
     */
    @Transactional
    public void update(SetmealDTO setmealDTO) {
        Setmeal setmeal = new Setmeal();
        BeanUtils.copyProperties(setmealDTO, setmeal);
        Long setmealId = setmeal.getId();

        setmealMapper.update(setmeal);

        //删除setmeal与Dish的对应关系
        setmealDishMapper.deleteBatch(Collections.singletonList(setmealId));

        //新增setmeal与Dish的对应关系
        List<SetmealDish> setmealDish = setmealDTO.getSetmealDishes();
        if (setmealDish != null && setmealDish.size() > 0) {
            //给这几个setmealDish的setmealId赋值
            setmealDish.forEach(iter -> iter.setSetmealId(setmealId));
            setmealDishMapper.insertBatch(setmealDish);
        }
    }
```
