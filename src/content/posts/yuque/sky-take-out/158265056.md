## 2、代码开发

### 1、清空购物车

#### 1、Controller

```java
/**
     * 根据用户id清空购物车的数据
     * @return
     */
    @DeleteMapping("/clean")
    @ApiOperation("根据用户id清空购物车的数据")
    public Result clean(){
        log.info("根据用户id清空购物车的数据");
        Long userId = BaseContext.getCurrentId();
        ShoppingCart shoppingCart = ShoppingCart.builder()
                .userId(userId)
                .build();
        shoppingCartService.clean(shoppingCart);

        return Result.success();
    }
```

#### 2、Service

```java
 /**
     * 根据用户id清空购物车的数据
     * @return
     */
    @Override
    public void clean(ShoppingCart shoppingCart) {
       shoppingCartMapper.clean(shoppingCart);

    }
```

#### 3、Mapper

```java
/**
     * 根据用户id清空购物车的数据
     * @return
     */
    @Delete("delete from shopping_cart where user_id = #{userId}")
    void clean(ShoppingCart shoppingCart);
```
