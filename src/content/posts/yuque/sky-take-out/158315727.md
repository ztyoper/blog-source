### 2、接口设计

> 接口设计（共涉及到1个接口）：
> - 用户下单

#### 1、用户下单

> 1. 根据订单提交界面，我们知道我们 `需要的参数` 大概有：
>    1. 收获地址簿的id
>    2. 是否立即送出（加上送出的时间，时间一般是下单时间的后一个小时）
>    3. 购物车中的内容（购物车商品信息：name, image等可放在 `订单明细` 中）
>    4. 打包费（可以自己算，一道菜一块钱打包）
>    5. 配送费
>    6. 合计金额
>    7. 备注
>    8. 餐具数量
>    9. 发票
> 2. 参考“饿了吗”我们还可以 `补充参数` ：
>    1. 用户的信息。这个可以使用地址簿id来查询用户的信息（赵先生， 手机号）
> 3. 返回的参数：
>    1. 返回订单的id。它作为 `唯一标识` ，前端如果还想对该订单做其他操作。其他操作可以把它作为参数传给后端。（这也是为什么每一个表都要设置一个唯一标识的原因。我们之前返回的地址簿信息。每一个地址都有地址id,这次用户下单就将地址id作为参数传回来了。我们也就能保存设置该订单的地址为id对应的地址。&lt;毕竟每一个用户都可能会有多个地址&gt;）
>    2. 支付剩余时间（微信已经给我们弄好了，前端调用对应端口就行），我们要返回一个下单时间。
>    3. 返回订单总金额
>    4. 返回一个用时间戳生成的订单号。没啥作用的订单号。

#### 2、数据库设计

> 我们要保存的`订单的信息`肯定包括完传入的参数。传入的参数都是需要的字段，需要保存在数据库中的。
> 其余还需要保存：
> 1. 订单的状态要保存（1待付款 2待接单 3已接单 4派送中 5已完成 6已取消）
> 2. 付款的时间要保存
> 3. 购物车中的内容（购物车商品信息：name, image等可放在 `订单明细` 中）
> `订单的明细`除了name, image，还有每一种菜品的份数，价格。因为订单明细保存的是该订单购物车的商品信息。于是订单：订单明细 = 1对多的关系。

#### 1、Controller

```java
@RestController
@Slf4j
@Api(tags = "C端用户的订单管理")
@RequestMapping("/user/order")
public class OrderController {
    @Autowired
    private OrderService orderService;

    /**
     * 用户下单
     * @return
     */
    @ApiOperation("用户下单")
    @PostMapping("/submit")
    public Result<OrderSubmitVO> submit(@RequestBody  OrdersSubmitDTO ordersSubmitDTO){
        log.info("用户下单:{}", ordersSubmitDTO);
        OrderSubmitVO orderSubmitVO = orderService.submit(ordersSubmitDTO);
        return Result.success(orderSubmitVO);
    }
}
```

#### 2、Service

```java
/**
     * 用户下单
     * @return
     */
    @Transactional
    public OrderSubmitVO submit(OrdersSubmitDTO ordersSubmitDTO) {
        //1、处理各种业务异常（地址簿为空、购物车数据为空）
        AddressBook addressBook = addressBookMapper.getById(ordersSubmitDTO.getAddressBookId());
        if (addressBook == null) {
            //1.1. 地址簿为空
            throw new OrderBusinessException(MessageConstant.ADDRESS_BOOK_IS_NULL);
        }

        Long userId = BaseContext.getCurrentId();
        ShoppingCart shoppingCart = ShoppingCart.builder()
                .userId(userId)
                .build();
        List<ShoppingCart> shoppingCartList = shoppingCartMapper.list(shoppingCart);
        if (shoppingCartList == null || shoppingCartList.size() <= 0) {
            //1.2. 购物车数据为空
            throw  new OrderBusinessException(MessageConstant.SHOPPING_CART_IS_NULL);
        }
        //2、向订单表插入1条数据
        Orders order = new Orders();
        BeanUtils.copyProperties(ordersSubmitDTO , order);
        order.setNumber(String.valueOf(System.currentTimeMillis()));
        order.setStatus(Orders.PENDING_PAYMENT);
        order.setUserId(userId);
        order.setOrderTime(LocalDateTime.now());
        order.setPayStatus(Orders.UN_PAID);
        order.setUserName(userMapper.getById(userId).getName());
        order.setPhone(addressBook.getPhone());
        order.setAddress(addressBook.getDetail());
        order.setConsignee(addressBook.getConsignee());

        //添加order
        orderMapper.insert(order);
        //3、向订单明细表插入n条数据
        List<OrderDetail> orderDetailList = new ArrayList<>();
        for(ShoppingCart shopCart : shoppingCartList){
            OrderDetail orderDetail = new OrderDetail();
            BeanUtils.copyProperties(shopCart, orderDetail);
            orderDetail.setOrderId(order.getId());
            orderDetailList.add(orderDetail);
        }
        orderMapper.insertBatch(orderDetailList);
        //4、清空当前用户的购物车数据
        shoppingCartMapper.clean(shoppingCart);
        //5、封装VO返回结果
        OrderSubmitVO orderSubmitVO = new OrderSubmitVO();
        orderSubmitVO.setId(order.getId());
        orderSubmitVO.setOrderTime(LocalDateTime.now());
        orderSubmitVO.setOrderNumber(order.getNumber());
        orderSubmitVO.setOrderAmount(order.getAmount());
        return orderSubmitVO;
    }
```

#### 3、Mapper

```java
@Mapper
public interface OrderMapper {
    /**
     * 插入用户的订单
     * @param order
     */
    @Insert("insert into orders (number, user_id, address_book_id, order_time, checkout_time, amount, remark, phone, address, user_name, consignee, cancel_reason, rejection_reason, cancel_time, estimated_delivery_time, delivery_time, pack_amount, tableware_number)" +
            "values" +
            "(#{number}, #{userId}, #{addressBookId}, #{orderTime},null,#{amount},#{remark},#{phone},#{address},#{userName},#{consignee},null,null,null,#{estimatedDeliveryTime},null,#{packAmount},#{tablewareNumber} )")
    @Options(useGeneratedKeys = true,keyProperty = "id")
    void insert(Orders order);

    /**
     * 批量导入OrderDetails
     * @param orderDetailList
     */
    void insertBatch(List<OrderDetail> orderDetailList);
}
```
