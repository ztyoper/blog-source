## 2、代码开发

### 1、Controller

```java
/**
     * 启售，停售菜品
     * @param status
     * @param id
     * @return
     */
    @PostMapping("/status/{status}")
    @ApiOperation("启售，停售菜品")
    public Result startOrStopDish(@PathVariable Integer status , Long id ){
        log.info("启售，停售菜品:{},{}",status , id);
        dishService.startOrStopDish(status, id);
        return Result.success();
    }
```

1. id是拼接到url上的请求参数，没有body，就算有body,也不会理会。

### 2、Service

```java
/**
     * 启售，停售菜品
     * @param status
     * @param id
     * @return
     */
    @Override
    public void startOrStopDish(Integer status, Long id) {
        //update dish set status = ? where id = ?
        Dish dish = Dish.builder()
                .status(status)
                .id(id)
                .build();

        dishMapper.update(dish);
    }
```

### 3、Mapper

```java
    /**
     * 修改菜品
     * @param dish
     */
    @AutoFill(value = OperationType.UPDATE)
    void update(Dish dish);
```

## 3、功能测试

> 功能测试方式：

> 2. 通过前后端联调测试(前端还没有写好接口时，该种测试无法执行)
> 3. 注意：由于开发阶段前端和后端是并行开发的，后端完成某个功能后，此时前端对应的功能可能还没有开发完成，导致无法进行前后端联调测试。所以在开发阶段，后端测试主要以接口文档测试为主。
