# Redis常用命令

## 1、字符串操作命令

Redis字符串类型常用命令：

1. set

```sql
set key value  设置指定key的值 多次执行可以覆盖key 返回OK
set num 1
set num 2 
结果 2
```

```sql
get num 返回key对应的value 2
```

```sql
setex key seconds value  设置指定key的值，并将key的过期时间设为seconds秒 多次执行可以覆盖key 返回OK
全称 set with expiration

TTL : time to live 还剩多少时间存活
```

```sql
setnx num 3 设置指定key的值 多次执行不可以覆盖key 返回： key不存在时返回 1  key存在时返回 0
```
