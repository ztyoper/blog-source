## 2、代码开发

### 1、Controller

```java
/**
     * 批量删除菜品
     * @param dishIds
     * @return
     */
    @DeleteMapping
    @ApiOperation("删除菜品")
    public Result delete(@RequestParam("ids") List<Long> dishIds){//接收1,2,3
        log.info("开始删除菜品：{}", dishIds);
        dishService.deleteBatch(dishIds);
        return Result.success();
    }
```

1. GetMapping不能使用@RequestBody来获取参数。因为参数不是在请求体中。而是拼接到url中。

### 2、Service

```java
/**
     * 批量删除菜品
     *
     * @param dishIds
     * @return
     */
    @Override
    @Transactional
    public void deleteBatch(List<Long> dishIds) {
        //判断菜品是否正在启售。（status == 1?）
        List<Integer> statuses = dishMapper.queryStatusByDishIds(dishIds);

        for (int status : statuses) {
            if (status == StatusConstant.ENABLE) {
                throw new DeletionNotAllowedException(MessageConstant.DISH_ON_SALE);
            }
        }
        //判断菜品是否管理套餐
        List<Long> setmealIds = setmealMapper.querySetmealIdsByDishIds(dishIds);
        if (setmealIds != null && setmealIds.size() > 0) {
            throw new DeletionNotAllowedException(MessageConstant.CATEGORY_BE_RELATED_BY_SETMEAL);
        }
        //删除菜品
        dishMapper.deleteBatch(dishIds);

        //删除菜品关联的几种口味
        dishFlavorMapper.deleteFlavorsByDishIds(dishIds);

    }
```
