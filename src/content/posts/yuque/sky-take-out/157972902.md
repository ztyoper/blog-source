# 公共字段自动填充

## 1、问题分析

![tmpD987.png](https://pub-ccd5622eabb54b4a81678003778ddce1.r2.dev/PicGo/b34155d04dbfc8ecbbee3c2638907cab2783e1a4c18466d185816b85b6da6055.png)

1. 每一个表都有公共的字段，而这些字段的初始化有都是相似的。例如：employee表和category表的 `create_user、update_user、create_time、update_time` 都会如上图，经过这些初始化。我们的工作就是抽取出来用 `切面` 进行初始化。

## 2、实现思路

![tmpB685.png](https://pub-ccd5622eabb54b4a81678003778ddce1.r2.dev/PicGo/75c2602797596addf4f1ab5b52996624260a84991323d8d3464da79e5eb5e4a1.png)

1. `create_user、create_time` 涉及的操作数据库的 `mapper` 方法是 `insert`
2. `update_user、update_time` 涉及的操作数据库的 `mapper` 方法是 `insert` 和 `update`
3. 自定义枚举类OperationType来判断涉及的操作数据库的 `mapper` 方法是 `insert` 还是 `update` 哪种类型

### 1、自定义注解AutoFill

> 自定义注解AutoFill，用于标识需要进行公共字段自动填充的方法

```java
@Target(ElementType.METHOD)//只能定义在方法上
@Retention(RetentionPolicy.RUNTIME)//固定写法，运行时生效
public @interface AutoFill {
    OperationType value();// 定义一个属性，类型是我们自定义的枚举类
}
```

### 2、自定义切面类AutoFillAspect

> 自定义切面类AutoFillAspect,统一拦截加入了AutoFill注解的方法，通过反射为公共字段赋值

```java
package com.sky.aspect;
@Aspect
@Component
@Slf4j
public class AutoFillAspect {
    //切入点是mapper下所有类的所有方法(所有参数) 并且 标注了注解AutoFill
    @Pointcut("execution(* com.sky.mapper.*.*(..)) && @annotation(com.sky.annotation.AutoFill)")
    public void autoFillPointCut(){}

    /**
     * 前置通知，在通知中进行公共字段的赋值
     * @param joinPoint
     */
    @Before("autoFillPointCut()")
    public void autoFill(JoinPoint joinPoint){
        log.info("进入切入点函数的前置通知...");
        //获取到当前被拦截方法上的数据库操作类型， insert 还是 update
        //signature.getMethod()是”切入点方法“对应的切入的方法
        MethodSignature signature = (MethodSignature) joinPoint.getSignature();
        AutoFill autoFill = signature.getMethod().getAnnotation(AutoFill.class);
        OperationType value = autoFill.value();

        //获取到当前被拦截的方法的参数
        Object[] args = joinPoint.getArgs();
        Object obj = args[0];//我们约定第一个参数一定是Employee employee 或者 Category category

        //准备赋值的数据
        LocalDateTime now = LocalDateTime.now();
        Long currentId = BaseContext.getCurrentId();
        //根据当前不同的操作类型，为对应的属性通过反射来赋值

        try {
            if(value == OperationType.INSERT){
                Method setCreateTime = obj.getClass().getMethod(AutoFillConstant.SET_CREATE_TIME, LocalDateTime.class);
                Method setCreatUser = obj.getClass().getMethod(AutoFillConstant.SET_CREATE_USER, Long.class);
                Method setUpdateTime = obj.getClass().getMethod(AutoFillConstant.SET_UPDATE_TIME, LocalDateTime.class);
                Method setUpdateUser = obj.getClass().getMethod(AutoFillConstant.SET_UPDATE_USER, Long.class);

                setCreatUser.invoke(obj,currentId);
                setCreateTime.invoke(obj, now);
                setUpdateTime.invoke(obj, now);
                setUpdateUser.invoke(obj, currentId);

            }else if(value == OperationType.UPDATE){
                Method setUpdateTime = obj.getClass().getMethod(AutoFillConstant.SET_UPDATE_TIME, LocalDateTime.class);
                Method setUpdateUser = obj.getClass().getMethod(AutoFillConstant.SET_UPDATE_USER, Long.class);

                setUpdateTime.invoke(obj, now);
                setUpdateUser.invoke(obj, currentId);
            }
        } catch (Exception e) {
            e.printStackTrace();
        }
    }
}
```

### 3、Mapper的方法上加入AutoFill注解

```java
@Mapper
public interface EmployeeMapper {
    /**
     * 新增员工
     * @param
     * @return
     */
    @AutoFill(value = OperationType.INSERT)
    @Insert("insert into employee ( name, username, password, phone, sex, id_number, status, create_time, update_time, create_user, update_user )" +
            "values" +
            "(#{name}, #{username}, #{password},#{phone}, #{sex}, #{idNumber}, #{status}, #{createTime}, #{updateTime},#{createUser}, #{updateUser})")
    void insert(Employee employee);

    /**
     * 启用或者禁用员工
     * @param status
     * @param id
     * @return
     */
    @AutoFill(value = OperationType.UPDATE)
    void update(Employee employee);

}
```

其他mapper方法也是一样的。所以对于`create_user、update_user、create_time、update_time`方法的初始化都用@AutoFill注解解决。
