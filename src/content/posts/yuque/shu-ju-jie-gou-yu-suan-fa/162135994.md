### 试题一：LCM、GCD【编程题】

> 48与18的GCD:
> $$
> \begin{align}
> & 48 \div 18 = 2 ....12 \newline
> & 18 \div 12 = 1 ....6 \newline
> & 12 \div \ \ 6 = 2 ....0 \newline
> \end{align}
> $$
> 48与18的LCM:
> $LCM(a, b) = \frac{a \times b}{GCD(a, b)}$

```java
    //求ab之间的最大公约数，辗转相除法
    static int gcd(int a,int b){
        return b == 0 ? a : gcd(b,a % b);//没有问题，不用比较大小
    }
    // 第二种写法
    static int gcd(int a, int b){
        while(b!= 0){
            int temp = b;
            b = a % b;
            a = temp;
        }
        return a;
    }
    //求ab之间的最小公倍数
    static int lcm(int a,int b){
        return a * b / gcd(a,b);
    }
```

```java
public class qmi {

     * 不用快速幂求 2 ^100 % 1000
     */
    public static void power(int a, int b , int m){
        long start  = System.currentTimeMillis();
        long ans = 1L;
        while(b> 0){
            ans = ans * a;
            ans = ans % m;
            b--;
        }
        long end = System.currentTimeMillis();
        System.out.println(ans%m + "耗时： " + (end -start));

    }

    /**
     * 第一次优化，快速幂的初次使用
     * @param a
     * @param b
     * @param m
     */
    public static void qmi(int a, int b , int m){
        long start  = System.currentTimeMillis();
        long  ans = 1L;
        while (b > 0) {
            if (b % 2 == 0) {
                //如果指数为偶数
                b = b / 2;//把指数缩小为一半
                a = a * a % 1000;//底数变大成原来的平方
            } else {
                //如果指数为奇数
                b = b - 1;//把指数减去1，使其变成一个偶数
                ans = ans * a % 1000;//此时记得要把指数为奇数时分离出来的底数的一次方收集好
                b = b / 2;//此时指数为偶数，可以继续执行操作
                a = a * a % 1000;
            }
        }
        long end = System.currentTimeMillis();
        System.out.println(ans%m + "耗时： " + (end -start));

    }
    /**
     * 第二次优化，指令优化
     * @param a
     * @param b
     * @param m
     */
    public static void qmi(int a, int b , int m){
        long start  = System.currentTimeMillis();
        long  ans = 1L;
        while (b > 0) {
            if ((b & 1) == 1) {
                //如果指数为奇数
                // b = b - 1;//把指数减去1，使其变成一个偶数
                ans = ans * a % 1000;//此时记得要把指数为奇数时分离出来的底数的一次方收集好
            }
                b = b >> 1;//此时指数为偶数，可以继续执行操作,， b>>1就可以不用b = b - 1;了
                a = a * a % 1000;
        }
        long end = System.currentTimeMillis();
        System.out.println(ans%m + "耗时： " + (end -start));
```

### 试题三：唯一分解定理【编程题】

> **质因数分解定理**是唯一分解定理在自然数领域的具体应用，而唯一分解定理则是一个更一般性的数论定理，适用范围更广，不仅仅局限于自然数的质因数分解。在整数环等更一般的数学结构中，唯一分解定理描述了类似于质因数分解的唯一性分解性质。

> 时间限制: 1.0s 内存限制: 512.0MB 本题总分： 10 分

**<span style="color: var(--cm-text-color-regular)">【问题描述】</span>**

> 题意：唯一分解定理指的是：对于任意一个&gt;1的正整数，都可以以唯一的一种方式分解为若千质因数的乘积。
> $x = p_1^{k_1} * p_2^{k_2}* \dots * p_m^{k_m}$这个式子中的**p1,p2**是类似**2,3,5,7**这样的质数。
> 将单个数字进行质因数方法是，从小到大枚举**x**的所有可能的质因子，最大枚举到**sqrt（x）像 9 就只需要找到 3 之前的因子就行，n/2 是初始版本，这是优化版本**,每遇到一个可以整除的数字i，就不断进行除法直到除尽。最后如果还有**x&gt;1**,说明还有一个较大的质因子。

**<span style="color: var(--cm-text-color-regular)">【思路分析】</span>**

> 通过某个数字的唯一分解【质因数分解】：$x = p_1^{k_1} * p_2^{k_2}* \dots * p_2^{k_m}$我们可以求出x的约数（因数）个数。
> 例如:$36 = 2^2 * 3^3$$2^2有约数2^0,2^1,2^2也就是（1 ，2， 4）$$3^2有约数3^0,3^1,3^2也就是（1 ，3， 9）$
> (1，2，4) * （1，3，9）= 1，3，9，2，6，18，4，12，36共9个约数，因此36有9个正约数。

```java
/**
 * @author ztyOperation
 * @create 2023-05-12 16:11
 * 100的阶乘的所有约数
 */
public class Factorial {
    public static void main(String[] args) {
        new Factorial().run();
    }
    void run(){
        int[] arr = new int[101];
        for(int i = 2 ; i<=100; i++){
            int n = i;//把阶乘的每一项都提出来，分别找出每一项的所有质因数
            for(int j = 2; j*j<=n; j++){//一个数的约数的平方小于等于该数
                while(n % j == 0){
                    arr[j]++;//arr[11] = 3 表示有三个质因数 11
                    n/=j;
                }
            }
            //整除完了后如果剩下的n不为1，则当前的n为因子,例如 n== 5时，5是质数，因此没有因子，直接将arr[5]++即可，因为我们是找出阶乘的每一项
            if(n>1){
                arr[n]++;
            }
        }
        long res = 1;
        for(int i = 2,len = arr.length; i<len; i++){
            res = res * (arr[i] + 1);
        }
        System.out.println(res);
    }

}
```

### 试题五：欧拉降幂【编程题】

> 时间限制: 1.0s 内存限制: 512.0MB 本题总分： 10 分

**<span style="color: var(--cm-text-color-regular)">【问题描述】</span>**

> 题意：定义$F(n)=\textstyle \prod_1^n {i}，给定n,m，求n^{F_m}对1e9+7取模后的值$

**<span style="color: var(--cm-text-color-regular)">【输入格式】</span>**

> 输入共一行，包含两个整数n，m。

**<span style="color: var(--cm-text-color-regular)">【输出格式】</span>**

> 输出共一行，表示答案

**<span style="color: var(--cm-text-color-regular)">【样例输入】</span>**

**<span style="color: var(--cm-text-color-regular)">【样例输出】</span>**

**<span style="color: var(--cm-text-color-regular)">【评测用例规模与约定】</span>**

> <span style="color: var(--cm-text-color-regular)">对于 100 %的评测用例，</span>$1 \le n \le 10^9 , 1 \le m \le 10^6$

**<span style="color: var(--cm-text-color-regular)">【思路分析】</span>**

> 1. 首先要知道欧拉函数
>    $\varphi (n)$
>    , 它表示小于等于n中并且与n互质的数的个数。
>    1. $\varphi(n) = n (1-\frac{1}{p_1})(1-\frac{1}{p_2})(1-\frac{1}{p_3})...(1-\frac{1}{p_m})$
>       $p_1\sim p_m$
>       是对n进行唯一分解之后的质因子。该公式不用理解，直接用
> 2. 互质：两个数的最大公约数是1， 比如， 2 3 或 2 5 或 5 8
> 3. 质数：只有1 和 自己两个因子的数，比方是2 3 5 7 11 13
> 4. 质因子：一个数的因子（除数）中是质数的因子。换句话说，如果一个数可以被另一个数整除，而这个除数是一个质数，那么这个质数就是原数的质因子。例如，对于数字12来说，它的因子有1、2、3、4、6、12，其中2和3是质数，因此12的质因子是2和3。

**单点欧拉函数解法：**

> 这个程序是求单点欧拉函数，即求phi(n)，这个n范围一般是1～1e9，我们利用类似唯一分解的框架去枚举所有质因子按照之前的计算公式去计算即可。后面学习线性筛法后可以筛除一段区间内的所有数字的欧拉函数（例如1～1e7的所有数字的欧拉函数）。
> <span style="color: rgb(36, 41, 47)">与16互质的数是：1, 3, 5, 7, 9, 11, 13, 15。共8个</span>
> <span style="color: rgb(36, 41, 47)">质数的phi(n) = n-1 ， n与n不互质。1与任何数都互质</span>

```java
import java.util.Scanner;

public class Main {
	//这道题只能使用欧拉降幂，不然直接快速幂，幂太大了会溢出然后答案错误
	public static void main(String[] args) {
		// TODO Auto-generated method stub
		Scanner scan = new Scanner(System.in);
		// 在此输入您的代码...
		long n = scan.nextInt();
		long m = scan.nextInt();
		long c = 1000000007; //科学计数法是double类型的，需要转换为long太麻烦，直接定义long的mod值
		// jiechen后面其实也可以不用 + phi(c)因为不管n是多少，n和c一定互质。
		System.out.print(qmi(n, jiechen(m, phi(c)) + phi(c), c));
		scan.close();
	}

	private static long phi(long c) {
		long ans = c;
		for (int i = 2; i * i <= c; i++) {
			if (c % i == 0) {
				// 不能写成 ans = ans * (1 - 1 / i)，i过大时 1 / i可能会等于0
				ans = ans * (i - 1) / i;
				while (c % i == 0)
					c /= i;
			}
		}
		if (c > 1)
			ans = ans * (c - 1) / c;
		// n是质数,因此这里其实可以直接return n - 1;
		return ans;
	}

	private static long jiechen(long m, long mod) {
		long res = 1;
		while (m > 0) {
			res = res * m % mod;
			m--;
		}
		return res;
	}

	private static long qmi(long a, long b, long mod) {
		long ans = 1;
		while (b > 0) {
			if ((b & 1) == 1) {
				ans = ans * a % mod;
				b--;
			}
			a = a * a % mod;
			b >>= 1;
		}
		return ans;
	}

}
```

**补充：**

> **同余定理**：如果两个整数 a 和 b 满足 a ≡ b (mod m)，即 a 与 b 对模 m 同余，那么它们在模 m 下的余数相等。
> 同余定理具有以下性质：
> 反身性：a ≡ a (mod m)，任意整数 a 对于任意模 m 都满足自己与自己同余。
> 对称性：如果 a ≡ b (mod m)，则 b ≡ a (mod m)，即同余关系是对称的。
> 传递性：如果 a ≡ b (mod m) 且 b ≡ c (mod m)，则 a ≡ c (mod m)，即同余关系是传递的。
> **加法性质**：(a + b) % m = ((a % m) + (b % m)) % m。即两个数相加后再取余，结果等于分别对这两个数取余后再相加再取余。
> **减法性质**：(a - b) % m = ((a % m) - (b % m) + m) % m。即两个数相减后再取余，结果等于分别对这两个数取余后再相减再加上模数再取余。这里不可以省略括号里面的**加m！（a-b）%m =(a % m) - (b % m)) % m必须要满足 -1 % 3 = 2这样的性质，然而java和c++中都是结果为-1。**但(a - b - c) % m 时，就变为了( a % m - b % m + m - c % m + m) % m 每多一个符号`-`，就要叫一个m，这里的m是不能省略的。
> **乘法性质**：(a * b) % m = ((a % m) * (b % m)) % m。即两个数相乘后再取余，结果等于分别对这两个数取余后再相乘再取余。
> **指数性质**：(a^b) % m = ((a % m)^b) % m。即一个数的指数次幂再取余，结果等于这个数对模数取余后的指数次幂再取余。
> java,c++中正数mod y 等于正数， 负数mod y 等于负数，总之一个数mod y在 【-y+1, y-1】之间。我们要让其恒大于等于0，我们就 （x % y + y） % y 也就是【-y+1 + y , y-1 + y】 % y = 【1 ，y-1】之间。
> (2y -1) % y = (2y % y - 1 % y + y) % y = (0 -1 + y) % y = y-1

### 试题六：费马小定理【编程题】

> 费马小定理：若p为质数，且gcd(a,p)=1,则有$a^{p-1} \equiv 1 \pmod p$
> 因为p是一个质数，所以对于任意的&lt;p的正整数a,都有gcd(a,p) = 1即a、p必然互质。
> 一般来讲题目给的模数都是一个质数，从而满足费马小定理，可以使用费马小定理来求逆元

### 试题十：排列组合【编程题】

> 题目：机器人的选法总数

> 时间限制: 1.0s 内存限制: 512.0MB 本题总分： 10 分

**<span style="color: var(--cm-text-color-regular)">【问题描述】</span>**

> 题意：小蓝买了n种机器人，每种机器人各一个。他要选择一个或多个机器人来组成机甲战队。然而，她讨厌两个数字a和b，因此机甲战队中的机器人数量不能为a或b。请问他可以组成多少不同组合的机甲战队，当两个机甲战队中存在一个机器人在一个机甲战队中被使用而在另一个机甲战队中没有被使用时，这两个机甲战队被认为是不同的。

**<span style="color: var(--cm-text-color-regular)">【输入格式】</span>**

> 输入一行3个整数n,a,b。
> 数据范围保证：$2\le n \le 10^9, 1\le a \le b \le min(n,2 \times 10^5)$

**<span style="color: var(--cm-text-color-regular)">【输出格式】</span>**

> 输出一个整数表示答案，答案需要对10^9十7取模。

**<span style="color: var(--cm-text-color-regular)">【样例输入】</span>**

> 4 1 3

**<span style="color: var(--cm-text-color-regular)">【样例输出】</span>**

> 7

**<span style="color: var(--cm-text-color-regular)">【评测用例规模与约定】</span>**

> <span style="color: var(--cm-text-color-regular)">对于 100 %的评测用例， 无</span>

**【组合知识】**

> $$
> \begin{align}
> C_n^m = \frac{n \times (n-1) \times (n-2) \times \dots \times (n-m+1)}
> {m \times (m-1) \times (m-2) \times \dots \times 1}
> = \frac{n!}{(n-m)!m!}
> \end{align}
> $$
> $C_n^0 + C_n^1 + C_n^2 + \dots + C_n^n = 2^n \quad A_n^n = n!$
> 方法一：n类东西，每类都有选中或不选中两种状态，所以最终是2^n
> 方法二：$(x+1)^n = C_n^0 + C_n^1 * x + C_n^2 * x^2 + \dots + C_n^n * x^n \quad 当x = 1时可以得到上式$
> $C_n^m = C_{n-1}^m + C_{n-1}^{m-1}$
> n个数中取m个数，如果第m个数不被取到的话：$C_{n-1}^m$
> n个数中取m个数，如果第m个要被取到的话：$C_{n-1}^{m-1}$

**<span style="color: var(--cm-text-color-regular)">【思路分析】</span>**

> 0个或多个机器人：$C_n^0 + C_n^1 + C_n^2 + \dots + C_n^n = 2^n$
> 一个及以上：$减去C_n^0$
> 不选总数为a或者b：$减去C_n^a \quad 减去C_n^b$
> 最终：$2^n - C_n^0 - C_n^a - C_n^b$
> **减法性质**：(a - b) % m = ((a % m) - (b % m) + m) % m。即两个数相减后再取余，结果等于分别对这两个数取余后再相减再加上模数再取余。这里可以省略括号里面的**加m。**但(a - b - c) % m 时，就变为了( a % m - b % m + m - c % m + m) % m 每多一个符号`-`，就要叫一个m，这里的m是不能省略的。

```java
package test;

import java.util.ArrayList;
import java.util.List;
import java.util.Scanner;

public class Test {
	static Scanner scanner = new Scanner(System.in);
	static long p = (long)1e9 +7;
	public static void main(String[] args) {
		
		long n = scanner.nextLong();
		long a = scanner.nextLong();
		long b = scanner.nextLong();
		
//		[2^n - c(n,a) - c(n,b) - 1] % p
		long ans = qmi(2,n) - c(n,a) + p - c(n,b) + p - 1 + p;
		System.out.println(ans % p);
		
	}
	public static long c(long n, long m) {
		long ans = 1L;
		for(long i = n ; i>=n-m+1; i--) {
			ans = ans * i % p;
		}
		for(long i = 1; i<=m; i++) {
			
			//如果使用公式，就必须算出n!/(n-m)!m!的值然后取模，但是会溢出。
			//乘分数容易有误差，我们这里使用逆元进行取模运算
			ans = ans * qmi(i, p - 2 ) % p;
		}
		return ans;
	}

		while(b>0) {

			a = a*a%p;
			b>>=1;
		}
		return ans;
```

> 补充：
> 在模 P 算术下，各运算的等效形式如下（假定运算均在整数范围内，P 为正整数）：
> - **和** ：
>    $((A + B) \bmod P \equiv \big[(A \bmod P) + (B \bmod P)\big] \bmod P)$
> - **差** ：
>    $((A - B) \bmod P \equiv \big[(A \bmod P) - (B \bmod P) + P\big] \bmod P)$
>    （加 P 是为了避免负数取模歧义）
> - **积** ：
>    $((A \times B) \bmod P \equiv \big[(A \bmod P) \times (B \bmod P)\big] \bmod P)$
> - **商** ：
>    $((A \div B) \bmod P)$
>    等价于
>    $(A \times B^{-1} \bmod P)，其中 B^{-1}$
>    是 B 在模 P 下的 **乘法逆元** （满足
>    $(B \times B^{-1} \equiv 1 \pmod P)$
>    。此等式仅在 B 与 P **互质** 时成立（特别地，当 P 为素数且
>    $(B \not\equiv 0 \pmod P)$
>    时始终成立）。
> 当我说“特别地，当 (P) 为素数且$(B \not\equiv 0 \pmod P)$时始终成立”，是在解释**除法取模的一个关键前提**。
> 简单来说：
> - **一般情况下** ：要用“乘以逆元”代替除法，必须满足 **除数** **(** **B** **)** **和模数** **(** **P** **)** **互质** （最大公约数为1）。
> - **如果 (P) 是素数** ：只要 (B) 不是 (P) 的倍数（即
>    $(B \bmod P \neq 0)）$
>    ，它就 **自动** 与 (P) 互质，逆元一定存在。
> **所以这句话的潜台词是：**在算法竞赛和密码学中，**模数常取大素数**（如`1e9+7`），正是为了确保除法（乘以逆元）在绝大多数情况下都能顺利进行，不需要单独判断互质性。

### 试题十二：裴蜀定理【编程题】

> ![image.png](https://pub-ccd5622eabb54b4a81678003778ddce1.r2.dev/PicGo/a7d0f22a9a68854635cf48c3a563cc1fef5dd707faa25cb8c3724296dc838522.png)

【思路分析】

> 使用裴蜀定理来解决，裴蜀定理的定义：
> `gcd(a, b) = d的话，就存在两个整数参数x,y使 ax + by = d(或者d的倍数)`
> 拓展`gcd(a1,a2,,,an) = d的话，就存在n个整数参数x1,x2,,,xn使 a1x1 + a2x2+..+ anxn = d(或者d的倍数)`
> 下面是数学归纳法求解n项的时候：
> ![tmp76D7.png](https://pub-ccd5622eabb54b4a81678003778ddce1.r2.dev/PicGo/24846324ae7a9940006f88c48a08e01b70017ca6e3397a55968a0b9f84906d62.png)
> 当我们找到 a1x1 + a2x2+..+ anxn = d时，我们只能凑出d或d的整数，其他的数凑不出来。但如果我们选的n个数它们的公约数是 1 的话，就可以凑出1或1的倍数，也就是所有正整数，因此这道题就转化为找到能构成公约数为1的n个的代价为最小。这样就是背包问题（一个数选择还是不选择）。![069da328be73dfb756b8f5e808e5dd2c.jpg](https://pub-ccd5622eabb54b4a81678003778ddce1.r2.dev/PicGo/8055d72e0d341fa454bc63b9948763e6479096e217230642beb21c7d5e8a682b.jpg)
> 因为第二维度j作为前i个数的最大公约数在取值上是0_10∧9，但这个范围不是连续的(中间可能出现前i个数，不可能出现的最大公约数，因此我们使用map来降低空间使用)，而是在前i个数每一个ai的约数中去找。已知1e9的约数个数为1344个左右，2e9的约数个数为1500个左右，Integer.MAX_VALUE的约数个数为1600个左右，总共有300个ai，因此可能取到的最大公约数个数是绝对小于300*1344=4*1e5个的(去重后可能还更少，而且每个ai不一定有1344个约数，而且我们使用map来遍历不会遍历没有改最大公约数的情况)，因此我们的时间复杂度是小于300*300*1344=1.2*1e8的。1s能解决。

```java
import java.io.BufferedInputStream;
import java.io.BufferedReader;
import java.io.IOException;
import java.io.InputStreamReader;
import java.io.StreamTokenizer;
import java.util.HashMap;
import java.util.Map;
import java.util.Map.Entry;
import java.util.Set;

public class Main {
	static int n;
	static int[] a;
	static int[] b;
	// 将map看成<第二维度, 存储的结果>就行，我们之前使用二维Dp第二维度是0~N连续的。共N个。
	// 现在这道题第二维度数值最大取到10^9，但是共300 * 1344多个。因此我们使用map来存储
	static Map<Integer, Integer>[] f;

	public static void main(String[] args) throws IOException {
		n = nextInt();
		a = new int[n + 1];
		b = new int[n + 1];
		f = new HashMap[n + 1];
		for (int i = 0; i <= n; i++)
			f[i] = new HashMap<>();

		for (int i = 1; i <= n; i++)
			a[i] = nextInt();
		for (int i = 1; i <= n; i++)
			b[i] = nextInt();
		// 前0个数，当最大公约数为0时，代价也为0。也就是一个数都没取嘛。
		f[0].put(0, 0);
		for (int i = 0; i <= n; i++) {
			Set<Integer> keys = f[i].keySet();
			for (int j : keys) {
				int cost = f[i].get(j);
                //不选第 i+1 种
				f[i + 1].put(j, min(get(f[i + 1], j), cost));
				int d = gcd(j, a[i + 1]);
                //选第 i+1 种
				f[i + 1].put(d, min(get(f[i + 1], d), cost + b[i + 1]));
			}
		}
		//这就是第一种方式，但是不好求A,因为A可以是很多数
//		for (int i = 1; i <= n; i++) {
//			Set<Integer> keys = f[i].keySet();
//			for (int j : keys) {
//				int cost = f[i - 1].get(j);
//                //不选第 i 种
//				f[i].put(j, cost));
//				// j = gcd(A, a[i]); 不好得到A,这里面的A表示前i-1种中选择，然后得到公约数A，然后这个公约数A和ai的公约数必须为j
//                //选第 i 种
//				f[i].put(j, min(f[i].get(j), get(f[i - 1], A) + b[i]));
//			}
//		}
		Integer res = f[n].get(1);
		System.out.println(res == null ? -1 : res);

	}

	static int get(Map<Integer, Integer> map, int j) {
		if (map.containsKey(j))
			return map.get(j);
		else
			return Integer.MAX_VALUE;
	}

	static int gcd(int a, int b) {
		return b == 0 ? a : gcd(b, a % b);
	}

	static int min(int a, int b) {
		return a < b ? a : b;
	}

	static StreamTokenizer token = new StreamTokenizer(
			new BufferedReader(new InputStreamReader(new BufferedInputStream(System.in))));

	static int nextInt() throws IOException {
		token.nextToken();
		return (int) token.nval;
	}

}
```
