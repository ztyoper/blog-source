# 01字典树(01-trie)

> 01字典树（01-trie）是一种特殊的字典树，它的字符集只有(0,1),相对与字典树，就是二叉字典树，主要用来解决一些关于二进制上的问题，例如异或问题和孕集问题等。

### 试题一：<span style="color: rgb(34, 34, 38)">最大异或对</span>

> ![image.png](https://pub-ccd5622eabb54b4a81678003778ddce1.r2.dev/PicGo/cc2655c12e9783fbaea1906c47748832b6d31a8d042cc0dbf23c24d685246fd7.png)

【思路分析】

> 将数组中所有正整数的二进制表示，按照从高位到低位的顺序，当作字符串挂载在trie树上,然后贪心的走（因为二进制中高位的权值要大于地位，高位异或结果为1要大于所有低位异或结果为1的总和），每一次走跟当前位相反的一位就可以了。
> 根据上述思路，异或最小值就是将二进制反过来就行。
> 因为数大小为1e9也就是int整型，32位。也就是最多比较32次。然后总共有n个数。求得每个数的异或最大就是O(32n)。
> 暴力求解：双重for循环，n个数两两异或。O(n^2) = 4e8要超时。
> ![952429adaf651aebc445bf242da4a45d.jpg](https://pub-ccd5622eabb54b4a81678003778ddce1.r2.dev/PicGo/6fdb14968ebcedafcdac37c3309cef0576d1ee3f5ec96c2b10be24c9ab3d0667.jpg)

```java
import java.util.HashMap;
import java.util.Map;
import java.util.Scanner;

public class Main {
	static Scanner scanner = new Scanner(System.in);
	static class TreeNode{
		Map<Integer , TreeNode> map;
		int val = 0;
		public TreeNode() {
			this.map = new HashMap<>();
		}
	}
	static TreeNode root = new TreeNode();
	
	public static void insert(int num) {
		TreeNode node = root;
		for(int i = 31; i>=0; i--) {
			//每1二进制位进行与操作，直接最开始右移动31位
			//将该数的32位二进制逐个添加到字典树中（其实使用普通二叉树也行）
			int c = num >> i & 1;
			if(!node.map.containsKey(c)) {
				node.map.put(c, new TreeNode());
			}
			node = node.map.get(c);
		}
		node.val = num;
		
	}
	public static int getMax(int num) {
		TreeNode node = root;
		for(int i = 31; i>=0; i--) {
			//异或的性质：对应位不同得1，相同得0。因此 高位优先取反 能最大化结果。
            int c = num >> i & 1 ^ 1;   // 取反：期望走相反的位，这里感觉也能使用非运算，而不是异或运算
            if (node.map.containsKey(c)) {
                node = node.map.get(c); // 能走相反就走
            } else {
                node = node.map.get(1 ^ c); // 否则只能走相同位
            }
		}
		return node.val ^ num;
	}
	public static void main(String[] args) {
		int n = scanner.nextInt();
		int[] nums = new int[n];
		int max = 0;
		for(int i = 0; i<n; i++) {
			nums[i] = scanner.nextInt();
			insert(nums[i]);
		}
		for(int i = 0; i<n; i++) {
			max = Math.max(max, getMax(nums[i]));
		}
		System.out.println(max);
	}
}
```
