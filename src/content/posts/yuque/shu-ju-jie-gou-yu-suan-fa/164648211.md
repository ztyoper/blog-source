# 字典树(trie)

![tmpAE0C.png](https://pub-ccd5622eabb54b4a81678003778ddce1.r2.dev/PicGo/7a3a8d089da85ab37c958d463287e11e7fa3365ce7b0a6f9d638f86af527286e.png)

> 不管我们使用前缀和（字符串Hash）还是KMP都是线性查找时间。在乘以m,最终时间复杂度为O(n*m)
> 使用字典树先构造字典树（使用树形链表的形式存储n个字符串）然后在遍历字符串t。最终时间复杂度为O(n+m)
> 当然上述是字符串查找类型的题目。如果是n等于1，不管是在母字符串中查找t的出现位置或者次数。kmp和前缀和（字符串Hash）都可以做到O(n+m)，而字段树此时就不能完成了。比如"abcabcabc"中查找t="abc"出现的次数，就不能了。因为字典树是一条。但是出现位置我们可以通过结点的编号来找到。

![tmpEF5F.png](https://pub-ccd5622eabb54b4a81678003778ddce1.r2.dev/PicGo/c3aebf4548fce30437b71bffb46fcc3b44b1268ca4ffd6f61f3c003108f3d1fa.png)![tmp2B9.png](https://pub-ccd5622eabb54b4a81678003778ddce1.r2.dev/PicGo/93d1b2ff52d3dc7b3ec234df2678b83d1d69637210c5148c632efdddd6ba8d3d.png)

> 每个节点有两个属性。一个是map，如结点1：map('a',左子结点) map('c',右子结点) 。 其中 a,c 表示对于子结点的链路，另一个是cnt，左右子节点的 cnt 表示当前字符a或者c出现的次数。
> 我们的树形链表相当于是将字符串：aa , ab,ac ,ca, cbca , cbcb。提取共同部分然后保存到树中。这样查找特定字符串t的时候就可以直接查找出在这6个字符串中出现的次数。（如果t是“cbc”,9号结点的cnt=2,表示t出现了2次，但是我们这里不知道在这n个字符串中是哪两个字符串包含指定字符串t。这或许就是字典树的弊端。我们或许可以将cnt修改为列表list进行保存字符串编号，然后list.size就是出现次数。）

![image.png](https://pub-ccd5622eabb54b4a81678003778ddce1.r2.dev/PicGo/bd90e3468b34d6e1dc13d12e7de64d6f19a1fe0dd71b131bad97a03856edb27e.png)

> 如果当前字符串的字符不存在，这创建新的子结点。我们的字典树没有说是二叉的。可以是多叉的。

![image.png](https://pub-ccd5622eabb54b4a81678003778ddce1.r2.dev/PicGo/9ee24bd72c4ba30493310c93bebe0778f32e061260b15d950b2a83fc836b6b22.png)

> 该query是查找指定字符串t是否是这n个字符串的前缀的。如果是查找t出现在n个字符串中的次数，不是前缀的话，当t=abc，n个字符串又不是a开头，比如hcmabc的话，上述query函数就有问题。我们应该将循环设置为是否有下一个结点。然后用指针遍历字符串t,当字符串t被完整遍历后，则表示包含字符串t。若到null结点了，i还没有遍历完，则表示不包含字符串t。

### 试题一：前缀判定

> ![image.png](https://pub-ccd5622eabb54b4a81678003778ddce1.r2.dev/PicGo/3077a7e6d5897518c1808d3556273f6bbab5b7c1bb3393fac5d56d820fa449fe.png)

【思路分析】

> 如果使用kmp或者前缀和（字符串Hash）都是线性匹配时间。然后n个字符串。最终就是O(n*m) = 10^10要超时

```java
import java.util.HashMap;
import java.util.Map;
import java.util.Scanner;

public class Main {
	static Scanner scanner = new Scanner(System.in);
	static class TreeNode{
		Map<Character , TreeNode> map;
		int cnt;
		public TreeNode() {
			this.map = new HashMap<>();
			this.cnt = 0;
		}
	}
	static TreeNode root = new TreeNode();
	
	public static void insert(String s) {
		TreeNode node = root;
		for(int i = 0; i<s.length(); i++) {
			char c = s.charAt(i);
			if(!node.map.containsKey(c)) {
				node.map.put(c, new TreeNode());
			}
			node = node.map.get(c);
			//子结点的cnt次数++
			node.cnt++;
		}
	}
	//查找s字符串是否存在在字典树中
	//从头到尾的查找。
	public static boolean query(String s) {
		TreeNode node = root;
		for(int i = 0; i<s.length(); i++) {
			char c = s.charAt(i);
			if(!node.map.containsKey(c)) {
				return false;
			}
			node = node.map.get(c);
		}
		return node.cnt > 0;//其实也可以直接返回true。毕竟i遍历s字符串完全后，结点的cnt绝对是大于0的。
	}
	
	public static void main(String[] args) {
		int n = scanner.nextInt();
		int m = scanner.nextInt();
		String[] strs = new String[n];
		for(int i = 0; i<n; i++) {
			insert(scanner.next());
		}
		for(int i = 0; i<m; i++) {
			if(query(scanner.next())) {
				System.out.println("Y");
			}else {
				System.out.println("N");
			}
		}
	}
}
```
