## 单点修改，区间查询

### 区间和查询

> 使用树状数组 t 对原数组 a 进行前缀和维护。

> 暴力：单点修改O(1), 区间和查询O(n) , m次修改后，再来m次查询，最终O(n*m)
> 前缀和：单点修改O(n),区间和查询O(1)，m次修改后，再来m次查询，最终O(n*m)。适用于没有修改，或常数次修改，这样最终时间复杂度只有O(m)，m次查询。
> 树状数组：单点修改O(logN)，区间和查询O(logN)。m次修改后，再来m次查询，最终O(logN * m)

#### 树状数组初始化

##### 1、使用前缀和数组O(N）

> 优点：比使用add(x,k)方法的初始化要快，因为每次执行 t[i] = s[i] - s[i - (i & -i) ]的时间复杂度为O(1)
> - 开了前缀和数组s我们可以 **在原数组未修改** 之前来 **查询区间和** O(1)，但是当原数组 a 修改后，s数组又没有O(n)修改，此时就不能使用s数组了。因此，一般该s数组仅用于树状数组 t 的 **初始化** 。
> 缺点：这种方法需要开一个与原数组 a 相同长度的前缀和数组 s ，浪费空间。

```java
/**
 * [L,R]区间和查询 O(logN)
 *
 * @param L
 * @param R
 */
int query(int L, int R) {
    return ask(R) - ask(L - 1);
}

/**
 * 前x项和 O(logN)这是最坏情况，最好是O(1)直接查找到t[1] t[2] t[4] t[8]等
 *
 * @param x
 */
int ask(int x) {
    int sum = 0;
    //i-=lowbit(i)-->例如找到前6项和：t[6] + t[4] = t[6] lowbit(6) == 2是两项和，
    //t[6-lowbit(6)]是求剩余4项和
    for (int i = x; i > 0; i -= lowbit(i)) {
        //当i= 8or 4 or 2 or 1时，i-lowbit(i) = 0 而t[0] = 0
        sum += t[i];
    }
    return sum;
}
```

### 区间异或和查询

### 区间最值查询

> 使用树状数组 t 对原数组 a 进行前缀中最值维护。

#### 树状数组初始化O(N*logN)

> init()方法相比于update方式就是少了while循环，其他都没有改变。

```java
//该方法要在原数组 a 初始化时执行，并从最树底层开始初始化
//循环调用形式：init(i,a[i]);
static void init(int x, int w) {
    //给t[x]赋初值。最终一层for循环结果相当于t[x] = min{a[x],t[x]的所有子结点}
    t[x] = w; 
    int lx = x & -x; // lowbit(x)
    // 遍历所有子结点
    for (int i = 1; i < lx; i <<= 1) {
        t[x] = Math.min(t[x], t[x - i]);
    }
}
```

#### 区间最值查询O(logN)

> 暴力：单点修改O(1), 区间最值查询O(n) , m次修改后，再来m次查询，最终O(n*m)
> 前缀和维护不了区间最值：如果【1，3】上最大值是a[1] = 10000,那么根据前缀和方法，【1，10】上如果最大值也是10000,那么我们查找不了【4,10】上的最大值。
> 树状数组：单点修改O(logN*logN)【区间最值更新O(logN*logN)】，区间最值查询O(logN)。m次修改后，再来m次查询，最终O(logN*logN * m)

<span style="color: rgb(77, 77, 77)">设 ask(x,y)求区间 [x,y] 之间的最值， 已知 t[x] 表示 [x−lowbit(x)+1,x] 之间的最值，那如何求区间 [x,y] 的最值呢？</span>

![image.png](https://pub-ccd5622eabb54b4a81678003778ddce1.r2.dev/PicGo/cbe1a788d62d28d14ef544c23a92c05d2129cd1def2fc57a1237f28185d3838f.png)

我们不难发现:

- 如果求区间 [1,8] 的最值，就需要点 t[8]
- 如果求区间 [1,7] 的最值，就需要点 t[7],t[6],t[4]
- 如果求区间 [2,7] 的最值，就需要点 t[7],t[6],a[4],t[3],a[2]
- 如果求区间 [2,2] 的最值，就需要点 a[2]
- 如果求区间 [2,8] 的最值，就需要点 a[8],t[7],t[6],a[4],t[3],a[2]

```java
static int ask(int l, int r) {
    int ans = a[r];
    while (l <= r) {
        // t[r] 表示 [r−lowbit(r)+1,r] 之间的最值，lx作为左边界
        int lx = r - (r & -r) + 1;
        // lx>=l表示，t[r]都在要求的区间【L,R】之中。我们这里不用判断右边界。
        if (lx >= l) {
            ans = Math.max(ans, t[r]);
            r = lx - 1;
        } // r变为 r - lowbit(r)
        else {
            //lx左边界<l，因此我们先比较a[r]然后，然后r--让原数组过渡到下一个树状数组。如
            //查询【2,8】的最值，我们发现t[8]表示【1,8】的最值。我们先查询a[8]之后的查询交给t[7]
            ans = Math.max(ans, a[r]);
            r--;
        }
    }
    return ans;
}
```

#### 单点修改O(logN*logN)【区间最值更新O(logN*logN)】

树状数组<span style="color: rgb(77, 77, 77)">t[x] 保存着 [x−lowbit(x)+1,x] 之间的最值。当a[x]修改为w时：我们先有t[x] = a[x] = w;，为什么要修改t[x]，看后面有解释。</span>

![image.png](https://pub-ccd5622eabb54b4a81678003778ddce1.r2.dev/PicGo/cbe1a788d62d28d14ef544c23a92c05d2129cd1def2fc57a1237f28185d3838f.png)

我们不难发现，如果a[4]修改为w。a[4] = w ， t[4] = w后，我们要**两种**操作：**遍历所有子结点，修改包含该结点6的所有父节点的最值。**

1. 遍历子结点：看图，for循环结束：t[4]=maxOrMin { t[4], t[2], t[3] } =maxOrMin { w , t[2], t[3] }
2. 修改父结点：for循环结束：t[8] = maxOrMin { 更新后的t[4], t[6], t[7] }

就是这么奇妙。

**如何找父节点：**

- x += lowbit(x)

**如何找子结点：**

- x = 1000
- = 0100 + lowbit(0100) = 0100 + 100 = 0100 + 2^2
- = 0110 + lowbit(0110) = 0110 + 010 = 0110 + 2^1
- = 0111 + lowbit(0111) = 0111 + 001 = 0111 + 2^0
- 这里是lowbit(x) = lowbit(1000) = 2^3截止。不包括2^3。

> 若 x = 1010000
> = 1001000 + lowbit(1001000) = 1001000 + 1000 = 1001000 + 2^3
> = 1001100 + lowbit(1001100) = 1001100 + 100 = 1001100 + 2^2
> = 1001110 + lowbit(1001110) = 1001110 + 10 = 1001110 + 2^1
> = 1001111 + lowbit(1001111) = 1001111 + 1 = 1001111 + 2^0
> 从最小的1001000开始，每次往后面加1。子结点的个数为：lowbit(x)的二进制中0的位数。因此，修改的最坏复杂度为从t[1]修改到t[n],假若n = 32 = 100000。遍历次数总和：0 + 1 + 2 + 3 + 4 + 5 = 0 + 1 + 2 + ... +$log_2{32} = log_2{32}*(log_2{32}+1) / 2$。最终复杂度为O(logN^2),仍然比O(n)好很多

既然 x 可以通过子结点 + lowbit(子结点)得到。那么子结点 = x - lowbit(子结点)，而`lowbit(子结点)`就是`i`， for (int i = 1; i &lt; lowbit(x); i &lt;&lt;= 1)。我们这里遍历:

- i 可以等于 2^0,对应 t[x - i]就是 t[8-1] = t[7]
- i 可以等于 2^1,对应 t[x - i]就是 t[8-2] = t[6]
- i 可以等于 2^2,对应 t[x - i]就是 t[8-4] = t[4]

这个性质是树状数组用lowbit()方法来查询自己**所有子结点**的。和lowbit()公式一样记住！

```java
static void update(int x, int w) {
    t[i]=a[i]=w;//原数组也要跟着改变，求区间最大值要用
    while (x <= n) {// 遍x及其所有树上祖先进行修改
        t[x] = a[i];// 这个必须有。不然可能以前的最小值仍然存在。
        int lx = x & -x; // lowbit(x)
        // 遍历所有子结点
        for (int i = 1; i < lx; i <<= 1) {
            t[x] = Math.min(t[x], t[x - i]);
        }
        x += lx;
    }
}
```

```java
		m = nextInt();

		a = new int[n + 1];

				update(nextInt(), nextInt());

			}
		}

	}

		// 给t[x]赋初值。最终一层for循环结果相当于t[x] = min{a[x],t[x]的所有子结点}
		t[x] = w;

		int ans = a[r];

			// t[r] 表示 [r−lowbit(r)+1,r] 之间的最值
			int lx = r - (r & -r) + 1;

			if (lx >= l) {

				r--;
			}
```

## 区间修改，单点查询

> 【区间修改，单点查询】就没有那么多分类了。

> 使用树状数组 t 对原数组的**差分数组**d(diff) 进行前缀和维护。

> **暴力**：区间修改O(n), 单点查询O(1) , m次修改后，再来m次查询，最终O(n*m)
> **差分数组**：区间修改O(1), 单点查询O(n): 因为要**逆运算差分数组**来获取原数组 a 每一个元素的**增量**。因此是O(n)的时间复杂度。m次修改后，再来m次查询，最终O(n)。但倘若查询后，又修改，这时就**又要逆运算差分数组**来获取原数组 a 每一个元素的**增量**。如果出题人交替发出请求来卡你。这样最终时间复杂度可能是O(n*m)，m为**不连续**的查询次数。**连续就相当于只进行一次逆运算。**
> **树状数组**：区间修改O(logN)，单点查询O(logN)【我们通过**树状数组**来**逆运算**差分数组 d ，也就是求差分数组 d 的前缀和、原数组的每个元素的增量】。m次修改后，再来m次查询，最终O(logN * m)

#### 树状数组初始化O(1)

> 因为我们保证**逆运算**后的差分数组 d 是保存原数组 a**每一个元素**的**增量。**因此差分数组初始化为0，而树状数组又是维护差分数组的前缀和的，因此我们不用树状数组初**始化为0**就行。

#### 单点查询O(logN)

```java
/**
 * 前x项和 O(logN)这是最坏情况，最好是O(1)直接查找到t[1] t[2] t[4] t[8]等
 *
 * @param x
 */
int ask(int x) {
    int sum = 0;
    //i-=lowbit(i)-->例如找到前6项和：t[6] + t[4] = t[6] lowbit(6) == 2是两项和，
    //t[6-lowbit(6)]是求剩余4项和
    for (int i = x; i > 0; i -= lowbit(i)) {
        //当i= 8or 4 or 2 or 1时，i-lowbit(i) = 0 而t[0] = 0
        sum += t[i];
    }
    return sum;
}
```

## 区间修改，区间查询

区间和查询：

> **暴力**：区间修改O(n), 区间和查询O(n) , m次修改后，再来m次查询，最终O(n*m)
> **差分数组加前缀和数组**：区间修改O(1), 区间和查询O(1): 但如果区间修改更新差分数组的同时也要更新前缀和数组。这就是O(n)了。如果有多次更新每次都要维护前缀和数组。这样很麻烦。
> **单个树状数组**：区间修改O(logN)，区间查询O(N*logN)【我们通过**树状数组**来**逆运算**差分数组 d ，也就是求差分数组 d 的前缀和、原数组的每个元素的增量】。m次修改后，再来m次查询，最终O(N*logN * m)
> **两个树状数组：**区间修改O(logN)，区间查询O(logN)【一个树状数组用来维护差分数组 d 的前缀和，一个树状数组用来维护 i * d[ i]的前缀和。】
> 因为树状数组中维护的差分数组初始化为0，也就是逆运算后是原数组 a 的增量，因此需要在加一个前缀和数组进行对原数组 a 的区间和维护。在不修改的前提下，前缀和维护区间的和为O(1)大于树状数组O(logN)

#### 树状数组初始化O(1)

> 因为我们保证**逆运算**后的差分数组 d 是保存原数组 a**每一个元素**的**增量。**因此差分数组初始化为0，而树状数组又是维护差分数组的前缀和的，因此我们不用树状数组初**始化为0**就行。

#### 区间查询O(logN)

![image.png](https://pub-ccd5622eabb54b4a81678003778ddce1.r2.dev/PicGo/96ff71295984f69ccfdcd39483c7ce5a193b534827fb1320c5289e06a09d80d3.png)

```java
/**
查询区间[1,x]进行区间修改后的区间和
 */
static int ask(int x) {
    int sum = s[x];//第x项原数组 a 的前缀和。后面有解释原因。
    //i-=lowbit(i)-->例如找到前6项和：t[6] + t[4] = t[6] lowbit(6) == 2是两项和，
    //t[6-lowbit(6)]是求剩余4项和
    for (int i = x; i > 0; i -= lowbit(i)) {
        //当i= 8or 4 or 2 or 1时，i-lowbit(i) = 0 而t[0] = 0
        sum += (x + 1) * t1[i] - t2[x];
    }
    return sum;
}
// 查询区间[l,r]进行区间修改后的区间和
static int real_ask(int l, int r){
    return ask(r) - ask(l-1);
}
```
