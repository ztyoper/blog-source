# 二分mid写法改进

#### **二分查找中点计算的两种写法总结**

在二分查找（或类似算法）中，计算中间索引`mid`的常见方式有两种：

1. **标准中点（向下取整）** ：

- 原写法： `mid = (l + r) / 2`
- **改进写法（推荐）** ： `mid = l + (r - l) / 2`

2. **右偏中点（向上取整）** ：

- 原写法： `mid = (l + r + 1) / 2`
- **改进写法（推荐）** ： `mid = l + (r - l + 1) / 2`

---

#### **1. 标准中点**`(l + r) / 2`**→**`l + (r - l) / 2`

##### **特点**

- 适用于 **普通二分查找** （如 `while (l <= r)` 或 `while (l < r)` ）。
- **向下取整** ，即 `mid` 偏向 `l` （左边界）。

##### **改进原因**

- **防止溢出** ：当 `l` 和 `r` 很大时（如接近 `INT_MAX` ）， `l + r` 可能溢出，而 `r - l` 不会。
- **数学等价性** ：
[
   $\left\lfloor \frac{l + r}{2} \right\rfloor = l + \left\lfloor \frac{r - l}{2} \right\rfloor$
   ]

##### **示例**

- `l = 3` , `r = 7` ：

- 原式： `(3 + 7) / 2 = 5`
- 改进式： `3 + (7 - 3) / 2 = 5` （结果一致）。

- `l = 2e9` , `r = 2e9 + 1` （防溢出测试）：

- 原式： `(2e9 + 2e9 + 1) / 2` → 溢出（错误）。
- 改进式： `2e9 + (1) / 2 = 2e9` （正确）。

---

#### **2. 右偏中点**`(l + r + 1) / 2`**→**`l + (r - l + 1) / 2`

##### **特点**

- 适用于 **需要向上取整** 的情况（如 `while (l < r)` 且 `l = mid` 时避免死循环）。
- **向上取整** ，即 `mid` 偏向 `r` （右边界）。

##### **改进原因**

- **防止溢出** ： `l + r + 1` 更容易溢出，而 `r - l + 1` 不会。
- **数学等价性** ：
[
   $\left\lfloor \frac{l + r + 1}{2} \right\rfloor = l + \left\lfloor \frac{r - l + 1}{2} \right\rfloor$
   ]

##### **示例**

- `l = 3` , `r = 7` ：

- 原式： `(3 + 7 + 1) / 2 = 5` （注意 `+1` 的影响）。
- 改进式： `3 + (7 - 3 + 1) / 2 = 5` （结果一致）。

- `l = 2e9` , `r = 2e9` （防溢出测试）：

- 原式： `(2e9 + 2e9 + 1) / 2` → 溢出（错误）。
- 改进式： `2e9 + (0 + 1) / 2 = 2e9` （正确）。

---

#### **对比总结**

| **场景** | **原写法** | **改进写法** | **作用** |
| --- | --- | --- | --- |
| 标准中点（向下取整） | `(l + r) / 2` | `l + (r - l) / 2` | 防溢出，等价普通二分。 |
| 右偏中点（向上取整） | `(l + r + 1) / 2` | `l + (r - l + 1) / 2` | 防溢出，避免死循环。 |

---

#### **选择建议**

1. **默认情况** ：使用 **标准中点** `l + (r - l) / 2` （如 `while (l <= r)` ）。
2. **需要右偏时** ：使用 **右偏中点** `l + (r - l + 1) / 2` （如 `while (l < r)` 且 `l = mid` ）。

#### **代码模板**

```java
// 标准二分（向下取整）
int mid = l + (r - l) / 2;

// 右偏二分（向上取整）
int mid = l + (r - l + 1) / 2;
```

---

#### **附加说明**

- **位运算优化** ：在部分语言中可用 `>> 1` 代替 `/ 2` （如 `mid = l + ((r - l) >> 1)` ），但需确保 `(r - l)` 非负。&gt;&gt;优先级不如 + -
- **终止条件** ： `mid` 的计算方式需与 `while` 条件和边界更新逻辑匹配，避免死循环。
