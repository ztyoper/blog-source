## 一维前缀和

> O(1)获得区间和。O(n)进行初始化

### 初始化O(n)

```java
for(int i = 1; i<=n; i++){
    s[i] =s[i-1] + a[i];
}
```

### 区间和O(1)

```java
s[r] - s[l-1]
```

## 二维前缀和

> O(1)获得二维区间和。O(n*m)进行初始化

### 初始化O(n*m)

> <span style="color: rgb(77, 77, 77)">同一维前缀和一样，我们先来定义一个二维数组</span><span style="color: rgb(199, 37, 78)">s[][]</span><span style="color: rgb(77, 77, 77)">,</span><span style="color: rgb(199, 37, 78)">s[i][j]</span><span style="color: rgb(77, 77, 77)">表示二维数组中，左上角</span><span style="color: rgb(199, 37, 78)">(1, 1)</span><span style="color: rgb(77, 77, 77)">到右下角</span><span style="color: rgb(199, 37, 78)">(i, j)</span><span style="color: rgb(77, 77, 77)">所包围的矩阵元素的和。接下来推导二维前缀和的公式。</span>

![image.png](https://pub-ccd5622eabb54b4a81678003778ddce1.r2.dev/PicGo/ab7475b76034522bb240789e6a8992e4260042cf8f1463306397ae5e1304a895.png)

> 记忆的时候，子矩阵需要加上边角料。因此是`+ s[x1-1][y1] + s[x1][y1-1]`.
> 重叠部分重复加入，因此是`-s[x1-1][y1 - 1]`

```java
for(int i = 1; i<=n; i++){
    for(int j = 1; j<=n; j++){
        s[i][j] = s[i][j-1] + s[i-1][j] + a[i][j] - s[i-1][j-1];
    }
}
```

加上的aij元素不是右下角的方块，而是右下角的点。

### 二维区间和O(1)

![image.png](https://pub-ccd5622eabb54b4a81678003778ddce1.r2.dev/PicGo/38d63435d239895cde9100a06cd4d64b5aa6952aab6230615c6246a4015eea16.png)

> 间隙是正确的，因为我们把每一个点看做一个元素

> 记忆的时候，子矩阵需要减去多余边角料。因此是`- s[x1-1][y2] - s[x2][y1-1]`.
> 重叠部分减去，因此是`+s[x1-1][y1 - 1]`

```java
//子矩阵左上角(x1,y1) 右下角 (x2, y2)的二维子矩阵区间和 
int ans = s[x2][y2] - s[x1-1][y2] - s[x2][y1-1] + s[x1-1][y1 - 1]
```
