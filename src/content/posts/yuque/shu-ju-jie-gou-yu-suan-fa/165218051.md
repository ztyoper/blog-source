# 单调队列

> 单调队列我们使用实现Deque(双端队列)接口的LinkedList来快速插入和删除。

### 试题一：滑动窗口最大值

```java
import java.io.BufferedReader;
import java.io.IOException;
import java.io.InputStreamReader;
import java.util.ArrayList;
import java.util.Deque;
import java.util.LinkedList;
import java.util.StringTokenizer;

public class Main {
    public static void main(String[] args) throws IOException {
        //队列中存储的是数的索引，因为需要对窗口的大小进行判断，其实大多时候都是存储索引。如果不存储索引个就需要使用size()判断是否＞区间k 但该方法时间复杂度为n 通过这个例子，我们知道存储索引可以避免size()的使用也能获取到数组大小的方法。等等，可能size()是在添加元素时就开始更新的话，那该方法的时间复杂度也是1
        Deque<Integer> q = new LinkedList<>();
        char[] num = read.readLine().replace(" ","").toCharArray();
        int k = nextInt();

        ArrayList<Integer> list = new ArrayList<>();

        for(int i = 0; i<num.length; i++) {
            //队列的左边是头，右边是尾
            //1.从右入队，若小于当前尾元素就保留，因为不知道它是否是下一个窗口中的最大值；若大于当前尾元素，就删除当前尾元素，若新的尾元素还是小于，就继续删除。因为不可能成为窗口中最大元素了。
            //若该数大于前面出现的数。因为队列是单调递减的，就依次尾删除，等于看题目条件是否删除。
            //想象一个队列固定在原地，从右往左一次进入各个数。
            while(!q.isEmpty() && num[q.getLast()] <= num[i])
                q.removeLast();
            //该数尾入队，入队的是该数的 num 中的 下标索引
            q.addLast(i);
            //2.从左出队，元素个数大于滑动窗口的大小后，就剔除首元素。
            if(i - q.getFirst() + 1 > k)
                q.removeFirst();
            //3.保存结果
            //当遍历的元素个数大于等于窗口大小，就保存结果。
            if(i >= k-1) {
                list.add(num[q.getFirst()] - '0');
            }
        }
        for(int y : list) {
            System.out.println(y);
        }

    }

    static BufferedReader read = new BufferedReader(new InputStreamReader(System.in));
    static StringTokenizer token  = null;
    static String next(){
        while(token == null || !token.hasMoreTokens()){
            try {
                token = new StringTokenizer(read.readLine());
            } catch (IOException e) {
                throw new RuntimeException(e);
            }
        }
        return token.nextToken();
    }
    static int nextInt(){
        return Integer.parseInt(next());
    }


}
```
