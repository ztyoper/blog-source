### 试题一：最大回文子串

> ![image.png](https://pub-ccd5622eabb54b4a81678003778ddce1.r2.dev/PicGo/64535a388d80ee0d5d2ee3c52843c2bee3e318f00422e6db10b86972e9b9ff9f.png)

**【思路分析】**

> 暴力求解：双重for循环遍历所有的子串，对每一个子串进行回文判断O(n)，总共就是O(n^3)
> 暴力延展：外层循环字符串本身每一个字符，内层循环每个字符作为中心符时然后进行两边同时延展。（这是奇数个数的回文串，我们还要判断偶数个数的回文串）。总共就是O(n^2)
> 二分+哈希 可以做到O（nlogn）
> 使用manacher算法，O(n)。

```java
import java.util.Scanner;

public class Main {
	static Scanner scanner = new Scanner(System.in);
	public static void main(String[] args) {
		String s = scanner.nextLine();
		manacher(s);
	}
	public static void manacher(String s) {
		StringBuilder sb = new StringBuilder();
        //两头添加是为了保证不越界。当i-p[i]等于“^”时，暴力延展时判断为false,就结束延展。“$”是相同的作用。
		sb.append("^");
		for(int i = 0; i<s.length(); i++) {
			sb.append("#");
			sb.append(s.charAt(i));
		}
		sb.append("#");
		sb.append("\\@");
		int[] p = new int[sb.length()];
		int r = 0, c = 0, max = 1;
		for(int i = 1; i<sb.length()-1;i++) {
            //判断是继承对称点的最大回文半径还是赋值为1（包含i本身）
			p[i] = i<r?Math.min(p[2*c-i],r-i):1;
            //暴力延展。
			while(sb.charAt(i+p[i]) == sb.charAt(i-p[i]))
				p[i]++;
            //如果延展后（当前下标+回文半径）的长度大于r，就更改r的值。c的值赋值为下标i，因为i要++了，c就是i++后的i-1项
            //2c-i就是i-2项。这样之后p[i]再继承p[2c-i] = p[i-2]
            //如果延展后（当前下标+回文半径）的长度<=r,这r,c保持不变。
            //这里没有出现左边界L，因为p[2c-i]与L的距离就是i与r之间的距离，大小为r-i。i到r之间是上次循环判断后的回文串的右半部分。左半部分是到L。
            //Math.min(p[2*c-i],r-i)就是Math.min(p[2*c-i],p[2c-i]到L的距离)因此可以不用出现左边界L
            
			if(i + p[i] > r) {
				r = i+p[i];
				c = i;
			}
			max = Math.max(max, p[i]-1);
		}
		System.out.println(max);
	}
}
```

> 如果想要找出最大回文子串是哪一个：就打印新串，然后替换所有“#”

```java
import java.util.Scanner;

public class Main {
	static Scanner scanner = new Scanner(System.in);
	public static void main(String[] args) {
		String s = scanner.nextLine();
		manacher(s);
	}
	public static void manacher(String s) {
		String ss = null;
		StringBuilder sb = new StringBuilder();
		sb.append("^");
		for(int i = 0; i<s.length(); i++) {
			sb.append("#");
			sb.append(s.charAt(i));
		}
		sb.append("#");
		sb.append("\\@");
		int[] p = new int[sb.length()];
		int r = 0, c = 0, max = 1;
		for(int i = 1; i<sb.length()-1;i++) {
			p[i] = i<r?Math.min(p[2*c-i],r-i):1;
			while(sb.charAt(i+p[i]) == sb.charAt(i-p[i]))
				p[i]++;
			if(i + p[i] > r) {
				r = i+p[i];
				c = i;
			}
			int temp = max;
			max = Math.max(max, p[i]-1);
			//最大值改变了。
			if(temp != max) ss = sb.substring(i-p[i]+1, i+p[i]);
		}
		System.out.println(max);
		System.out.println(ss.replace("#", ""));
	}
}
```
