### 试题一：回文判断

> ![image.png](https://pub-ccd5622eabb54b4a81678003778ddce1.r2.dev/PicGo/84b5fd1ce1878dc795b3d3c57a05d074855f3f421febddb89691e76b9c16a894.png)

【思路分析】

> 对撞指针，每次判断s山和s[r]是否相等，如果相等就都移动一步，否则直接判断为“不是回文串”。

```java
import java.io.BufferedInputStream;
import java.io.BufferedReader;
import java.io.IOException;
import java.io.InputStream;
import java.io.InputStreamReader;
import java.io.StreamTokenizer;
import java.util.ArrayList;
import java.util.Arrays;
import java.util.Collections;
import java.util.HashMap;
import java.util.Map;
import java.util.Scanner;
import java.util.StringTokenizer;

public class Main {
	public static void main(String[] args) {
		try {
			String s = reader.readLine();
			boolean flag = true;
			for(int i = 0, j = s.length()-1; i<j; i++,j--) {
				if(s.charAt(i) != s.charAt(j))
				{
					flag = false;
					break;
				}
			}
			if(flag) {
				System.out.println("Y");
			}else {
				System.out.println("N");
			}
		} catch (IOException e) {
			// TODO Auto-generated catch block
			e.printStackTrace();
		}
	}

	static BufferedReader reader = new BufferedReader(new InputStreamReader(System.in));

	static StringTokenizer token = new StringTokenizer("");

	static String next() {
		while (!token.hasMoreTokens()) {
			try {
				token = new StringTokenizer(reader.readLine());
			} catch (IOException e) {
				// TODO Auto-generated catch block
				e.printStackTrace();
			}
		}
		return token.nextToken();
	}

	static int nextInt() {
		return Integer.parseInt(next());
	}

}
```

## 快慢指针![tmp5471.png](https://pub-ccd5622eabb54b4a81678003778ddce1.r2.dev/PicGo/2a0c928c52339606b687cff9f253044499cb1f2a4996f92350db112f76a66265.png)![tmp66F0.png](https://pub-ccd5622eabb54b4a81678003778ddce1.r2.dev/PicGo/83d96dae979a4d2dc5f13654177df62034ca145c6d9a72045eb6faecbe80add0.png)

### 试题一：美丽的区间

> ![image.png](https://pub-ccd5622eabb54b4a81678003778ddce1.r2.dev/PicGo/0235377e177c7865fdf129d2ea22662283de3ede8a5c10d34a5020736af3301e.png)

【思路分析】

> 如果我们使用前缀和，对于任意区间的和都可以O(1)得出，但是我们要遍历所有可能的区间，也就是双重for循环，这样又是10^5 * 10^5会超时。
> 利用快慢指针，保持区间[L,R]尽可能小且和&gt;=S.在这里当[i,j]的sum&gt;=S后，再增加R没有意义，所以，j都不动了，然后尝试右移i,当i增大后sum可能&lt;S,这时再右移动j。最短区间是被记录下来了的。
> 题中都只能右移，从不出现左移。

```java
import java.io.BufferedInputStream;
import java.io.BufferedReader;
import java.io.IOException;
import java.io.InputStream;
import java.io.InputStreamReader;
import java.io.StreamTokenizer;
import java.util.ArrayList;
import java.util.Arrays;
import java.util.Collections;
import java.util.HashMap;
import java.util.Map;
import java.util.Scanner;
import java.util.StringTokenizer;

public class Main {
	public static void main(String[] args) {
		int n = nextInt();
		int s = nextInt();
		int[] a = new int[n];
		
		for(int i = 0; i<n; i++) {
			a[i] = nextInt();
		}
		int l= 0, r = 0, min = n+1;//min是存储最短区间长度。我们这里就l = 0，不用等于1
		long sum = 0;
		while(r<n) {
			sum +=a[r];
			while(sum >= s) {
				min = Math.min(min, r-l+1);//r-l+1表示区间长度
				//保存了满足条件的区间长度之后，我们将l进行右移动
				sum -=a[l];
				l++;
			}
			r++;
		}
		if(min != n+1)System.out.println(min);
		else System.out.println(0);
	}
	static BufferedReader reader = new BufferedReader(new InputStreamReader(System.in));

	static StringTokenizer token = new StringTokenizer("");

	static String next() {
		while (!token.hasMoreTokens()) {
			try {
				token = new StringTokenizer(reader.readLine());
			} catch (IOException e) {
				// TODO Auto-generated catch block
				e.printStackTrace();
			}
		}
		return token.nextToken();
	}

	static int nextInt() {
		return Integer.parseInt(next());
	}

}
```

### 试题二：两数之和|| - 输入有序数组

> ![image.png](https://pub-ccd5622eabb54b4a81678003778ddce1.r2.dev/PicGo/34586ede4c8f47eaf669cfbcf24cc390ecfaaa1b3f29549b24dc9de5167fbfd9.png)

【思路分析】

> 按照双指针的分析方式看看有没有**单调，**也就是在脑海中模拟一种双指针算法，使其能包含所有可能。
> 当 i 最初为最小值时，j从最大值开始，一次递减，当sum大于target时就递减 j ,当sum等于target时就输出答案。当sum小于target时，就将 i 右移动。

```java
class Solution {
    public int[] twoSum(int[] numbers, int target) {
        
        for(int i = 0, j = numbers.length - 1;i<numbers.length; i++){
            while(i<j && numbers[i] + numbers[j] > target) j--;
            if(i<j && numbers[i] + numbers[j] == target) return new int[]{i,j};
        }
        return null;
    }
}
```
