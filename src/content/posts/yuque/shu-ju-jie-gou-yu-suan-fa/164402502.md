### 试题一: 特殊的三角形

> ![image.png](https://pub-ccd5622eabb54b4a81678003778ddce1.r2.dev/PicGo/25236b15ee72adc6ee8f879a19dbe6954bde5e5955d2b2d14da8087889765a80.png)

【思路分析】

> 1. 搜索的过程这里是迭代不是递归。
> 2. 区间就使用前缀和[0,r] - [0,l-1]来解决。
> 3. 如果我们不剪枝：a b c他们的范围都是1&lt;=a &lt;=10^6,但事实是，不可能都去得到这么大。我们有以下剪枝过程

```java
import java.util.Scanner;

public class Main {
	static Scanner scanner = new Scanner(System.in);

	public static void main(String[] args) {
		//求出[1,2] [1,3]...[1,1e6]的所有区间的结果
		long[] sum = new long[(int)1e6 + 1];
		//迭代求解,遍历所有三角形的情况(保证a<b<c)
		for(int a = 1; a<100; a++) {
			for(int b = a+1; b<1000; b++) {
				for(int c = b+1; c<a+b; c++) {
					if(is(a,b,c) && a*b*c <=1e6) {
						sum[a*b*c]++;//这样是为了使用前缀和优化
					}
				}
			}
		}
		//前缀和优化
		for(int i = 1; i<=1e6; i++) {
			sum[i] +=sum[i-1];
		}
		int t = scanner.nextInt();
		while(t-->0) {
			int l = scanner.nextInt();
			int r = scanner.nextInt();
			System.out.println(sum[r] - sum[l-1]);
		}
		
	}
	public static boolean is(int a, int b, int c) {
		//三角形的性质
		return (a+b)>c && (a+c) > b && (b+c) > a;
	}
}
```
