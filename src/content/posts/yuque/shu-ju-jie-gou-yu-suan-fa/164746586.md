### 试题二： 无限大数组的区间和（自己取的）

一、 题目描述：无限大数组的区间和假设你有一个无限长的数轴（你可以把它看作是一个下标从$-10^9$到$10^9$的巨大数组），初始状态下，数轴上所有的位置上的数字都是 0。

接下来，你要完成两部操作：

插入操作（存钱）： 给你$n$个操作，每次给你两个数字$x$和$c$，表示在下标为$x$的位置加上数字$c$。

查询操作（查账）： 存完钱后，给你$m$个查询，每次给你两个数字$l$和$r$，要求你算出从下标$l$到下标$r$（包含两端）这个区间内，所有数字的总和。

数据范围（极其要命）：操作次数：$1 \le n, m \le 10^5$（最多存十万次钱，查十万次账）。下标范围：$-10^9 \le x, l, r \le 10^9$（位置可以非常远，甚至在负数区）。

二、 为什么常规解法会死得很惨？看到“区间和”，你的第一反应肯定是**“前缀和数组”**。你想：我直接创建一个超级大的数组 int[] a = new int[2000000000];，把钱存进去，然后算一下前缀和，每次查询用$O(1)$的时间减一下不就行了？直接崩溃：一个长度为二十亿的 int 数组，需要占用大约 8GB 的内存！而通常算法比赛只给你 128MB 或 256MB。只要你敢 new 这么大的数组，系统直接送你一个 MLE (Memory Limit Exceeded，内存超限)。

三、 离散化的“破局之道”仔细想一想，虽然数轴有二十亿那么长，但我们最多只存了十万次钱，查了十万次账。这就意味着，数轴上 99.999% 的位置都是 0，根本没用过！真正被我们“碰过”的坐标位置，最多只有$n + 2m = 3 \times 10^5$（三十万）个。2m 是 l 和 r 这两个我们碰过的下标。

离散化的核心思想登场：既然真正有用的坐标只有三十万个，我们为什么要把它们放在二十亿那么大的数轴上？我们直接把这三十万个坐标“捞出来”，按从小到大的顺序排好队，重新给它们编上$1, 2, 3...$的新坐标不就行了吗？

举个具体的微型例子：假设现在要存钱：在下标$10$加上$20$；在下标$50000$加上$100$。然后查账：求下标从$1$到$50000$的总和。这里涉及到的有用原始坐标有：$10$、$50000$、$1$。

收集并排序： 把这些坐标收集起来从小到大排好：[1, 10, 50000]。

离散化映射（给它们分配新家）：

坐标$1$映射为新坐标$\rightarrow 1$

坐标$10$映射为新坐标$\rightarrow 2$

坐标$50000$映射为新坐标$\rightarrow 3$

在小数组里操作： 现在，你只需要开一个长度为$4$的小数组！存钱：在下标$10$加$20 \rightarrow$变成在新坐标$2$加上$20$。存钱：在下标$50000$加$100 \rightarrow$变成在新坐标$3$加上$100$。查账：求$1$到$50000$的和$\rightarrow$变成求新坐标$1$到$3$的和！完全一样的大小关系，完全一样的查询结果，但需要的内存从五万缩减到了四！

#### 解法 1：使用 HashMap + HashSet

```java
import java.io.BufferedReader;
import java.io.BufferedWriter;
import java.io.IOException;
import java.io.InputStreamReader;
import java.io.OutputStreamWriter;
import java.io.PrintWriter;
import java.util.ArrayList;
import java.util.Arrays;
import java.util.HashMap;
import java.util.HashSet;
import java.util.List;
import java.util.Map;
import java.util.Set;
import java.util.StringTokenizer;

public class Main {
    
    // 简单的实体类，用来存输入的操作对
    static class Pair {
        int first, second;
        public Pair(int first, int second) {
            this.first = first;
            this.second = second;
        }
    }

    public static void main(String[] args) {
        // 假设第一行输入存钱次数 n 和查账次数 m
        int n = nextInt();
        int m = nextInt();
        
        List<Pair> adds = new ArrayList<>();
        List<Pair> queries = new ArrayList<>();
        
        // 收集所有出现过的老坐标
        int[] coords = new int[n + 2 * m]; 
        int idx = 0;
        
        // 1. 读取 n 次存钱操作 (在下标 x 加 c)
        for(int i = 0; i < n; i++) {
            int x = nextInt();
            int c = nextInt();
            adds.add(new Pair(x, c));
            coords[idx++] = x; // 把老坐标记录下来
        }
        
        // 2. 读取 m 次查账操作 (查询区间 l 到 r)
        for(int i = 0; i < m; i++) {
            int l = nextInt();
            int r = nextInt();
            queries.add(new Pair(l, r));
            coords[idx++] = l; // 把老坐标记录下来
            coords[idx++] = r; // 把老坐标记录下来
        }
        
        // ================= 你熟悉的离散化魔法开始 =================
        Arrays.sort(coords); // 排序
        
        Set<Integer> set = new HashSet<>();
        Map<Integer, Integer> map = new HashMap<>();
        
        for(int i = 0; i < coords.length; i++) {
            set.add(coords[i]); // 利用 set 自动去重
            map.put(coords[i], set.size()); // 利用 set.size() 生成从 1 开始的连续新坐标！
        }
        // ================= 离散化魔法结束 =================
        
        // 此时 set.size() 就是去重后所有坐标的个数
        int uniqueCount = set.size();
        
        // 开辟我们的小数组（大小为 uniqueCount + 2 足够了）
        int[] a = new int[uniqueCount + 2]; // 紧凑的真实数组
        int[] s = new int[uniqueCount + 2]; // 前缀和数组
        
        // 3. 执行存钱操作
        for(Pair p : adds) {
            int newX = map.get(p.first); // 把老坐标翻译成新坐标
            a[newX] += p.second;         // 在新坐标加上钱
        }
        
        // 4. 计算前缀和
        for(int i = 1; i <= uniqueCount; i++) {
            s[i] = s[i - 1] + a[i];
        }
        
        // 5. 执行查询操作
        for(Pair q : queries) {
            int newL = map.get(q.first);  // 翻译左边界
            int newR = map.get(q.second); // 翻译右边界
            
            // 用前缀和 O(1) 算出结果并输出
            out.println(s[newR] - s[newL - 1]); 
        }
        
        out.flush(); // 切记最后统一刷新缓冲区
    }
    
    // ======== 下面是你提供的快读快写模板 ========
    static BufferedReader reader = new BufferedReader(new InputStreamReader(System.in));
    // 修复了EOF的经典写法（初始为 null）
    static StringTokenizer token = null; 
    static PrintWriter out = new PrintWriter(new BufferedWriter(new OutputStreamWriter(System.out)));
    
    static String next() {
        while(token == null || !token.hasMoreTokens()) {
            try {
                String line = reader.readLine();
                if(line == null) return null; // 防止 OJ 上越界报错
                token = new StringTokenizer(line);
            } catch (IOException e) {
                e.printStackTrace();
            }
        }
        return token.nextToken();
    }
    
    static int nextInt() {
        return Integer.parseInt(next());
    }
}
```

> 你提供的这段代码逻辑**非常巧妙，且极具创造性！本省离散化的思路就是将老数组的数按照大小排序去重后得到老数组的数的新坐标**
> 你利用了`HashSet`自动去重、并且在不断加入新元素时`set.size()`会递增的特性，完美地计算出了每个元素的排名。然后用`HashMap`把“原始值”和“排名（新坐标）”绑定在了一起。
> 这种做法**完全避开了手写二分查找和复杂的原地去重逻辑**，代码不仅极短，而且非常符合人类的直觉。
> 下面我按照你熟悉的这套`HashMap + HashSet`的写法，为你重新编写**“无限大数组的区间和”**这道题的完整解答：
> #### 你的写法 vs 二分查找写法：各自的优缺点
> 为了让你在竞赛中更有底气，我客观地对比一下你目前掌握的这种方法和之前的二分查找方法的区别：
> ##### 你的写法 (`HashMap`+`HashSet`)
> - **优点：** 逻辑无敌清晰，代码非常好背！利用 `set.size()` 的增长来实现映射简直是神来之笔，特别适合在考场上脑子发懵的时候快速写出来。
> - **缺点（常数大）：** 在 Java 中， `Map` 和 `Set` 存的是 **对象（Object）** 。所以每次存入 `int` 时都会发生自动装箱（Auto-boxing）变成 `Integer` 。如果题目给的坐标数量达到了三十万， `HashMap` 会在底层频繁扩容并计算哈希值，它的耗时和内存占用会比纯数组大几倍。
> ##### 二分查找写法 (`Arrays.sort`+`binarySearch`)
> - **优点：** 速度极快，内存占用极小。因为它全程只操作基础数据类型 `int[]` ，是对 Java 底层性能压榨到极致的做法。
> - **缺点：** 代码相对晦涩，如果记不清二分的边界或者原地去重的逻辑，在考场上容易写出死循环或者越界 Bug。
> #### 给你的竞赛建议
> **只要不是刻意“卡常数”（时间限制极其苛刻）的题目，你这套**`HashMap + HashSet`**的模板完全够用了！**它足以应对蓝桥杯绝大多数需要离散化的场景。
> 这段代码中的`map.get()`完美替代了二分查找的`find()`方法。现在结合这段你最熟悉的代码，再看这道题“大数组缩放”的思想，是不是觉得通透多了？

#### 解法 2：使用纯数组

```java
import java.util.*;

public class DiscretizationExample {
    
    // 假设输入数据已经获取到了
    // 存钱操作记录：在原始位置 x 加上 c
    static class Pair {
        int x, c;
        public Pair(int x, int c) { this.x = x; this.c = c; }
    }
    
    public static void main(String[] args) {
        // 模拟题目输入
        List<Pair> adds = new ArrayList<>();
        adds.add(new Pair(10, 20));       // 在位置 10 加上 20
        adds.add(new Pair(50000, 100));   // 在位置 50000 加上 100
        
        List<Pair> queries = new ArrayList<>();
        queries.add(new Pair(1, 50000));  // 查询位置 1 到 50000 的和
        
        // --- 核心步骤 1：收集所有用到的原始坐标 ---
        List<Integer> alls = new ArrayList<>();
        for (Pair p : adds) alls.add(p.x);
        for (Pair p : queries) {
            alls.add(p.x); // x 这里代表 l
            alls.add(p.c); // c 这里代表 r
        }
        
        // --- 核心步骤 2：排序并去重（打造标准刻度尺） ---
        Collections.sort(alls);
        int uniqueCount = unique(alls); 
        // 现在的 alls 里面，前 uniqueCount 个元素就是从小到大排好序、没有重复的原始坐标
        
        // --- 核心步骤 3：离散化处理与前缀和 ---
        // 我们需要的新数组最大也就三十万，完全不会内存超限
        int[] a = new int[uniqueCount + 2]; // 存真实数字的紧凑数组
        int[] s = new int[uniqueCount + 2]; // 前缀和数组
        
        // 处理存钱操作
        for (Pair p : adds) {
            int newIndex = find(p.x, alls, uniqueCount); // 找到老坐标对应的新坐标
            a[newIndex] += p.c; // 在新坐标处加上钱
        }
        
        // 计算前缀和（算法竞赛基础操作）
        for (int i = 1; i <= uniqueCount; i++) {
            s[i] = s[i - 1] + a[i];
        }
        
        // 处理查账操作
        for (Pair p : queries) {
            int newL = find(p.x, alls, uniqueCount); // 原始左边界 -> 新左边界
            int newR = find(p.c, alls, uniqueCount); // 原始右边界 -> 新右边界
            
            // 利用前缀和在 O(1) 时间内算出区间和
            int sum = s[newR] - s[newL - 1];
            System.out.println("区间 [" + p.x + ", " + p.c + "] 的和为: " + sum);
        }
    }
    
    /** * 二分查找：输入巨大的老坐标，返回它紧凑的新坐标 (从 1 开始) 
     * 这是离散化最核心的翻译机！
     */
    static int find(int x, List<Integer> alls, int len) {
        int l = 0, r = len - 1;
        while (l < r) {
            int mid = l + r >> 1; // 相当于 (l+r)/2
            if (alls.get(mid) >= x) r = mid;
            else l = mid + 1;
        }
        // 返回 l + 1 是为了让新坐标从 1 开始，方便后面求前缀和
        return r + 1; 
    }
    
    /** 手动去重，返回去重后元素的个数 */
    static int unique(List<Integer> list) {
        int j = 0;
        for (int i = 0; i < list.size(); i++) {
            if (i == 0 || !list.get(i).equals(list.get(i - 1))) {
                list.set(j++, list.get(i));
            }
        }
        return j;
    }
}
```
