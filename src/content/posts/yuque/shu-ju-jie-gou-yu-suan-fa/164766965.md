## <span style="color: rgb(79, 79, 79)">1、查找大于等于目标元素的第一个元素</span>

![tmp4B1F.png](https://pub-ccd5622eabb54b4a81678003778ddce1.r2.dev/PicGo/07d05176ddde81a0c29c16caf62ab2dba68560a569293fe5dda80f4b4324945c.png)

```java
private static int upperBound(int l, int r, int x) {
    while (l < r) {
        int mid = (l + r) / 2;//取区间中间位置靠左的值
        if (a[mid] >= x) {
            r = mid;//区间向左缩短一半
        } else {
            l = mid + 1;//区间向右缩短一半
        }
    }//循环退出的时候，l必定等于r
    //因为数组是递增的，a[l]必定大于等于x,就不用进行比较
    // 若是大于等于x的话，就返回对应下标
    // 若是小于x的话，就返回-1。这样
    return a[l] >= x ? l : -1;
}
```

> 好的，我们严格套用你喜欢的分析模板，来对比`upperBound`（查找第一个大于等于目标元素）中**加1**与**不加1**的差异。
> #### 不加1（即`mid = (l + r) / 2`）的情况 —— 正确写法
> 此时`mid`向下取整，偏向左边。
> 当`l`和`r`相邻时（例如`r = l + 1`），`mid = l`：
> - **若** `a[mid] >= x` **成立** ：执行 `r = mid = l` ，此时 `l == r` ，循环结束。
> - **若** `a[mid] >= x` **不成立** ：执行 `l = mid + 1 = r` ，此时 `l == r` ，循环结束。
> **结论：不加1时，无论条件是否成立，区间都能严格缩小并退出循环。**
> 加1（即`mid = (l + r + 1) / 2`）的情况 —— 错误写法
> **此时 `mid` 向上取整，偏向右边。**
> **当 `l` 和 `r` 相邻时（例如 `r = l + 1`），`mid = r`：**
> - **若** `a[mid] >= x` **成立** **：执行** `r = mid = r` **，此时** **右边界** `r` **纹丝不动** **，区间依然是** `[l, r]` **，长度未变。**
> - **下一轮循环依然计算出** `mid = r` **，再次进入同一分支……** **陷入无限循环** **。**
> - **若** `a[mid] >= x` **不成立** **：执行** `l = mid + 1 = r + 1` **，此时** `l > r` **，循环虽然退出，但返回下标可能越界或完全错过正确答案。**
> **结论：加1时，一旦进入 `a[mid] >= x` 分支，右边界无法缩小，导致死循环。**
> **最终总结**
> - **这种写法用于当满足条件时更新右边界** `r = mid` **的场景。**
> - **必须使用向下取整的** `mid` **计算方式（不加1），否则会因右边界不移动而陷入死循环。**
> **所以 `upperBound` 使用 `r = mid`，自然不能加1**

| **边界更新动作** | **必须的取整方向** | **原因** |
| --- | --- | --- |
| `l = mid`**（左边界追右）** | **向上取整****（**`(l+r+1)/2`**）** | **防止**`l`**不移动死循环** |
| `r = mid`**（右边界追左）** | **向下取整****（**`(l+r)/2`**）** | **防止**`r`**不移动死循环** |

R只能等于mid，不能等于mid-1。因为这是二分。写成r = mid -1可能将大于等于目标元素的第1个元素给排除了，因此只可能是mid。

当r=mid的时候，如果循环条件加上l=r就会出现无穷循环。因此不能l=r。

## <span style="color: rgb(79, 79, 79)">3、查找小于等于目标元素的最后一个元素</span>

![image.png](https://pub-ccd5622eabb54b4a81678003778ddce1.r2.dev/PicGo/98be2ec29d64ef247aa24f1d67d89d5529cdfdf8dae6a4e4aeb2142c325c712f.png)

```java
private static int lowerBound(int l, int r, int x) {
    while (l < r) {
        int mid = (l + r + 1) / 2;//取区间中间位置靠右的值， +1是为了保证下标不为负值
        if (a[mid] <= x) {
            l = mid;
        } else {
            r = mid - 1;
        }
    }//循环退出的时候，l必定等于r
    //因为数组是递增的，a[l]必定小于等于x，就算没有比较
    // 若是小于等于x的话，就返回对应下标
    // 若是大于x的话，就返回下标 -1 。
    return a[l] <= x ? l : -1;
}
```

> 在二分查找“小于等于目标元素的最后一个元素”时，`mid = (l + r + 1) / 2`这里`+1`是为了实现**向上取整**（偏向右边），避免死循环。具体原因如下：
> #### 不加1（即`mid = (l + r) / 2`）的问题
> 当`l`和`r`相邻时（例如`r = l + 1`），`(l + r) / 2`计算得到`mid = l`（下取整，偏左）。
> - 若 `a[mid] <= x` 成立，执行 `l = mid` ，则 `l` 还是原来的 `l` ， **区间没有缩小** 。
> - 循环条件 `l < r` 依然为真，但 `l` 和 `r` 的值完全没变，陷入 **无限循环** 。
> - **若** `a[mid] <= x` **不成立：执行** `r = mid - 1 = l - 1` **，此时** `l > r` **，循环虽然退出，但返回下标可能越界或完全错过正确答案。**
> #### 加上1的作用
> `mid = (l + r + 1) / 2`在`r = l + 1`时计算得到`mid = r`（上取整，偏右）：
> - 若 `a[mid] <= x` ， `l = mid = r` ，此时 `l` 和 `r` 相等，循环结束。
> - 若 `a[mid] > x` ， `r = mid - 1 = l` ，同样 `l == r` ，循环结束。
> 因此，**+1 保证了每次迭代区间都能严格缩小**，最终退出循环。
> #### 总结
> - 这种写法用于 **当满足条件时更新左边界** `l = mid` 的场景。
> - 必须使用向上取整的 `mid` 计算方式，否则会因左边界不移动而陷入死循环。

### 试题二：全部都有的子序列

> ![image.png](https://pub-ccd5622eabb54b4a81678003778ddce1.r2.dev/PicGo/1aec23299c18220eca3af96014f3ba823b5672eb8fe0828bf82b12dd9b3d400a.png)

【思路分析】

> 解析：连续的子序列长度区间为[1,n],存在二段性，即必有[1,k-1]不符合题意，[k,n]小符合题意。那我们就可以二分答案即可。题意找的是满足条件的最小的数。即用第一个模板即可。判断长度是否满足题意用滑动窗口判断即可。mid代表连续子序列的长度。根据二分，不断调整mid的大小，这样的解决方法相比于普通滑动窗口O(n)变为了O(logn)

```java
import java.io.BufferedReader;
import java.io.IOException;
import java.io.InputStreamReader;
import java.util.HashSet;
import java.util.Set;
import java.util.StringTokenizer;

public class Main {
	public static void main(String[] args) {
		int n = nextInt();
		int[] a = new int[n];
		Set set  =new HashSet<>();
		for(int i =0 ; i<n; i++) {
			a[i] = nextInt();
			set.add(a[i]);
		}
		int m = set.size();
		int l = 1, r= n, mid = 0;
		//连续子序列的长度，可能是1到n，我们使用二分进行判断最短的长度
		while(l<r) {
			mid = (l+r) / 2;
			//该长度下能满足题意，就见效增大mid，因为是找满足题意的最短子序列，我们这里使用的模板一
			if(check(a,mid,m))r = mid;
			//该长度下无法满足题意，就增大mid
			else  l = mid+1;
		}
		System.out.println(l);//此时l与r与mid的值相同
	}
	//返回true，表示mid长度的连续子序列中存在符号题目要求的串
	public static boolean check(int[] a, int mid, int m) {
		int l = 0, r = 0;
		int n = a.length;
		//因为总共最多只有1000种不同的数字
		int[] f = new int[1001];
		int ans = 0;
		while(r<n) {
			f[a[r]]++;
			//如果该种数第一次出现，就将种类数加一
			if(f[a[r]] == 1)
				ans++;
			//当r-l+1>mid时，(r-l+1)大小只可能是mid+1。
			//因此while循环只会执行一次。可以使用if来替换while
			while(r-l+1 > mid) {
				f[a[l]]--;
				//如果该种数出现次数变为0，就将种类数减一
				if(f[a[l]] == 0)
					ans--;
				l++;
			}//while执行完后，r-l+1的长度为mid
			//放在while外面是因为可能当r-l+1<mid时就已经滑动窗口内出现可以满足题意的子序列了。
			//就返回true,让下一次的mid变小再来判断。
			if(ans == m) {
				return true;
			}
			r++;
		}
		return false;
	}

	static BufferedReader reader = new BufferedReader(new InputStreamReader(System.in));

	static StringTokenizer token =null;

	static String next() {
		while (token == null || !token.hasMoreTokens()) {
			try {
				token = new StringTokenizer(reader.readLine());
			} catch (IOException e) {
				// TODO Auto-generated catch block
				e.printStackTrace();
			}
		}
		return token.nextToken();
	}

	static int nextInt() {
		return Integer.parseInt(next());
	}

}
```

### 试题三：递增三元组

> ![image.png](https://pub-ccd5622eabb54b4a81678003778ddce1.r2.dev/PicGo/68ed2bd534adedac99e26eaecc2d6bc2043002e60c76a37d85d99e398c9e1115.png)

#### 解法一：二分解法

【思路分析】

> 如果暴力求解，三个for循环必定会爆掉。我们只遍历b数组。然后找出对于B数组中每一个元素，a,c数组中满足题意的区间。并将两个区间大小相乘即可。时间复杂度O(nlogn)
> ![84c01fc1330d15a028a11b1e3183ea9d.jpg](https://pub-ccd5622eabb54b4a81678003778ddce1.r2.dev/PicGo/a45b0b335375312b7470a6ec9463f4e14bfddcfe79ac97bb0d0f5c5e67d85854.jpg)

```java
import java.io.BufferedReader;
import java.io.IOException;
import java.io.InputStreamReader;
import java.io.OutputStreamWriter;
import java.io.PrintWriter;
import java.io.StreamTokenizer;
import java.util.Arrays;

public class Main {
	static BufferedReader in = new BufferedReader(new InputStreamReader(System.in));
	static PrintWriter out = new PrintWriter(new OutputStreamWriter(System.out));
	static StreamTokenizer sr = new StreamTokenizer(in);
	static int MAXN = (int) (1e5 + 10);
	static int[] a = new int[MAXN];
	static int[] b = new int[MAXN];
	static int[] c = new int[MAXN];
	static int n;

	public static void main(String[] args) throws IOException {
		n = nextInt();
		for (int i = 0; i < n; i++) {
			a[i] = nextInt();
		}

		for (int i = 0; i < n; i++) {
			b[i] = nextInt();
		}

		for (int i = 0; i < n; i++) {
			c[i] = nextInt();
		}
		Arrays.sort(a, 0, n);
		Arrays.sort(c, 0, n);
		
		long res = 0;

		for (int i = 0; i < n; i++) {
			int left = getA(0, n - 1, b[i]);
			int right = getB(0, n - 1, b[i]);
			//（n-right）如果下标从1开始，就应该是n - right + 1 , 区间长度
			res += (long) (left + 1) * (n - right);
		}
		out.println(res);
		out.flush();

	}

	// 小于等于x的最后一个元素的下标。如果是等于的话就返回-1。
	private static int getA(int l, int r, int x) {
		// TODO Auto-generated method stub
		while (l < r) {
			int mid = (l + r + 1) / 2;
			if (a[mid] < x) {
				l = mid;
			} else {
				r = mid - 1;
			}
		}//循环退出的时候，l必定等于r
		//因为数组是递增的，c[l]必定小于等于x，就算没有比较
		// 若是小于x的话，就返回对应下标
		// 若是等于x的话，就返回下标 -1 。
		return a[l] < x ? l : -1;
	}

	// 大于等于x的第一个元素的下标。如果是等于的话就返回-1。
	private static int getB(int l, int r, int x) {
		// TODO Auto-generated method stub
		while (l < r) {
			int mid = (l + r) / 2;
			if (c[mid] > x) {
				r = mid;
			} else {
				l = mid + 1;
			}
		}//循环退出的时候，l必定等于r
		//因为数组是递增的，c[l]必定大于等于x，就算没有比较
		// 若是大于x的话，就返回对应下标
		// 若是等于x的话，就返回下标 n。这样
		return c[l] > x ? l : n;
	}

	static int nextInt() throws IOException {
		sr.nextToken();
		return (int) sr.nval;
	}

}
```

#### 解法二：双指针解法

【思路分析】

> ![d8b8e5a7d144bd9fd43ad134f9ac0024.jpg](https://pub-ccd5622eabb54b4a81678003778ddce1.r2.dev/PicGo/22261801f5b0b5e42355c05deb960f563ca789c8c02e58d073c782b0f47c5943.jpg)

```java
import java.io.BufferedReader;
import java.io.IOException;
import java.io.InputStreamReader;
import java.io.OutputStreamWriter;
import java.io.PrintWriter;
import java.io.StreamTokenizer;
import java.util.Arrays;

public class Main {
	static BufferedReader in = new BufferedReader(new InputStreamReader(System.in));
	static PrintWriter out = new PrintWriter(new OutputStreamWriter(System.out));
	static StreamTokenizer sr = new StreamTokenizer(in);
	static int MAXN = (int) (1e5 + 10);
	static int[] a = new int[MAXN];
	static int[] b = new int[MAXN];
	static int[] c = new int[MAXN];
	static int n;

	public static void main(String[] args) throws IOException {
		n = nextInt();
		for (int i = 0; i < n; i++) {
			a[i] = nextInt();
		}
		for (int i = 0; i < n; i++) {
			b[i] = nextInt();
		}
		for (int i = 0; i < n; i++) {
			c[i] = nextInt();
		}

		Arrays.sort(a, 0, n);
		Arrays.sort(b, 0, n);
		Arrays.sort(c, 0, n);

		// 使用双指针算法
		long res = 0;
		for (int i = 0, ai = 0, ci = 0; i < n; i++) {
			while (ai < n && a[ai] < b[i]) {
				ai++;
			}
			while (ci < n && c[ci] <= b[i]) {
				ci++;
			}
			res += (long) ai * (n - ci);
		}

		out.println(res);
		out.flush();

	}

	static int nextInt() throws IOException {
		sr.nextToken();
		return (int) sr.nval;
	}

}
```

```java
		for (int i = 0; i < n; i++) {
			c[i] = nextInt();
		}
		for (int i = 0; i < n; i++) {
			as[a[i]]++;
			cs[c[i]]++;
		}

		// 计算出前缀和
		for (int i = 1; i < MAXN; i++) {
			as[i] += as[i - 1];
			cs[i] += cs[i - 1];
		}

		long res = 0;
		// 枚举枚举每一个bi
		for (int i = 0; i < n; i++) {
            //因为有as[b[i] - 1]，所以要特判一下。
			if (b[i] == 0) {
				continue;
			}
            // 乘后的结果需要使用long，因此先将前一个数转换类型为long
			res += (long) as[b[i] - 1] *  (cs[MAXN - 1] - cs[b[i]]);
		}

		out.println(res);
		out.flush();

	}

	static int nextInt() throws IOException {
		sr.nextToken();
		return (int) sr.nval;
	}

}
```

### 试题四：数的范围

> ![tmpE58B.png](https://pub-ccd5622eabb54b4a81678003778ddce1.r2.dev/PicGo/dda4685e6cdc9e12badca516fda08c4c4382f0cfaa78b7b4ff3c50440263404f.png)![tmpF76E.png](https://pub-ccd5622eabb54b4a81678003778ddce1.r2.dev/PicGo/7c748861a3163dc7b2fa413c3922d1b5c5636d7a180bb627d226c9582cb99f72.png)
> 输入：
> 6 3
> 1 2 2 3 3 4
> 3 4 5

【思路分析】

> upperBound和LowerBound

```java

import java.util.Scanner;

public class Main {
	public static void main(String[] args) {
		Scanner scan = new Scanner(System.in);
		int n = scan.nextInt();
		int q = scan.nextInt();
		int[] a = new int[n];
		for(int i = 0; i<n; i++) a[i] = scan.nextInt();
		while(q-->0) {
			int x = scan.nextInt();
			System.out.print(upperBound(a, x) + " ");
			System.out.print(lowerBound(a, x));
			System.out.println();
		}
		
	}

	static int upperBound(int[] a, int x) {
		int l = 0, r = a.length-1;
		while(l < r) {
			int mid = l + r >> 1;
			if(a[mid] >= x) r = mid;
			else l = mid + 1;
		}
		//最后是大于等于x的第一个数	
		return a[l] == x ? l : -1;
	}
	
	static int lowerBound(int[] a, int x) {
		int l = 0, r = a.length-1;
		while(l < r) {
			int mid = l + r + 1 >> 1;
			if(a[mid] <= x) l = mid;
			else r = mid - 1;
		}
		//最后是小于等于x的第一个数	
		return a[l] == x ? l : -1;
	}

}
```

### 试题五：浮点数的开方

> 问题说明：输入一个数x（x&gt;1，因为小于1的数进行开方，结果会比自身大，我们使用浮点数二分进行开方就不太适用），对其开方，结果保留6位小数。

【思路分析】

> 使用浮点数二分，浮点数没有边界问题，不需要+1 或者 -1，只需要看 (r - l ) &lt; 1e -8 然后退出循环即可。
> 小经验：当需要保留4位小数的时候，我们将精度设计为1e -6 ;当需要保留6位小数的时候，我们将精度设计为1e -7 ;当需要保留6位小数的时候，我们将精度设计为1e -8 。总是比多两个数量级，这样截断进行四舍五入的时候，就不会出现精度缺失的问题，比如:4开方后，这题，如果精度设置为1e -6结果就是 1.999999 如果精度是1e -8，结果就是2.000000

```java

import java.util.Scanner;

public class Main {
	public static void main(String[] args) {
		Scanner scan = new Scanner(System.in);
		double x = scan.nextDouble();
		
		System.out.printf("%f", square(x));

	}

	static public double square(double x) {
		double l = 0; double r = x;
		//因为[l,r]是在[0,x]之间的，所以只适用于x的开根数小于等于的情况，x = 0.01的时候，输出0.01，这里的0.01是[0,x]里的最大值
		while(r - l > 1e-8) {
			double mid = (l + r ) / 2;
			if(mid * mid >= x) r = mid;
			else l = mid;
		}
		//返回l r都行
		return l;
	}

}
```
