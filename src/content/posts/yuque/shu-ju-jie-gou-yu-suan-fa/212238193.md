# 数组复制

`System.arraycopy`是 Java 提供的一个高效数组复制方法，它的参数含义如下：

```plain
java


复制编辑
System.arraycopy(original, from, copy, 0, Math.min(original.length - from, newLength));
```

#### **参数解析**

1. `original` ：源数组，即要复制的数据的来源。
2. `from` ：源数组的起始位置（索引），表示从 `original[from]` 开始复制。
3. `copy` ：目标数组，即数据要复制到的数组。
4. `0` ：目标数组的起始位置（索引），表示数据从 `copy[0]` 开始存放。
5. `Math.min(original.length - from, newLength)` ：要复制的元素个数，取 `original.length - from` 和 `newLength` 中较小的那个，确保不会越界。

---

#### **示例**

```plain
java


复制编辑
public class ArrayCopyExample {
    public static void main(String[] args) {
        int[] original = {1, 2, 3, 4, 5};
        int from = 2;  // 从索引2开始复制，即从元素3开始
        int newLength = 3;
        int[] copy = new int[newLength];

        System.arraycopy(original, from, copy, 0, Math.min(original.length - from, newLength));

        for (int num : copy) {
            System.out.print(num + " ");
        }
    }
}
```

#### **执行结果**

```plain
复制编辑
3 4 5
```

#### **核心逻辑**

- `from = 2` ，所以从 `original[2] = 3` 开始复制。
- `newLength = 3` ，目标数组 `copy` 需要 3 个元素。
- `original.length - from = 5 - 2 = 3` ， `newLength = 3` ，因此 `Math.min(3, 3) = 3` ，最终复制 3 个元素。
- 复制后 `copy = {3, 4, 5}` 。

#### **注意事项**

1. **避免** `ArrayIndexOutOfBoundsException`

- `from` 不能大于 `original.length` ，否则会抛出异常。
- `newLength` 不能超过 `copy.length` ，否则目标数组不够存储数据。

2. **支持原始类型（** `int[]` **、** `char[]` **、** `double[]` **等）**

- `System.arraycopy` 适用于所有 Java 原始数组类型。

3. **性能**

- `System.arraycopy` 采用 **本地代码（native code）** 实现，比 `for` 循环复制更快。

这个方法常用于**数组扩容、数组截取、数据迁移**等场景。
