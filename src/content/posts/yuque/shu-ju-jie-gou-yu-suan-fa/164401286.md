# Java中如何输入一个字符

<span style="color: rgb(77, 77, 77)">在一次编写代码时需要让程序接收一个字符，当我写出</span>scanner<span style="color: rgb(77, 77, 77)">.next时，我惊奇的发现，</span>**<span style="color: rgb(77, 77, 77)">Scanner类中没有定义读取char的方法！！！</span>**

Java中的扫描器类支持nextInt()，nextLong()，nextDouble()等。

但是没有nextChar()。要读取char，我们使用next().charAt(0)。next()函数返回输入中的下一个标记/字符作为字符串，并且charAt(0)函数返回该字符串中的第一个字符。

<span style="color: rgb(77, 77, 77)">所以，我们有了思路：</span><span style="color: rgb(77, 77, 77)">先</span>**<span style="color: rgb(77, 77, 77)">创建一个Scanner对象</span>**<span style="color: rgb(77, 77, 77)">，</span>**<span style="color: rgb(77, 77, 77)">调用Scanner对象的next()方法获取控制台输入的字符串</span>**<span style="color: rgb(77, 77, 77)">，返回的是一个String类型,因为没有nextChar()方法，所以</span>**<span style="color: rgb(77, 77, 77)">调用String的charAt(0)方法获取第一个字符</span>**<span style="color: rgb(77, 77, 77)">，这样一来，我们就输入了一个字符串</span>

<span style="color: rgb(77, 77, 77)">根据查找的资料以及知识储备，我总结了三条可以输入一个字符的方法：</span>

```java
import java.util.Scanner;
Scanner scanner = new Scanner(System.in);
char c = scanner.next().charAt(0);
```

<span style="color: rgb(77, 77, 77)">这是目前为止最常用的方法，就是上面的黑字原理</span>

```java
import java.util.Scanner;
Scanner scanner = new Scanner(System.in);
char c = scanner.next().toCharArray()[0];
```

<span style="color: rgb(77, 77, 77)">这个用起来一般般，没有第一种好用，有些浪费资源，没有第一种简单</span>

```java
import java.io.BufferedReader;
import java.io.IOException;
import java.io.InputStreamReader;
char c = (char)new BufferedReader(new InputStreamReader(System.in)).read();
```

<span style="color: rgb(77, 77, 77)">这样也可以输入，但是！这情况用于没有scanner包时使用，很麻烦，需要导入很多东西，不建议使用，了解一下即可</span>

<span style="color: rgb(77, 77, 77)">综上所述，</span>**<span style="color: rgb(77, 77, 77)">记住第一种方法，即可</span>**<span style="color: rgb(77, 77, 77)">，我们来回顾一下第一种</span>

```java
import java.util.Scanner;
Scanner scanner = new Scanner(System.in);
char c = scanner.next().charAt(0);
```
