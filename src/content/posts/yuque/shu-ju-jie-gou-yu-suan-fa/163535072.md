> 初始化：这一步是可以省略的。因为数组默认是0
> 上面笔误，应该是j= 1-&gt;8，其中j只能从1开始不能从weight[i]开始,，因为如果物品weight[1]=10000 value[1] = 1e3而物品weight[2]=20000 value[1] = 1e8。dp[1][weight[1]]到最大容量dp[1][max]这一行的赋值没有问题。但是dp[2][weight[2]]到最大容量dp[2][max]这一行有问题。因为dp[2][20000]前面都是0了，但是应该是1e3

```java
/**
 * @author ztyOperation
 * @create 2022-05-20-10:55
 * 01背包问题
 * 1.如果装不下当前物品，那么前n个物品的最佳组合与前n-1个物品的最佳组合是一样的
 * 2.如果装的下物品
 * ①不装当前物品，那么前n个物品的最佳组合与前n-1个物品的最佳组合是一样的
 * ②装当前物品，其剩余的背包空间(减去了装下当前物品后剩下的背包空间)的最佳组合
 * 即为前n-1个物品在剩余空间(减去了装下当前物品后剩下的背包空间)下的最佳组合，总价值为当前物品价值加上该最佳组合
 * 选取①②中最高价值作为选择
 *
 */
public class BackPackQuestion {
    public static void main(String[] args) {
        int[] weight = {0,2,3,4,5};
        int[] value = {0,3,4,5,6};
        int[][] dp = new int[5][9];//体积从0-8
        int[] object = new int[5];//用于查找装的物品
        int maxValue = Dynamic(dp, weight, value);
        System.out.println(maxValue);
        int[] find = Find(weight, value,9);
        for(int i = 0; i<find.length; i++){
            if(find[i] == 1){
                System.out.println("第" + i + "个物品被装入");
            }
        }

        //BackPackQuestion.Find(dp,weight,value,dp.length -1 ,dp[0].length -1,object);

    }

    /**
     *
     * @param dp
     * @param weight
     * @param value
     * @return 返回该背包能装入最大的价值。
     */
    public static int Dynamic(int[][] dp, int[] weight, int[] value){
        int i = 1; int j  = 1;
        for( i = 1; i<weight.length; i++){//前i种物品中选择
            for(j = 1; j<dp[i].length; j++){////共有j个大小的背包空间
                if(weight[i]>j) {//该编号物品重量打于背包重量
                    dp[i][j] = dp[i - 1][j];
                }else{
                    dp[i][j] = Math.max(dp[i-1][j], dp[i-1][j-weight[i]]+value[i]);
                }
            }
        }
        return dp[i-1][j-1];
    }

       /*
         int i = dp.length-1;//4
        int j  =dp[0].length-1;//8
        */
    private static void Find(int[][] dp, int[] weight,int[] value, int i ,int j,int[] object){//回溯查找装了哪些编号的东西
        if(i == 0){
//            for(int k = 0; k<5; k++){
//                System.out.print(object[k] + " ");
//            }
                return;
        }
        if(dp[i][j] == dp[i-1][j]){//如果没有装编号为i的物品
            object[i] = 0;
            Find(dp,weight,value,i-1,j,object);
        }
        else if(dp[i][j] == dp[i-1][j-weight[i]]+value[i]){//如果装了编号为i的物品
            object[i] = 1;
            Find(dp,weight,value,i-1,j-weight[i],object);//看看剩余空间有没有装编号为i-1的物品
        }
    }

    /**
     *注意：weight[0]  = 0 表示 本身有一个重量为0的物品，这样做的好处是为了避免数组越界。
     * @param weight weight的长度就是物品的个数，一个weight对应的值就是它的重量，或者说它占的体积。
     * @param value  value的长度就是物品的个数，一个value对应的值就是它所对应的价值。
     * @param volume volume就是背包的体积，或者说背包的大小，或者说方格数。
     * @return   Find函数返回object数组。,object[1] = 1，则1号物品在背包中。
     */
    public static int[] Find(int[] weight,int[] value, int volume){
        int[][] dp = new int[weight.length][];
        for(int i = 0; i< dp.length; i++) dp[i] = new int[volume];
        Dynamic(dp,weight,value);
        int[] object = new int[value.length];
        Find(dp,weight,value,dp.length-1,dp[0].length-1,object);
        return object;
    }
}
```

> ![0c1e0438fc1f64fcb674bf3a7d763f6b.jpg](https://pub-ccd5622eabb54b4a81678003778ddce1.r2.dev/PicGo/95a0c53b57fc6c8be26642b1c5dba4865ef972b6e9dea202260cf74e60b6ba94.jpg)
> 上述i应该从0开始。因为不存在二维数组解法中i-1的操作。所以不需要从1开始。背包大小为4时，装完物品1，就继续判断是否装入物品2，而装入的物品1已经表示为dp[1]，dp[1]装入了物品1。

```java
 public static void main(String[] args) {
        int[] weight = {1, 3, 4};
        int[] value = {15, 20, 30};
        int bagWight = 4;
        testWeightBagProblem(weight, value, bagWight);
    }
 
    public static void testWeightBagProblem(int[] weight, int[] value, int bagWeight){
        int wLen = weight.length;
        //定义dp数组：dp[j]表示背包容量为j时，能获得的最大价值
        int[] dp = new int[bagWeight + 1];
        //遍历顺序：先遍历物品，再遍历背包容量
        for (int i = 0; i < wLen; i++){
            for (int j = bagWeight; j >= weight[i]; j--){
                dp[j] = Math.max(dp[j], dp[j - weight[i]] + value[i]);
            }
        }
    }
```
