# 差分

## 一维差分

### 公式推导过程

> a1 a2 a3 a4 a5，如果区间修改【1,3】上要添加c变成a1+c, a2+c,a3+c, a4,a5，我们现在有s1 s2 s3 s4 s5表示前缀和。
> ① 让a1+c，s1,s2,s3,s4,s5都要加c。变成s1+c，s2+c，s3+c，s4+c，s5+c。
> ① 再让a4-c，就变成s1+c，s2+c，s3+c，s4，s5。
> 我们发现【1，3】区间上都添加了c，但不是原数组a1+c, a2+c, a3+c, a4, a5是它原来的前缀和数组 s 变成了s1+c，s2+c，s3+c，s4，s5。如果我们让前缀和的值作为原数组的值。也就是s1=a1, s2=a2, s3=a3, s4=a4, s5=a5。如果数组aa的前缀和是a1,a2,a3,a4,a5那么真正的要+c或-c原数组 aa 应该是多少呢？
> 因为：a1 = aa1, a2 = aa1 + aa2, a3 = aa1 + aa2 + aa3
> aa1 = a1 - a0 (s2 = 0)
> aa2 = a2 - a1
> aa3 = a3 - a2
> 或者：
> 前缀和公式： a[i] = a[i-1] + aa[i]
> 差分公式就是反着来： aa[i] = a[i] - a[i-1]
> 差分数组 d 就是aa数组， 就应该是 d[i] = a[i] - a[i-1] 这是一维差分推导过程。二维也是一样。
> 最终我们知道当对区间进行m次操作。本来时间复杂度为n×m。但是对其差分数组作m次的两次单点操作。然后根据前缀和求得原数组的单点值。最终时间复杂度就变成了min(n,m)。

## ![tmp70F3.png](https://pub-ccd5622eabb54b4a81678003778ddce1.r2.dev/PicGo/fc89a80dec3ac2949b854dcf5594dcf100454a6ed95dd805cd413974ff2af0dd.png)

> a数组是从1开始初始化。Diff[1] = a[1] - a[0]
> a[1] = diff[1]
> a[i] = diff[1] + diff[2] + .... + diff[i]

### 初始化O(n)

> 我们保证**逆运算**后的差分数组 d 是保存原数组 a**每一个元素**的**增量。**因此差分数组初始化为0
> 我们使用差分数组表示元素的增量就可以省略差分数组的初始化。不同于前缀和数组需要初始化。差分数组可以避免初始化。
> 逆运算：所有对于数组aa，或者说是差分数组 d 的逆运算都是将差分数组 d 进行前缀和处理。**本文的所有逆运算就是前缀和。**

### 区间修改O(1)

```java
d[l] += c;
d[r+1] -= c;
```

### 逆运算差分O(n)

> 逆运算差分获得原数组每一个元素的增量。用于多次区间修改后，的多次单点查询。如果修改和查询是交替进行。那么每次查询前都要逆运算差分数组来获取每个元素的增量。这时最终时间复杂度是O(n*m)，这时，我们需要用树状数组对差分数组进行维护。

```java
for(int i = 1; i<=n; i++){
    //逆运算差分，求得每一个元素的增量
    d[i] += d[i-1];
    //修改后的元素值 a[i] = a[i] + d[i];
    a[i] += d[i];
}
```

import java.io.BufferedReader;
import java.io.IOException;
import java.io.InputStream;

import java.io.StreamTokenizer;
import java.util.HashMap;

public class Main {
	static Scanner scanner = new Scanner(System.in);
	static StreamTokenizer token = new StreamTokenizer(
			new BufferedReader(new InputStreamReader(new BufferedInputStream(System.in))));

	static int nextInt() {
		try {
			token.nextToken();
		} catch (IOException e) {
			// TODO Auto-generated catch block
			e.printStackTrace();
		}
		return (int) token.nval;
	}

	public static void main(String[] args) {
		int n = nextInt();
		int m = nextInt();
		int[] arr = new int[n + 1];
		//每次x比较大，要使用long来存储
		long[] diff = new long[n + 2];
		for (int i = 1; i <= n; i++) {
			arr[i] = nextInt();
			diff[i] = arr[i] - arr[i - 1];
		}
		for (int i = 0; i < m; i++) {
			// 开始第一次操作
			// 注意L,R是从1开始的，不是从0
			int L = nextInt();
			int R = nextInt();
			int x = nextInt();
			diff[L] += x;
			diff[R + 1] -= x;
		}
		// 输出结果，long防止前缀和爆掉。一定要是long的
		long sum = 0;
		for (int i = 1; i <= n; i++) {
			sum += diff[i];
			if (sum > 0)
				System.out.print(sum + " ");
			else
				System.out.print(0 + " ");

		}
	}
}

## 二维差分

> <span style="color: rgb(77, 77, 77)">如果扩展到二维，我们需要让二维数组被选中的子矩阵中的每个元素的值加上</span><span style="color: rgb(199, 37, 78)">c</span><span style="color: rgb(77, 77, 77)">,是否也可以达到</span><span style="color: rgb(199, 37, 78)">O(1)</span><span style="color: rgb(77, 77, 77)">的时间复杂度。答案是可以的，</span>**<span style="color: rgb(77, 77, 77)">考虑二维差分</span>**<span style="color: rgb(77, 77, 77)">。</span>

### 公式推导过程

> ![7643c21f481212243d176153dcfa0bf2.jpg](https://pub-ccd5622eabb54b4a81678003778ddce1.r2.dev/PicGo/ad6e9a38c36300ef7d059265be0809a6a959170ddb699a4b3b7a869ace48500b.jpg)
> 原数组：
> a11，a12，a13，a14
> a21，<span style="color: #117CEE">a22</span>，a23，<span style="color: #74B602">a24</span>
> a31，a32，a33，a34
> a41，<span style="color: #ED740C">a42</span>，a43，<span style="color: #E4495B">a44</span>
> 如果我们要让左上角（x1,y1），右下角(x2,y2)构成的原矩阵进行区间加**<span style="color: rgb(199, 37, 78)">c变成：</span>**
> x1 = 2 , y1 = 2, x2 = 3, y2 = 3b
> a11，a12， a13， a14
> a21，a22+c，a23+c，a24
> a31，a32+c，a33+c，a34
> a41，a42， a43， a44
> **①**<span style="color: #117CEE">`a22 = a22 + c`</span>后，二维前缀和数组 s变成：
> s11，s12， s13， s14
> s21，<span style="color: #117CEE">s22+c，s23+c，s24+c</span>
> s31，<span style="color: #117CEE">s32+c，s33+c，s34+c</span>
> s41，<span style="color: #117CEE">s42+c，s43+c，s44+c</span>
> **②**<span style="color: #ED740C">`a42 = a42 - c`</span>，二维前缀和数组 s变成：
> s11，s12， s13， s14
> s21，<span style="color: #117CEE">s22+c，s23+c，s24+c</span>
> s31，<span style="color: #117CEE">s32+c，s33+c，s34+c</span>
> s41，<span style="color: #ED740C">s42， s43，</span><span style="color: #74B602"></span><span style="color: #ED740C">s44</span>
> **③**<span style="color: #74B602">`a24 = a24 - c`</span>，二维前缀和数组 s变成：
> s11，s12， s13， s14
> s21，<span style="color: #117CEE">s22+c，s23+c，</span><span style="color: #74B602">s24</span>
> s31，<span style="color: #117CEE">s32+c，s33+c，</span><span style="color: #74B602">s34</span>
> s41，<span style="color: #ED740C">s42， s43，</span><span style="color: #74B602">s44-c</span>
> **④**<span style="color: #E4495B">`a44 = a44 + c`</span>，二维前缀和数组 s变成：
> s11，s12， s13， s14
> s21，<span style="color: #117CEE">s22+c，s23+c，</span><span style="color: #74B602">s24</span>
> s31，<span style="color: #117CEE">s32+c，s33+c，</span><span style="color: #74B602">s34</span>
> s41，<span style="color: #ED740C">s42， s43，</span><span style="color: #E4495B">s44</span>
> 执行完**① ② ③ ④**后，我们就让左上角（x1,y1），右下角(x2,y2)构成的前缀和矩阵进行了区间上的加**<span style="color: rgb(199, 37, 78)">c。</span>**
> 但不是原数组变成这样：
> a11，a12， a13， a14
> a21，a22+c，a23+c，a24
> a31，a32+c，a33+c，a34
> a41，a42， a43， a44
> 我们就令s[i,j]等于a[i,j]但是如果数组aa[i,j]的前缀和是a[i,j]那么原数组 aa 应该是多少呢？
> 前缀和初始化公式：
> a[i,j] = a[i-1,j] + a[i,j-1] +**aa[i,j]**- a[i-1,j-1]
> -&gt;
> **aa[i,j]**= a[i,j] - a[i-1,j] - a[i,j-1] + a[i-1,j-1]
> 差分数组 b 就是aa数组， 就应该是 b[i,j] = a[i,j] - a[i-1,j] - a[i,j-1] + a[i-1,j-1]这是二维差分推导过程。三维也是一样。

> ![7643c21f481212243d176153dcfa0bf2.jpg](https://pub-ccd5622eabb54b4a81678003778ddce1.r2.dev/PicGo/ad6e9a38c36300ef7d059265be0809a6a959170ddb699a4b3b7a869ace48500b.jpg)
> **对比一维：**
> **差分数组的逆运算就是差分数组的前缀和。区间修改操作之后，我们要获得原数组的单点值，就需要差分数组的逆运算，也就是前缀和计算。**
> b[i] = a[i] - a[i-1] 区间修改后， 逆运算本应为：s[i] = s[i-1] + b[i] 。
> 我们使用这种形式，少开一个前缀和数组：b[i] +=b[i-1]
> 增量表示，b数组不初始化。也即是b[i] = 0, 区间修改后，逆运算本应为：s[i] = s[i-1] + b[i] , a[i] += s[i]
> 我们使用这种形式，少开一个前缀和数组：b[i] +=b[i-1]; a[i] += b[i]。
> 本质就是不开辟s数组，而是继续沿用b数组去逆运算。
> **对于二维：**
> b[i,j] = a[i,j] - a[i-1, j] - a[i, j-1] + a[i-1, j-1] 区间修改后逆运算(前缀和)本应为：s[i,j] = b[i,j] + s[i-1,j] + s[i,j-1] - s[i-1,j-1]
> 我们使用这种形式，少开一个前缀和数组：b[i,j] += b[i-1,j] + b[i,j-1] - b[i-1,j-1]
> b[i,j] = 0, 区间修改后，逆运算(前缀和)本应为：s[i,j] = b[i,j] + s[i-1,j] + s[i,j-1] - s[i-1,j-1] a[i,j] += s[i,j] s[i,j]是（1，1）到（i,j）的子矩阵的区间和。
> 我们使用这种形式，少开一个前缀和数组：b[i,j] += b[i-1,j] + b[i,j-1] - b[i-1,j-1]; a[i,j] +=b[i,j]

### 初始化O(n*m)

> 我们保证**逆运算**后的差分数组 b 是保存原数组 a**每一个元素**的**增量**。因此差分数组 b 初始化为0

### 区间修改O(1)

> 我们将上述①②③④操作封装成一个插入函数:

```java
void insert(int x1,int y1,int x2,int y2,int c)
{     //对b数组执行插入操作，等价于对a数组中的(x1,y1)到(x2,y2)之间的元素都加上了c
    b[x1][y1] += c;
    b[x2 + 1][y1] -= c;
    b[x1][y2 + 1] -= c;
    b[x2 + 1][y2 + 1] += c;
}
```

### 逆运算差分O(n*m)

> 逆运算差分获得原数组每一个元素的增量。用于多次区间修改后，的k次单点查询。如果修改和查询是交替进行。那么每次查询前都要逆运算差分数组来获取每个元素的增量。这时最终时间复杂度是O(n*m*k)，这时，我们需要用二维树状数组对差分数组进行维护。

```java
for(int i = 1; i<=n; i++){
    for(int j = 1; j<=m; j++){
        b[i,j] += b[i-1][j] + b[i,j-1] - b[i-1,j-1];
        a[i,j] +=b[i,j];
    }
}
或者分开写：可读性提高
for(int i = 1; i<=n; i++){
    for(int j = 1; j<=m; j++){
        //先计算出每一个元素的增量
        b[i,j] += b[i-1][j] + b[i,j-1] - b[i-1,j-1];
    }
}
for(int i = 1; i<=n; i++){
    for(int j = 1; j<=m; j++){
        a[i,j] +=b[i,j];
    }
}
```

### 试题一：差分矩阵

> acwing的题

> ![image.png](https://pub-ccd5622eabb54b4a81678003778ddce1.r2.dev/PicGo/82f55eb5f9dca0c0e317e927615fa411afa1312f9fe7273db611ba3e5cb95cd1.png)

输入样例：

```java
3 4 3
1 2 2 1
3 2 2 1
1 1 1 1
1 1 2 2 1
1 3 2 3 2
3 1 3 4 1
```

输出样例：

```java
2 3 4 1
4 3 4 1
2 2 2 2
```

【思路分析】

> 暴力：如果每次都是整个矩阵进行修改，每次修改都O(n*m), 那么q=100000次就是O(n*m*1000000),最差，1e11
> 差分：初始化O(n*m), 每次修改O(1)，逆运算差分O(n*m) 输出结果O(n*m), 最终O(n*m)

```java
import java.io.BufferedInputStream;
import java.io.BufferedReader;
import java.io.BufferedWriter;
import java.io.IOException;
import java.io.InputStreamReader;
import java.io.OutputStreamWriter;
import java.io.PrintWriter;
import java.io.StreamTokenizer;

public class Main {
	static int n;
	static int m;
	static int q;
	static int[][] a;
	static int[][] b;

	public static void main(String[] args) throws IOException {

		n = nextInt();
		m = nextInt();
		q = nextInt();
		a = new int[n + 1][m + 1];
		//b的大小要比a大一点，不然x2+1或者y2+1就越界了。
		b = new int[n + 2][m + 2];
		for (int i = 1; i <= n; i++) {
			for (int j = 1; j <= m; j++) {
				a[i][j] = nextInt();
			}
		}
		while (q-- > 0) {
			int x1 = nextInt();
			int y1 = nextInt();
			int x2 = nextInt();
			int y2 = nextInt();
			int c = nextInt();
			update(x1, y1, x2, y2, c);
		}
		// 逆运算差分
		for (int i = 1; i <= n; i++) {
			for (int j = 1; j <= m; j++) {
				b[i][j] += b[i - 1][j] + b[i][j - 1] - b[i - 1][j - 1];
				a[i][j] += b[i][j];
			}
		}
		// 输出结果
		for (int i = 1; i <= n; i++) {
			for (int j = 1; j <= m; j++) {
				wt.print(a[i][j] + " ");
			}
			wt.println();
			wt.flush();
			
		}
		wt.close();

	}

	static void update(int x1, int y1, int x2, int y2, int c) {
		b[x1][y1] += c;
		b[x1][y2 + 1] -= c;
		b[x2 + 1][y1] -= c;
		b[x2 + 1][y2 + 1] += c;
	}

	static BufferedReader read = new BufferedReader(new InputStreamReader(System.in));
	static StreamTokenizer token = new StreamTokenizer(
			new BufferedReader(new InputStreamReader(new BufferedInputStream(System.in))));

	static int nextInt() throws IOException {
		token.nextToken();
		return (int) token.nval;
	}

	static PrintWriter wt = new PrintWriter(new BufferedWriter(new OutputStreamWriter(System.out)));
}
```
