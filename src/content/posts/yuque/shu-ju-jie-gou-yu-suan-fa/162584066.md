### 试题一: 矩形交集【编程题】

> 时间限制: 1.0s 内存限制: 512.0MB 本题总分： 10 分

**<span style="color: var(--cm-text-color-regular)">【问题描述】</span>**

> <span style="color: rgb(77, 77, 77)">主函数输入两个矩形，调用isOverlap函数判断是否重叠。</span>

**<span style="color: var(--cm-text-color-regular)">【输入格式】</span>**

> <span style="color: rgb(77, 77, 77)">判断次数</span>
> <span style="color: rgb(77, 77, 77)">矩形1的对角线顶点坐标x1、y1、x2、y2</span>
> <span style="color: rgb(77, 77, 77)">矩形2的对角线顶点坐标x1、y1、x2、y2</span>

**<span style="color: var(--cm-text-color-regular)">【输出格式】</span>**

> <span style="color: rgb(77, 77, 77)">是否重叠</span>

**<span style="color: var(--cm-text-color-regular)">【样例输入】</span>**

> <span style="color: rgb(77, 77, 77)">3</span><span style="color: var(--cm-text-color-regular)"></span><span style="color: rgb(77, 77, 77)">1 5 2 9</span><span style="color: var(--cm-text-color-regular)"></span><span style="color: rgb(77, 77, 77)">1 3 2 4</span><span style="color: var(--cm-text-color-regular)"></span><span style="color: rgb(77, 77, 77)">5 6 7 8</span><span style="color: var(--cm-text-color-regular)"></span><span style="color: rgb(77, 77, 77)">5 7 7 9</span><span style="color: var(--cm-text-color-regular)"></span><span style="color: rgb(77, 77, 77)">2 5 1 0</span><span style="color: var(--cm-text-color-regular)"></span><span style="color: rgb(77, 77, 77)">9 4 2 9</span>

**<span style="color: var(--cm-text-color-regular)">【样例输出】</span>**

> <span style="color: rgb(77, 77, 77)">not overlapped</span><span style="color: var(--cm-text-color-regular)"></span><span style="color: rgb(77, 77, 77)">overlapped</span><span style="color: var(--cm-text-color-regular)"></span><span style="color: rgb(77, 77, 77)">overlapped</span>

**<span style="color: var(--cm-text-color-regular)">【评测用例规模与约定】</span>**

**<span style="color: var(--cm-text-color-regular)">【思路分析】</span>**

> <span style="color: rgb(77, 77, 77)">首先它给出的只是对角线顶点坐标并没有说是哪个对角线，所以我们首先要处理一下，把它变成次对角线的两个坐标，即</span>**<span style="color: rgb(77, 77, 77)">左下角</span>**<span style="color: rgb(77, 77, 77)">的坐标和</span>**<span style="color: rgb(77, 77, 77)">右上角</span>**<span style="color: rgb(77, 77, 77)">的坐标，具体方法是把大的坐标放到右边，小的放左边，代码中的有交换逻辑就是用来干这个的。</span>
> <span style="color: rgb(77, 77, 77)">完了之后怎么知道重不重叠呢？</span>
> <span style="color: rgb(77, 77, 77)">判断不重叠应该更方便一些，那什么情况下两个矩阵不重叠？</span>
> <span style="color: rgb(77, 77, 77)">就是一个矩阵在另一个矩阵的周围，以一个矩阵为中心，四条边可以划出八个区域，这八个区域又可分成上下左右四种情况，对于每一种情况都只是需要进行坐标与坐标之间的比较就行。</span>
> <span style="color: rgb(77, 77, 77)">还要注意的是，在这道题，沾边也算重叠。</span>

### 试题二: 矩形交集和并集【编程题】

> <span style="color: rgb(77, 77, 77)">能包含这两个矩形的最小矩形。它一定是存在的。</span>
> <span style="color: rgb(77, 77, 77)">本题目的要求就是：由用户输入两个矩形的坐标，程序输出它们的交集和并集矩形。</span>

### 试题三: 是否构成矩形【编程题】

> 时间限制: 1.0s 内存限制: 512.0MB 本题总分： 10 分

**<span style="color: var(--cm-text-color-regular)">【问题描述】</span>**

> 题意：分别输入四条边的两个顶点$(x_1, y_1)和(x_2, y_2)$，判断这四条边能否构成一个正面积的矩形。

**<span style="color: var(--cm-text-color-regular)">【输入格式】</span>**

> 输入包含四行，每行包含四个整数，表示门的四条边的端点坐标(x1,1)和(x2,2)

**<span style="color: var(--cm-text-color-regular)">【输出格式】</span>**

> <span style="color: rgb(77, 77, 77)">如果这四条边可以构成一个正面积的矩形，输出YES",否则输出"“NO”。</span>

**<span style="color: var(--cm-text-color-regular)">【样例输入】</span>**

> 1 1 1 2
> 1 2 3 2
> 3 2 3 1
> 3 1 1 1

**<span style="color: var(--cm-text-color-regular)">【样例输出】</span>**

> YES

**<span style="color: var(--cm-text-color-regular)">【评测用例规模与约定】</span>**

> <span style="color: var(--cm-text-color-regular)">对于 100 %的评测用例， 无</span>

**<span style="color: var(--cm-text-color-regular)">【思路分析】</span>**

> 思路：
> 1.是否分别有两条边平行于x轴和y轴
> 2.满足1的情况下，平行于x轴和平行于y轴的两条边长度相等
> 3.四条边首尾相连由于题目只包含8个坐标，判断条件可以简化：
> 1.是否分别有两条边平行于x轴和y轴
> 2.每个点恰好出现了两次 -&gt; 与输入相关

**解法：**

```java
public class Test1 {
	public static void main(String[] args) {
		int i = 0;
		Scanner scanner = new Scanner(System.in);
		Map<Point, Integer> pointCount = new HashMap<>(); 
		int verticleCount = 0;
		int horizonCount = 0;
		while(i<4) {
			//统计每一个点出现的次数
			Point p1 = new Point(scanner.nextDouble(), scanner.nextDouble());
			int intValue = 0;
			intValue = pointCount.get(p1) == null ? 0 : pointCount.get(p1).intValue();
			pointCount.put(p1, intValue + 1);
			
			Point p2 = new Point(scanner.nextDouble(), scanner.nextDouble());
			
			intValue = pointCount.get(p2) == null ? 0 : pointCount.get(p2).intValue();
			pointCount.put(p2, intValue + 1);
			
			//统计有多少与坐标轴平行的线
			
			if(p1.x == p2.x) horizonCount++;
		
			if(p1.y == p2.y) verticleCount++;
			
			i++;
		}
		
		Set<Point> keySet = pointCount.keySet();
		Iterator<Point> iterator = keySet.iterator();
		int count = 0;// 出现了两次的点的个数，如果是count = 4的话，那么满足每个点恰好出现了两次
		while(iterator.hasNext()) {
			Point key = iterator.next();
			if(pointCount.get(key) == 2) count ++ ;
		}
		
		if(horizonCount == 2 && verticleCount == 2 && count == 4)
			System.out.println("能构成矩形");
		else System.out.println("不能构成矩形");
	}

}
class Point{
	double x;
	double y;
	
	
	public Point() {
		super();
		// TODO Auto-generated constructor stub
	}
	
	
	public Point(double x, double y) {
		super();
		this.x = x;
		this.y = y;
	}


	@Override
	public int hashCode() {
		return Objects.hash(x, y);
	}
	@Override
	public boolean equals(Object obj) {
		if (this == obj)
			return true;
		if (obj == null)
			return false;
		if (getClass() != obj.getClass())
			return false;
		Point other = (Point) obj;
		return Double.doubleToLongBits(x) == Double.doubleToLongBits(other.x)
				&& Double.doubleToLongBits(y) == Double.doubleToLongBits(other.y);
	}
	
}
```

### 试题四：任意多边形面积计算【编程题】

> 时间限制: 1.0s 内存限制: 512.0MB 本题总分： 10 分

**<span style="color: var(--cm-text-color-regular)">【问题描述】</span>**

> 题意：分别输入N个顶点$(x_1, y_1)，(x_2, y_2)....(x_n, y_n)$，求出这N个顶点构成的多边形的面积（凸凹都可能）

**<span style="color: var(--cm-text-color-regular)">【输入格式】</span>**

> 输入包含四行，第一行输入N，第二行输入N个顶点$(x_1, y_1)，(x_2, y_2)....(x_n, y_n)$

**<span style="color: var(--cm-text-color-regular)">【输出格式】</span>**

> <span style="color: rgb(77, 77, 77)">输出面积（保留两位小数）</span>

**<span style="color: var(--cm-text-color-regular)">【样例输入】</span>**

> 8
> 1 1 1 2 1 2 3 2 3 2 3 1 3 1 1 1

**<span style="color: var(--cm-text-color-regular)">【样例输出】</span>**

> YES

**<span style="color: var(--cm-text-color-regular)">【评测用例规模与约定】</span>**

> <span style="color: var(--cm-text-color-regular)">对于 100 %的评测用例， 无</span>

**<span style="color: var(--cm-text-color-regular)">【思路分析】</span>**

> 使用公式$S = \frac{1}{2} * \lvert \sum_{k=1}^{N}{ \left ( \overrightarrow p_k \times \overrightarrow { p_{k+1} } \right )} \rvert$该公式可以求凸凹，顺逆，但是输入的点必须顺逆，不然连线会交叉。公式来源如下：
> 【如何编程计算任意多边形的面积？理解了之后发现好简单！】 我们这里使用点到原点的直线。[https://www.bilibili.com/video/BV1dv4y1R7Jm/?share_source=copy_web&vd_source=11b35d5d86259f941815a9ac2ec8e354](https://www.bilibili.com/video/BV1dv4y1R7Jm/?share_source=copy_web&vd_source=11b35d5d86259f941815a9ac2ec8e354)

```java
public class 任意多边形的面积 {
	public static void main(String[] args) {
		int N = nextInt();
		if(N < 0 ) System.out.println(0);
		int cnt = 0;
		Point temp = null , i , j = null;
		double sum = 0;
		if(N-- > 0) {
			j = new Point(nextDouble(), nextDouble());
			temp = j;//保存第一个点
		}
		while(cnt<N) {
			i = j;
			j = new Point(nextDouble(), nextDouble());
			sum += crossProduct(i, j);
			
			
			cnt++;
		}
		//还有最后一个点与第一个点进行叉乘
		sum +=crossProduct(j, temp);
		
		System.out.println(1.0 / 2 * Math.abs(sum));
		
	}

		return i.x * j.y - i.y * j.x;
```
