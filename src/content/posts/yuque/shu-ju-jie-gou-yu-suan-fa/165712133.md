# 二维树状数组

![image.png](https://pub-ccd5622eabb54b4a81678003778ddce1.r2.dev/PicGo/cbe1a788d62d28d14ef544c23a92c05d2129cd1def2fc57a1237f28185d3838f.png)

## 单点修改，区间查询

### 1、区间和查询

> 使用树状数组 t 对原数组 a 进行前缀和维护。

> 暴力：**单点修改**O(1), 区间和查询O(n*m) , k次修改后，再来k次查询，最终O(n*m*k)
> 前缀和：单点修改O(n*m),区间和查询O(1)，k次修改后，再来k次查询，最终O(n*m*k)。适用于没有修改，或常数次修改，这样最终时间复杂度只有O(K*n*m)，K次查询。
> 树状数组：**单点修改**O(logN*logN)先对行进行修改，然后对列进行修改，区间和查询O(logN*logN)。k次修改后，再来k次查询，最终O(logN*logN * k)

#### 1、单点修改O(logN*logN)

```java
* 单点修改 O(logN*logN)找到所有包含该点的序列进行修改
*/
static void add(int x, int y, int c) {
    ////当x是固定值时，这就是一个横向的一维树状数组的操作
    for(;x<=n; x+=lowbit(x)){
        for(int ty = y; ty<=m; ty+=lowbit(ty)){
            t[x][ty] += c;
        }
    }
}
```

```java
/**
 * 区间和查询 O(logN*logN)
 *
 */
static int query(int x1, int y1, int x2, int y2) {
    //二维前缀和推导出的公式
    return ask(x2, y2) - ask(x1 - 1, y2) - ask(x2, y1 - 1) + ask(x1 - 1, y1 - 1);
}

/**
 * 前x项和 O(logN*logN)这是最坏情况，最好是O(1)直接查找到对应前缀和等
 */
static int ask(int x, int y) {
    int sum = 0;
    for (; x > 0; x -= lowbit(x)) {
        for (int ty = y; ty > 0; ty -= lowbit(ty)) {
            sum += t[x][ty];
        }
    }
    return sum;
}
```

#### 3、树状数组初始化

##### 1、使用前缀和数组O(N*M）

> 优点：比使用add(x,y,k)方法的初始化要快，因为每次执行t[i][j] = s[i][j] - s[i][j - (j & -j)];的时间复杂度为O(1)
> - 开了前缀和数组s我们可以 **在原数组未修改** 之前来 **查询区间和** O(1)，但是当原数组 a 修改后，s数组又没有O(n*m)修改，此时就不能使用s数组了。因此，一般该s数组仅用于树状数组 t 的 **初始化** 。
> 缺点：这种方法需要开一个与原数组 a 相同长度的前缀和数组 s ，浪费空间。

```java
for (int i = 1; i <= n; i++) {
    for (int j = 1; j <= m; j++) {
        a[i][j] = nextInt();
        s[i][j] = s[i][j - 1] + a[i][j];

for (int i = 1; i <= n; i++)
Arrays.fill(s[i], 0);

// 二维树状数组是对每行的前缀和再在列方向进行修改。
for (int j = 1; j <= m; j++) {
```

### 2、区间最值查询

> 使用树状数组 t 对原数组 a 进行前缀中最值维护。

#### 1、单点修改O(logN*logN*logN)【区间最值更新O(logN*logN*logN)】

树状数组<span style="color: rgb(77, 77, 77)">t[x] 保存着 [x−lowbit(x)+1,x] 之间的最值。</span>

![image.png](https://pub-ccd5622eabb54b4a81678003778ddce1.r2.dev/PicGo/cbe1a788d62d28d14ef544c23a92c05d2129cd1def2fc57a1237f28185d3838f.png)

> 先对**将该结点的最值修改为w，然后将该结点与它该行所有子结点进行遍历比较更新最值**。然后找**该元素结点对应的行数查找列方向上的子结点行，然后进行子结点行上对应列数位置进行遍历更新。假如 t 大小4*4。修改t[4][3]先看后面的3，发现行上要比较儿子结点{a[4][3]本身，t[4][2]}。再看前面的3，发现行4的子结点行是3 2。因此要比较行3上min{min , t[3][3] } 不用min{a[3][3]，t[3][2]}，因为t[3][3]已经是min{a[3][3]，t[3][2]}。还要比较min{min,, t[2][3]}不用min{a[2][3] , t[2][2]}，因为t[2][3]已经是min{a[2][3]，t[2][2]}。这一步做完就是O(logN*logN)了。然后还要修改包含t[4][3]的所有祖先结点和祖先行。**

输入：

```java
3 3         最值         t数组
1 2 3      1 1 1         1 1 3   
4 5 6      1 1 1         1 1 3
7 8 9      1 1 1         7 7 9
(1,1)修改成1000后
3 3         最值         t数组        
1000 2 3  1000 2 2      1000 2 3     
4    5 6  4    2 2      4    2 3     
7    8 9  4    2 2      7    7 9
```

```java
static void update(int x, int y, int w) {
    t[x][y]=a[x][y]=w;//原数组也要跟着改变，求区间最大值要用

    //对当前行的祖先行进行更新。
    while(x<=n) {
        //对当前行上的祖先结点进行更新
        int lx = x & -x;
        int ty = y;
        while(ty<=m) {
            t[x][ty] = a[x][ty];//必须有！不然原来的最小值可能还会存在。
            int ly = ty & -ty;
            // 遍历所有子结点
            for (int j = 1; j < ly; j <<= 1) {
                t[x][ty] = Math.min(t[x][ty], t[x][ty - j]);
            }
            //儿子行有哪些。小于lx的都是。
            for (int i = 1; i < lx; i <<= 1) {
                //儿子行上对于y的子结点。其实不用进行行方向的对比。因为
                t[x][ty] = Math.min(t[x][ty], t[x - i][ty]);
            }
            ty +=ly;
        }
        x += lx;
    }

}
```

#### 2、区间最值查询O(N*logN)

> 暴力：单点修改O(1), 区间最值查询O(n*m) , k次修改后，再来k次查询，最终O(n*m*k)
> 前缀和维护不了区间最值：如果【1，3】上最大值是a[1] = 10000,那么根据前缀和方法，【1，10】上如果最大值也是10000,那么我们查找不了【4,10】上的最大值。一维不行，二维也应该不行。
> 树状数组：单点修改O(logN*logN*logN)【区间最值更新O(logN*logN*logN)】，区间最值查询O(N*logN)。k次修改后，再来k次查询，最终O( N*logN * k)

```java
static int ask(int x1, int y1, int x2, int y2) {
    int ans = a[x2][y2];
    // 所有每行的结果进行最值查询
    while (x1 <= x2) {
        int lx = x2 - (x2 & -x2) + 1;
        if (lx >= x1) {
            // 每一行最值查询
            int l = y1;
            int r = y2;
            while (l <= r) {
                int ly = r - (r & -r) + 1;
                if (ly >= l) {
                    ans = Math.min(ans, t[x2][r]);
                    r = ly - 1;
                } // r变为 r - lowbit(r)
                else {
                    ans = Math.min(ans, a[x2][r]);
                    r--;
                }
            }
            x2 = lx - 1;
        } else {
            //O(N)
            for(int  i = y2; i>=y1; i--){
                ans = Math.min(ans, a[x2][i]);
            }
            x2--;
        }

    }
    return ans;
}
```

#### 3、树状数组初始化O(N*M*logN)

> init()方法相比于update方式就是少了while循环，其他都没有改变。

```java
// 该方法要在原数组 a 初始化时执行，并从最树底层开始初始化
// 循环调用形式：init(i,j,a[i][j]);
static void init(int x, int y, int w) {

    t[x][y] = w;
    //当前x行中的最小值。
    int ly = y & -y;
    // 遍历所有子结点
    for (int j = 1; j < ly; j <<= 1) {
        t[x][y] = Math.min(t[x][y], t[x][y - j]);
    }
    //当前y列中的最小值。
    int lx = x & -x;
    for (int i = 1; i < lx; i <<= 1) {
        t[x][y] = Math.min(t[x][y], t[x - i][y]);
    }

}
```

## 区间修改，单点查询

> 【区间修改，单点查询】就没有那么多分类了。

> 使用树状数组 t 对原数组的**差分数组**d(diff) 进行前缀和维护。

> **暴力**：区间修改O(n*m), 单点查询O(1) , k次修改后，再来k次查询，最终O(n*m*k)
> **差分数组**：区间修改O(1), 单点查询O(n*m): 因为要**逆运算差分数组**来获取原数组 a 每一个元素的**增量**。因此是O(n*m)的时间复杂度。k次修改后，再来k次查询，最终O(n*m)。但倘若查询后，又修改，这时就**又要逆运算差分数组**来获取原数组 a 每一个元素的**增量**。如果出题人交替发出请求来卡你。这样最终时间复杂度可能是O(n*m*k)，m为**不连续**的查询次数。**连续就相当于只进行一次逆运算。**
> **树状数组**：我们使用二维树状数组维护二维差分数组，区间修改【相当于4个单点修改】O(logN*logN)，单点查询O(logN*logN)【我们通过**树状数组**来**逆运算**差分数组 d ，也就是求差分数组 d 的前缀和、原数组的每个元素的增量】。k次修改后，再来k次查询，最终O(logN*logN * k)

#### 1、树状数组初始化O(1)

> 因为我们保证**逆运算**后的差分数组 d 是保存原数组 a**每一个元素**的**增量。**因此差分数组初始化为0，而树状数组又是维护差分数组的前缀和的，因此我们不用树状数组初**始化为0**就行。

#### 3、单点查询O(logN*logN)

```java
/*
 * 前x项和 O(logN*logN)这是最坏情况，最好是O(1)直接查找到对应前缀和等
 */
static int ask(int x, int y) {
    int sum = 0;
    for (; x > 0; x -= lowbit(x)) {
        for (int ty = y; ty > 0; ty -= lowbit(ty)) {
            sum += t[x][ty];
        }
    }
    return sum;
}
```

> 差分数组b[i,j]的前缀和。就是s[i,j]，即为a[i,j]的增量。之前是：b[i,j] = 0, 区间修改后，逆运算(前缀和)为：s[i,j] = b[i,j] + s[i-1,j] + s[i,j-1] - s[i-1,j-1] a[i,j] += s[i,j] s[i,j]是（1，1）到（i,j）的子矩阵的区间和。 我们使用这种形式，少开一个前缀和数组：b[i,j] += b[i-1,j] + b[i,j-1] - b[i-1,j-1]; a[i,j] +=b[i,j]。
> 这里我们不进行双重for循环得到s[i,j]，也就是b[i,j]的前缀和。我们使用二维树状数组来获取b[i,j]的前缀和。而b[i,j]的前缀和恰好是a[i,j]的增量。
> 一维：前缀和求导公式是d[i] +=d[i-1] ,使用一维树状数组维护：直接ask(x) O(N) -&gt;O(logN)
> 二维：前缀和求导公式是b[i,j] += b[i-1,j] + b[i,j-1] - b[i-1,j-1] ,使用二维树状数组维护：直接ask(x，y) O(N*M) -&gt;O(logN*logN)

> **暴力**：区间修改O(n*m), 区间和查询O(n*m) , k次修改后，再来k次查询，最终O(n*m*k)
> **单个树状数组**：区间修改O(logN*logN)，区间查询O(N*logN*logN)【我们通过**树状数组**来**逆运算**差分数组 d ，也就是求差分数组 d 的前缀和、原数组的每个元素的增量】。k次修改后，再来k次查询，最终O(N*logN * logN * k)
> **两个树状数组：**区间修改O(logN*logN)，区间查询O(logN*logN)【一个树状数组用来维护差分数组 d 的前缀和，一个树状数组用来维护 i * d[ i]的前缀和。】
> 因为树状数组中维护的差分数组初始化为0，也就是逆运算后是原数组 a 的增量，因此需要在加一个前缀和数组进行对原数组 a 的区间和维护。在不修改的前提下，前缀和维护区间的和为O(1)大于树状数组O(logN*logN)

#### 树状数组初始化O(1)

> 因为我们保证**逆运算**后的差分数组 d 是保存原数组 a**每一个元素**的**增量。**因此差分数组初始化为0，而树状数组又是维护差分数组的前缀和的，因此我们不用树状数组初**始化为0**就行。

```java
/**
* 单点修改 O(logN*logN)找到所有包含该点的序列进行修改
*/
static void add(int x, int y, int c) {
    ////当x是固定值时，这就是一个横向的一维树状数组的操作
    for(;x<=n; x+=lowbit(x)){
        for(int ty = y; ty<=m; ty+=lowbit(ty)){
            t1[x][ty] += c;
            t2[x][ty] += c*x;
            t3[x][ty] += c*y;
            t4[x][ty] += c*x*y;
        }
    }
}
```

```java
static void update(int x1,int y1,int x2,int y2,int c)
```

#### 区间查询O(logN*logN)

![image.png](https://pub-ccd5622eabb54b4a81678003778ddce1.r2.dev/PicGo/96ff71295984f69ccfdcd39483c7ce5a193b534827fb1320c5289e06a09d80d3.png)

> 上图是一维的区间和[1,x]，我们发现，是枚举每一个x,求得b[i]的前缀和，也就是每一个a[i]对应的增量。
> 二维上应该就是：$\sum_i^x\sum_j^y\sum_h^i\sum_k^jb[h][k]$遍历矩阵中每一个元素a[i][j]的对应的增量。
> 首先，类比一维数组，统计一下每个 b[h][k] 出现过多少次。b[1][1] 出现了 x * y 次， b[1][2] 出现了 x * (y - 1)次......
> 因此 b[h][k] 就出现了 (x - h + 1) * (y - k + 1) 次。
> 那么这个式子就可以写成：
> $\sum_i^x\sum_j^yb[i][j] * (x + 1 - i) * (y + 1 - j)$
> 把这个式子展开，就得到：
> $(x + 1) * (y + 1) * \sum_i^x\sum_j^yb[i][j] - (y + 1)* \sum_i^x\sum_j^yb[i][j] * i -(x + 1)* \sum_i^x\sum_j^yb[i][j] * j + \sum_i^x\sum_j^yb[i][j] * i *j$
> 那么我们要开四个树状数组，分别维护：
> $b[i][j]，b[i][j] * i，b[i][j] * j，b[i][j] * i *j$
> 至此，就可以解决区间求和的问题了。

```java
/**
查询区间(1,1)到(x,y)进行区间修改后的区间和
 */
static int ask(int x, int y) {
    int sum = s[x][y];//第x项原数组 a 的前缀和。后面有解释原因。
    for (; x > 0; x -= lowbit(x)) {
        for (int ty = y; ty > 0; ty -= lowbit(ty)) {
            sum += (x+1)*(y+1)*t1[i][j]-(y+1)*t2[i][j]-(x+1)*t3[i][j]+t4[i][j];
        }
    }
    return sum;
}
// 查询区间(x1,y1)到(x2,y2)进行区间修改后的区间和
static int real_ask(int x1, int y1, int x2, int y2){
    return ask(x2,y2) - ask(x2 - 1, y1) - ask(x1, y2 - 1) + ask(x1 - 1, y1 - 1);
}
```
