### 试题一: 取钱

> ![image.png](https://pub-ccd5622eabb54b4a81678003778ddce1.r2.dev/PicGo/9c51c2817fd1926813888b8e5ebe07e21e9785cd96da62e365dea7578ca27170.png)

【思路分析】

> ![tmp18DE.png](https://pub-ccd5622eabb54b4a81678003778ddce1.r2.dev/PicGo/72f0b4c82e1588aff59f382a3457da909bb7884b433d805c20d4fbdf896576f5.png)
> dp_i表示取钱总数 i , 我们看到这是线性的动态规划问题。
> 转移方程为：
> dp[i]=Math.min(dp[i-1],dp[i-4],dp[i-5],dp[i-10],dp[i-20])+1

```java
import java.io.IOException;
import java.util.Arrays;
import java.util.Scanner;

public class Main {
	static int[] a = {1,4,5,10,20};
	static Scanner scan = new Scanner(System.in);
	public static void main(String[] args) throws IOException {
	
		int[] dp = new int[(int)1e5];
		Arrays.fill(dp, (int)1e9);//初始化1e9
		dp[0] = 0;
		for(int i = 0 ; i<dp.length; i++) {
			for(int j : a) {
				if(i>=j)
				dp[i] = Math.min(dp[i-j]+1, dp[i]);
			}
		}
        //不能使用true!!!!
		while(scan.hasNextInt()) {
			int n = scan.nextInt();
			System.out.println(dp[n]);
		}
	}
}
```

### 试题二: 破损的台阶

> ![image.png](https://pub-ccd5622eabb54b4a81678003778ddce1.r2.dev/PicGo/9ad0b94b6ffdb24a61ab52e8c10d6bfafd959385766ebf7e6022d4f637907d27.png)

【思路分析】

> 共有n阶台阶，如果不考虑破损的情况。如果我们当前要到台阶2，那么走法数量：dp2 =dp0 + dp1,也就是从i-1,i-2上来。
> 考虑破损情况：
> 当前第 i 阶台阶是破损的台阶：dp[i] = -1;
> 当前第 i 阶台阶不是破损的台阶：
> 如果当i-1为破损台阶的话，就不能加上dp_{i-1}也就是不能从i-1台阶上来。
> 如果当i-2为破损台阶的话，就不能加上dp_{i-2}也就是不能从i-2台阶上来。
> 如果最终第n阶台阶是破损台阶的话，我们只有0种走法到地n阶台阶。

```java
import java.util.Scanner;

public class Main {
	static Scanner scan = new Scanner(System.in);

	public static void main(String[] args){

		long[] dp = new long[(int) 1e5 + 1];
		long mod = (long) 1e9 + 7;
		dp[0] = 1;// 不考虑破损情况，dp1 = dp0 , dp2 = dp0 + dp1
		int n = scan.nextInt();
		int m = scan.nextInt();// 破损的台阶数
		for (int i = 0; i < m; i++) {
			int k = scan.nextInt();
			dp[k] = -1;// 破损的台阶就置为-1
		}
		for (int i = 1; i <= n; i++) {
			if(dp[i] == -1) continue;
			if (i >= 1 && dp[i - 1] != -1)
				dp[i] += dp[i - 1] % mod;
			if (i >= 2 && dp[i - 2] != -1)
				dp[i] += dp[i - 2] % mod;
			dp[i] %= mod;
		}
		if(dp[n] == -1) System.out.println(0);
		else System.out.println(dp[n]);
	}

}
```

### 试题二: 传球游戏

> ![image.png](https://pub-ccd5622eabb54b4a81678003778ddce1.r2.dev/PicGo/4c41e3a4c66932a98ca3eafc3d7360c2d9a1d0e31c5683aaa60ee68b73b6b162.png)

【思路分析】

> ![image.png](https://pub-ccd5622eabb54b4a81678003778ddce1.r2.dev/PicGo/e74dd3439887f1bd9dc5ad771963de233749fb54b787b6d9c8f6a4b4c4cc1fb2.png)
> 1号同学，可以收到5号和2号传来的球，因此是一个二维DP,j+1就是右边同学传来，j-1就是左边传来，但是第0号同学，（我们可以设置二维DP从0开始，也可以不从0开始，但是为了取模的方便，我们从0开始），0-1就是负数了，因此需要+n,如果j-1是正数，+n取模n是没有影响的。
> 结论：为了取模的方便，我们从0开始。

```java
import java.util.Scanner;

public class Main {
	static Scanner scan = new Scanner(System.in);

	public static void main(String[] args){
		int n = scan.nextInt();
		int m = scan.nextInt();
		int[][] dp = new int[m+1][n];
		dp[0][0] = 1;

		for(int i = 1; i<=m; i++) {
			for(int j = 0; j<n; j++) {
				dp[i][j] += dp[i-1][(j+1)%n] + dp[i-1][(j-1+n)%n];
			}
		}
		//dp[m][1],dp[m][2]，，都可以，因为是一个环，任何人都可以是小蛮
		System.out.println(dp[m][0]);
	}

}
```

### 试题三: 摆花

> ![image.png](https://pub-ccd5622eabb54b4a81678003778ddce1.r2.dev/PicGo/914786114dca419f066275d402fa7dbeab99f811da399e4181d67414ab78fc90.png)

【思路分析】

> ![image.png](https://pub-ccd5622eabb54b4a81678003778ddce1.r2.dev/PicGo/404b59f309be9b5ceabbec39472e1fd35c8beb2160a7fae0acca526cdd75f235.png)
> dp[i][0] = 0, 0&lt;=i&lt;=n, 因为前i种花，总共摆0盆，都是1种方案，也就是不摆。
> 当i = 2时，前两种花，第一种花可以最少摆0盆，最多摆a\[1\](假如为4)盆，因此，总共摆了 j 盆，dp[i][j] += dp[i-1][j-0]+dp[i-1][j-1]+dp[i-1][j-2]+dp[i-1][j-3]+dp[i-1][j-4]。也就是第一种花可以摆 j-k盆。

```java
import java.util.Scanner;

public class Main {
	static Scanner scan = new Scanner(System.in);

	public static void main(String[] args){
		int n = scan.nextInt();
		int m = scan.nextInt();
		int[][] dp = new int[n+1][m+1];
		int[] a = new int[n+1];
		int mod = (int)1e6+7;
		for(int i = 1; i<=n; i++)
			a[i] = scan.nextInt();
		for(int i = 0; i<=n; i++) {
			dp[i][0] = 1;
		}
		for(int i = 1; i<=n; i++) {
			for(int j = 1; j<=m; j++) {
				for(int k = 0; k<=a[i] && k<=j; k++) {
					dp[i][j] += dp[i-1][j-k];
					dp[i][j] %= mod;
				}
			}
		}
		System.out.println(dp[n][m]);
	}

}
```

### 试题六：最少路径费

> ![QQ图片20240531104750.jpg](https://pub-ccd5622eabb54b4a81678003778ddce1.r2.dev/PicGo/e087527cf851a4dbcb5c33bcf34bc4d7ad5ee3b1dcb331e1ac4613266f6bc70f.jpg)
> 输入：
> 5
> 1 4 6 8 10
> 2 5 7 15 17
> 6 8 9 18 20
> 10 11 12 19 21
> 20 23 25 29 33

【思路分析】

> 1、2n-1步的意思就是不能走回头步。2、因为我们是求最小值，我们不能直接f[][] = min(),我们要将`f[0][0~n],f[0~n][0]`设置一堵墙，也就是最大值，防止从这些地方过来，这些地方没有赋值之前全都是 0

```java
import java.io.IOException;
import java.util.Arrays;
import java.util.Scanner;

public class Main {
	static Scanner scan = new Scanner(System.in);
	static int n;
	static int[][] w;
	static int[][] f;

	public static void main(String[] args) throws IOException {
		// 矩阵的大小
		n = Integer.parseInt(scan.nextLine());
		w = new int[n + 1][n + 1];
		f = new int[n + 1][n + 1];

		// 设置墙
		Arrays.fill(f[0], Integer.MAX_VALUE);
		for (int i = 0; i <= n; i++)
			f[i][0] = Integer.MAX_VALUE;

		for (int i = 1; i <= n; i++) {
			for (int j = 1; j <= n; j++) {
				w[i][j] = scan.nextInt();
			}
		}

		for (int i = 1; i <= n; i++) {
			for (int j = 1; j <= n; j++) {
				if(i == 1 && j == 1)f[i][j] = w[i][j];
				else f[i][j] = min(f[i - 1][j], f[i][j - 1]) + w[i][j];
			}
		}
		System.out.println(f[n][n]);
	}

	static int min(int a, int b) {
		return a < b ? a : b;
	}

}
```

【思路分析】

> ![2426aeddbed9394002c39d00c3e51b5a.jpg](https://pub-ccd5622eabb54b4a81678003778ddce1.r2.dev/PicGo/8d9145bb493c170fb6b3b1218520a010558d31e7f4fac1ae814483665dd7d0f3.jpg)
> 因为是走两次，如果我们先走一次（将走过的置为0），再走一次，会出现一个问题：第一次走出来最大值，但是第二次走出来，两次走出来的值相加不一定是两次总和中的最大值。因此我们需要两条路同时走，我们的状态方程也就变成了`f(i1,j1,i2,j2)`, f 维护两次路径之和的最大值。
> 又出现一个问题，当两条路径同时走时，两条路径可能会重合，这样当前这一步就必须只能添加一次`w(i1,j1)`,不能添加`w(i1,j1) + w(i2, j2)`了。我们要判断重合的情况：重合时必然：`k = i1 + j1 = i2 + j2`,又因为我们同时走两条路径，每一次迭代的时候，他们的的步数一定是相等的，因此我们使用拓展后的状态方程`f(k,i1,i2)`来表示两条路径这时的和的最大值。`j1 = k - i1 , j2 = k - i2`,判断是否重合：因为步数是一样的，如果我们`i1 = i2`的话，就**充分**证明了两条路径发生了重合。
> 闫氏分析法：如图，有四种情况。每一种情况转移的时候又要判断是否重合。

```java
import java.io.IOException;
import java.util.Scanner;

public class Main {
	static Scanner scan = new Scanner(System.in);
	static int n;
	static int[][] w ;
	static int[][][] f;

	public static void main(String[] args) throws IOException {
		// 矩阵的大小
		n = Integer.parseInt(scan.nextLine());
		w = new int[n +1][n + 1];
		f = new int[n * n + 1][n + 1][n + 1];

		// 非0值的点
		while (scan.hasNextLine()) {
			String string = scan.nextLine();
			String[] split = string.split(" ");
			int a = Integer.parseInt(split[0]);
			int b = Integer.parseInt(split[1]);
			int c = Integer.parseInt(split[2]);
			if (a == 0 && b == 0 && c == 0)
				break;
			w[a][b] = c;
		}

		for (int k = 2; k <= n + n; k++) {
			for (int i1 = 1; i1 <= n; i1++) {
				for(int i2 = 1; i2 <= n; i2++) {
					int j1 = k - i1; int j2 = k - i2;
					//区间判断，可能不用加，但是先加上再说
					if(j1 >= 1 && j1<=n && j2 >= 1 && j2 <= n) {
						//判断是否重合
						int t = w[i1][j1];
						if(i1 != i2) t+=w[i2][j2];
						//因为要判断四个情况的最大值，因此我们需要下述的比较方式
						f[k][i1][i2] = max(f[k][i1][i2], f[k-1][i1 - 1][i2 - 1] + t);
						f[k][i1][i2] = max(f[k][i1][i2], f[k-1][i1 - 1][i2] + t);
						f[k][i1][i2] = max(f[k][i1][i2], f[k-1][i1][i2 - 1] + t);
						f[k][i1][i2] = max(f[k][i1][i2], f[k-1][i1][i2] + t);

					}
				}
			}
		}
		System.out.println(f[n + n][n][n]);

	}
	static int max(int a, int b) {
		return a > b? a:b;
	}

}
```

import java.util.Scanner;

public class Main {

### 试题二: 最长公共连续子序列

#### 解法一

【思路分析】

> 从试题一: 最长公共子序列改编过来的。时间复杂度为O(n^2)

```java
import java.util.Scanner;

public class Main {
	static Scanner scan = new Scanner(System.in);

	public static void main(String[] args) {
		int n = scan.nextInt();
		int m = scan.nextInt();
		int[] a = new int[n + 1];
		int[] b = new int[m + 1];
		int[][] dp = new int[n + 1][m + 1];
		int max = 0;//保存答案
		for (int i = 1; i <= n; i++)
			a[i] = scan.nextInt();
		for (int i = 1; i <= m; i++)
			b[i] = scan.nextInt();

		for (int i = 1; i <= n; i++) {
			for (int j = 1; j <= m; j++) {
				if (a[i] == b[j])
					dp[i][j] = dp[i - 1][j - 1] + 1;
				max = Math.max(max,dp[i][j]);
			}
		}
		System.out.println(max);
	}
}
```

package OtherTests;

public class MaxStringTest {
    public static void main(String[] args) {
        String a = "12345";
        String b = "232145";
        String result = maxStringFromTwoStrings(a, b);
        System.out.println("两个字符串中相同的最大子串为： "+result);
    }

    public static  String maxStringFromTwoStrings(String s1 , String s2){
        String maxS = "";
        String temp = ""; //用于储存所有可能的子串
        for(int i = 0; i<s2.length(); i++){
            for(int x = 0; x<=i ; x++){//x等于i说明可以取到“单个字母”
                if(s1.contains(s2.substring(x,i+1))){//substring()方法是左闭右开的所以i要加1
                    temp = s2.substring(x,i+1);
                    if(temp.length() > maxS.length()){
                        maxS = temp;
                    }
                }
            }
        }
        return maxS;

    }
}
