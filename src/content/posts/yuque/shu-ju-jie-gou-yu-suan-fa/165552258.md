# Java数组排序

```java
import java.util.Arrays;
public class Main {
    public static void main(String[] args) {
    	//只能是Integer引用类型，才能定制化排序
		Integer[] arr = new Integer[] {0,0,1,2,3,4};
		//Arrays提供的sort都是左闭右开的。
		Arrays.sort(arr,1,arr.length,(o1,o2)->o2-o1);
		
		for(int y : arr) {
			System.out.print(y + " ");
		}
	}
}
```
