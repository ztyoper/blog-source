# debug

### 1.Q1

> 数据库注释乱码：
> sql中添加：
> SET NAMES utf8mb4; 的作用只是将当前交互的页面修改为 对应的 编码方式，数据库本身的编码方式并没有改变。

```plain
CREATE database if NOT EXISTS `ry-vue` default character set utf8mb4 collate utf8mb4_unicode_ci;
use `ry-vue`;

SET NAMES utf8mb4;
```
