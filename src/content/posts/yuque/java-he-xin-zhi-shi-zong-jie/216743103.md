# 嘉洋实习的一些总结

算法逻辑门户项目：

吊车支腿位完全伸出逻辑实现：通过调用 api 获得的 目标检测的 区域（两点坐标）+ 置信度 使用 iou 等方式去判断。

摄像头识别两人的逻辑实现（也叫摄像头遮挡判断逻辑）：使用滑动窗口

视频分析项目：

已分析文件导出为 zip 以及表格。（表格要求展示分析文件对应的图片使用 easyexcel 之前使用的都是 apache 的 poi）

修改已分析文件列表展示部分：添加上传人字段，所属区域等级，第一等级：单位，第二等级：采油厂， 第三等级：采油厂，第四等级 场站

文件上传项目：

修改文件上传接口：上传的文件要求在文件名上拼接上传人名称，上传人所属区域，以便通过所属区域进行数据展示过滤。也就是采油厂只能看到采油厂人以及下面所属的所有场站上传

的文件。

为什么不直接看数据库？因为上传到服务器本地的文件会被修改如文件名称，并且其他项目业务也要用到上传的文件。因此还弄了一个 springtask 进行定时刷新数据库上传文件元数据信息。（文件内容是数据，文件相关信息是元数据）
