# 执行计划八种访问类型详解

### <span style="color: rgb(64, 64, 64)">1. NULL</span>

**<span style="color: rgb(64, 64, 64)">性能最优</span>**<span style="color: rgb(64, 64, 64)"></span><span style="color: rgb(64, 64, 64)">- 无需访问表或索引即可获取结果</span>

**<span style="color: rgb(64, 64, 64)">特点</span>**<span style="color: rgb(64, 64, 64)">：</span>

- 查询不需要访问表或索引
- 直接从系统获取结果
- 极为罕见的情况

**<span style="color: rgb(64, 64, 64)">示例</span>**<span style="color: rgb(64, 64, 64)">：</span>

<span style="color: rgb(82, 82, 82)">sql</span>

<span style="color: rgb(82, 82, 82)">复制</span>

<span style="color: rgb(82, 82, 82)">下载</span>

<span style="color: rgb(73, 73, 73)">EXPLAIN SELECT 1+1;</span>

**<span style="color: rgb(64, 64, 64)">执行计划</span>**<span style="color: rgb(64, 64, 64)">：</span>

<span style="color: rgb(82, 82, 82)">text</span>

<span style="color: rgb(82, 82, 82)">复制</span>

<span style="color: rgb(82, 82, 82)">下载</span>

```plain
id | select_type | table | type | possible_keys | key  | key_len | ref  | rows | Extra
---+-------------+-------+------+---------------+------+---------+------+------+-------
1  | SIMPLE      | NULL  | NULL | NULL          | NULL | NULL    | NULL | NULL | No tables used
```

### <span style="color: rgb(64, 64, 64)">2. system</span>

**<span style="color: rgb(64, 64, 64)">性能极优</span>**<span style="color: rgb(64, 64, 64)"></span><span style="color: rgb(64, 64, 64)">- 系统表查询，仅返回一行结果</span>

**<span style="color: rgb(64, 64, 64)">特点</span>**<span style="color: rgb(64, 64, 64)">：</span>

- 查询系统表
- 表中只有一行数据
- 是const类型的特例

**<span style="color: rgb(64, 64, 64)">示例</span>**<span style="color: rgb(64, 64, 64)">：</span>

<span style="color: rgb(82, 82, 82)">sql</span>

<span style="color: rgb(82, 82, 82)">复制</span>

<span style="color: rgb(82, 82, 82)">下载</span>

```plain
-- 假设只有一行数据的系统表
EXPLAIN SELECT * FROM mysql.proxies_priv WHERE User = 'root';
```

**<span style="color: rgb(64, 64, 64)">执行计划</span>**<span style="color: rgb(64, 64, 64)">：</span>

<span style="color: rgb(82, 82, 82)">text</span>

<span style="color: rgb(82, 82, 82)">复制</span>

<span style="color: rgb(82, 82, 82)">下载</span>

<span style="color: rgb(73, 73, 73)">type: system</span>

### <span style="color: rgb(64, 64, 64)">3. const</span>

**<span style="color: rgb(64, 64, 64)">性能极优</span>**<span style="color: rgb(64, 64, 64)"></span><span style="color: rgb(64, 64, 64)">- 通过主键或唯一索引查询单条记录</span>

**<span style="color: rgb(64, 64, 64)">特点</span>**<span style="color: rgb(64, 64, 64)">：</span>

- 使用主键或唯一索引的等值查询
- 最多返回一行记录
- 查询被优化为常量

**<span style="color: rgb(64, 64, 64)">示例</span>**<span style="color: rgb(64, 64, 64)">：</span>

<span style="color: rgb(82, 82, 82)">sql</span>

<span style="color: rgb(82, 82, 82)">复制</span>

<span style="color: rgb(82, 82, 82)">下载</span>

<span style="color: rgb(73, 73, 73)">EXPLAIN SELECT * FROM users WHERE user_id = 100; -- user_id是主键</span>

**<span style="color: rgb(64, 64, 64)">执行计划</span>**<span style="color: rgb(64, 64, 64)">：</span>

<span style="color: rgb(82, 82, 82)">text</span>

<span style="color: rgb(82, 82, 82)">复制</span>

<span style="color: rgb(82, 82, 82)">下载</span>

```plain
type: const
key: PRIMARY
```

### <span style="color: rgb(64, 64, 64)">4. eq_ref</span>

**<span style="color: rgb(64, 64, 64)">性能极优</span>**<span style="color: rgb(64, 64, 64)"></span><span style="color: rgb(64, 64, 64)">- 多表连接中的主键/唯一索引等值匹配</span>

**<span style="color: rgb(64, 64, 64)">特点</span>**<span style="color: rgb(64, 64, 64)">：</span>

- JOIN操作中通过主键或唯一索引关联
- 对于前表的每一行，只匹配后表的一行
- 是JOIN操作中最理想的类型

**<span style="color: rgb(64, 64, 64)">示例</span>**<span style="color: rgb(64, 64, 64)">：</span>

<span style="color: rgb(82, 82, 82)">sql</span>

<span style="color: rgb(82, 82, 82)">复制</span>

<span style="color: rgb(82, 82, 82)">下载</span>

```plain
EXPLAIN SELECT * FROM orders 
JOIN users ON orders.user_id = users.user_id  -- user_id是主键
WHERE orders.order_id = 500;
```

**<span style="color: rgb(64, 64, 64)">执行计划</span>**<span style="color: rgb(64, 64, 64)">（users表部分）：</span>

<span style="color: rgb(82, 82, 82)">text</span>

<span style="color: rgb(82, 82, 82)">复制</span>

<span style="color: rgb(82, 82, 82)">下载</span>

```plain
type: eq_ref
key: PRIMARY
```

### <span style="color: rgb(64, 64, 64)">5. ref</span>

**<span style="color: rgb(64, 64, 64)">性能良好</span>**<span style="color: rgb(64, 64, 64)"></span><span style="color: rgb(64, 64, 64)">- 使用普通索引的等值查询</span>

**<span style="color: rgb(64, 64, 64)">特点</span>**<span style="color: rgb(64, 64, 64)">：</span>

- 使用非唯一索引进行等值查询
- 可能返回多行数据
- 比全表扫描快但比eq_ref慢

**<span style="color: rgb(64, 64, 64)">示例</span>**<span style="color: rgb(64, 64, 64)">：</span>

<span style="color: rgb(82, 82, 82)">sql</span>

<span style="color: rgb(82, 82, 82)">复制</span>

<span style="color: rgb(82, 82, 82)">下载</span>

```plain
-- 假设name字段有普通索引
EXPLAIN SELECT * FROM users WHERE name = '张三';
```

**<span style="color: rgb(64, 64, 64)">执行计划</span>**<span style="color: rgb(64, 64, 64)">：</span>

<span style="color: rgb(82, 82, 82)">text</span>

<span style="color: rgb(82, 82, 82)">复制</span>

<span style="color: rgb(82, 82, 82)">下载</span>

```plain
type: ref
key: idx_name
```

### <span style="color: rgb(64, 64, 64)">6. range</span>

**<span style="color: rgb(64, 64, 64)">性能中等</span>**<span style="color: rgb(64, 64, 64)"></span><span style="color: rgb(64, 64, 64)">- 索引范围扫描</span>

**<span style="color: rgb(64, 64, 64)">特点</span>**<span style="color: rgb(64, 64, 64)">：</span>

- 使用索引检索指定范围内的行
- 比全索引扫描(index)更高效
- 常见于范围条件查询

**<span style="color: rgb(64, 64, 64)">示例</span>**<span style="color: rgb(64, 64, 64)">：</span>

<span style="color: rgb(82, 82, 82)">sql</span>

<span style="color: rgb(82, 82, 82)">复制</span>

<span style="color: rgb(82, 82, 82)">下载</span>

```plain
EXPLAIN SELECT * FROM users 
WHERE age BETWEEN 20 AND 30;  -- age字段有索引
```

**<span style="color: rgb(64, 64, 64)">执行计划</span>**<span style="color: rgb(64, 64, 64)">：</span>

<span style="color: rgb(82, 82, 82)">text</span>

<span style="color: rgb(82, 82, 82)">复制</span>

<span style="color: rgb(82, 82, 82)">下载</span>

```plain
type: range
key: idx_age
```

### <span style="color: rgb(64, 64, 64)">7. index</span>

**<span style="color: rgb(64, 64, 64)">性能较差</span>**<span style="color: rgb(64, 64, 64)"></span><span style="color: rgb(64, 64, 64)">- 全索引扫描</span>

**<span style="color: rgb(64, 64, 64)">特点</span>**<span style="color: rgb(64, 64, 64)">：</span>

- 按索引顺序扫描全部或大部分索引条目
- 当Extra显示"Using index"时为覆盖索引
- 比ALL全表扫描稍好

**<span style="color: rgb(64, 64, 64)">示例</span>**<span style="color: rgb(64, 64, 64)">：</span>

<span style="color: rgb(82, 82, 82)">sql</span>

<span style="color: rgb(82, 82, 82)">复制</span>

<span style="color: rgb(82, 82, 82)">下载</span>

<span style="color: rgb(73, 73, 73)">EXPLAIN SELECT id FROM users; -- id是主键</span>

**<span style="color: rgb(64, 64, 64)">执行计划</span>**<span style="color: rgb(64, 64, 64)">：</span>

<span style="color: rgb(82, 82, 82)">text</span>

<span style="color: rgb(82, 82, 82)">复制</span>

<span style="color: rgb(82, 82, 82)">下载</span>

```plain
type: index
key: PRIMARY
Extra: Using index
```

### <span style="color: rgb(64, 64, 64)">8. ALL</span>

**<span style="color: rgb(64, 64, 64)">性能最差</span>**<span style="color: rgb(64, 64, 64)"></span><span style="color: rgb(64, 64, 64)">- 全表扫描</span>

**<span style="color: rgb(64, 64, 64)">特点</span>**<span style="color: rgb(64, 64, 64)">：</span>

- 没有使用任何索引
- 需要扫描整张表的所有行
- 大数据量表性能极差

**<span style="color: rgb(64, 64, 64)">示例</span>**<span style="color: rgb(64, 64, 64)">：</span>

<span style="color: rgb(82, 82, 82)">sql</span>

<span style="color: rgb(82, 82, 82)">复制</span>

<span style="color: rgb(82, 82, 82)">下载</span>

<span style="color: rgb(73, 73, 73)">EXPLAIN SELECT * FROM users WHERE gender = 'M'; -- gender字段无索引</span>

**<span style="color: rgb(64, 64, 64)">执行计划</span>**<span style="color: rgb(64, 64, 64)">：</span>

<span style="color: rgb(82, 82, 82)">text</span>

<span style="color: rgb(82, 82, 82)">复制</span>

<span style="color: rgb(82, 82, 82)">下载</span>

<span style="color: rgb(73, 73, 73)">type: ALL</span>

### <span style="color: rgb(64, 64, 64)">性能排序总结</span>

<span style="color: rgb(82, 82, 82)">text</span>

<span style="color: rgb(82, 82, 82)">复制</span>

<span style="color: rgb(82, 82, 82)">下载</span>

<span style="color: rgb(73, 73, 73)">NULL &gt; system &gt; const &gt; eq_ref &gt; ref &gt; range &gt; index &gt; ALL</span>

### <span style="color: rgb(64, 64, 64)">优化建议</span>

1. 尽量让查询达到const或eq_ref级别
2. 普通查询至少达到ref级别
3. 避免出现ALL类型的全表扫描
4. 对于index类型的全索引扫描，考虑是否必要
5. 使用EXPLAIN分析查询并创建合适的索引

#### **<span style="color: rgb(64, 64, 64)">关键结论</span>**

1. **<span style="color: rgb(64, 64, 64)">无WHERE条件的纯SELECT</span>**

- 通常是 <span style="color: rgb(64, 64, 64)">`index`</span> （全索引扫描）或 <span style="color: rgb(64, 64, 64)">`ALL`</span> （全表扫描）
- 若使用覆盖索引，会有 <span style="color: rgb(64, 64, 64)">`Using index`</span> 提示（性能稍好）

2. **<span style="color: rgb(64, 64, 64)">性能排序</span>** <span style="color: rgb(64, 64, 64)">`const`</span> &gt; <span style="color: rgb(64, 64, 64)">`eq_ref`</span> &gt; <span style="color: rgb(64, 64, 64)">`ref`</span> &gt; <span style="color: rgb(64, 64, 64)">`range`</span> &gt; <span style="color: rgb(64, 64, 64)">`index`</span> &gt; <span style="color: rgb(64, 64, 64)">`ALL`</span> 您的查询属于较后的 <span style="color: rgb(64, 64, 64)">`index`</span> 或 <span style="color: rgb(64, 64, 64)">`ALL`</span> ，需优化。
3. **<span style="color: rgb(64, 64, 64)">优化建议</span>**

- 添加WHERE条件利用索引
- 若必须全量查询，确保使用覆盖索引（如 <span style="color: rgb(64, 64, 64)">`INDEX(id, name)`</span> ）
- 大数据量时考虑分页查询
