# 注意事项

1. `select * from xxx` 尽量不要使用 `"*"` , 而是具体字段。
2. 当 `select * from xxx where id = xxx` 时，我们知道只可能返回一条结果。我们可以再加一个limit 1 来提高查询效率。告诉 SELECT 语句只需要返回一条记录即可。这样的好处就是 SELECT 不需要扫描完整的表，只需要检索到一条符合条件的记录即可返回。
3. 【强制】超过三个表禁止 join。需要 join 的字段，数据类型保持绝对一致；多表关联查询时， 保证被关联的字段需要有索引。说明：即使双表 join 也要注意表索引、SQL 性能。来源：阿里巴巴《Java开发手册》
