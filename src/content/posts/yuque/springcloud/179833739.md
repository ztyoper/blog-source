# 聚合类型

Elasticsearch 提供了多种聚合类型来满足不同的数据分析需求。聚合类型大致可以分为几大类：

1. **度量聚合 (Metrics Aggregations)** ：

- 这些聚合用于计算数值型字段的度量值，如平均值、总和、最小值、最大值等。
- **常见度量聚合** ：

- **Avg Aggregation** ：计算平均值。
- **Sum Aggregation** ：计算总和。
- **Min Aggregation** ：找出最小值。
- **Max Aggregation** ：找出最大值。
- **Stats Aggregation** ：计算多个度量值，包括最小值、最大值、平均值和总和。
- **Extended Stats Aggregation** ：除了基本的度量值外，还支持计算标准差等额外统计信息。
- **Cardinality Aggregation** ：估计唯一值的数量。

1. **桶聚合 (Bucket Aggregations)** ：

- 这些聚合用于将数据分组到不同的桶中。
- **常见桶聚合** ：

- **Terms Aggregation** ：根据字段的值将文档分组到不同的桶中。
- **Histogram Aggregation** ：将数值型字段的值分组到区间内。
- **Date Histogram Aggregation** ：将日期字段的值分组到时间区间内。
- **Range Aggregation** ：根据范围将数值型字段的值分组到不同的桶中。
- **Filters Aggregation** ：根据过滤条件将文档分组到不同的桶中。
- **Filter Aggregation** ：类似于 Filters Aggregation，但只能应用一个过滤条件。
- **Geo Distance Aggregation** ：根据地理位置距离将文档分组到不同的桶中。

1. **管道聚合 (Pipeline Aggregations)** ：

- 这些聚合基于其他聚合的结果来计算新的度量值。
- **常见管道聚合** ：

- **Derivative Aggregation** ：计算度量聚合之间的差值。
- **Bucket Script Aggregation** ：基于桶聚合的结果计算新的度量值。
- **Moving Function Aggregation** ：计算滑动窗口内的度量值。
- **Percentiles Aggregation** ：计算百分位数。

1. **复合聚合 (Composite Aggregation)** ：

- 允许您根据多个字段的组合将文档分组到桶中。

1. **其他聚合** ：

- **Sampler Aggregation** ：从桶中随机抽取样本。
- **Top Hits Aggregation** ：从桶中返回文档的顶部命中。
- **Global Aggregation** ：用于全局聚合，不受查询过滤条件的影响。

#### 示例

以下是一些常见聚合类型的示例：

1. **度量聚合示例** ：

- 计算 `price` 字段的平均值：

```json
GET /items/_search
{
  "size": 0,
  "aggs": {
    "avg_price": {
      "avg": {
        "field": "price"
      }
    }
  }
}
```

1. **桶聚合示例** ：

- 根据 `brand` 字段将文档分组到不同的桶中：

```json
GET /items/_search
{
  "size": 0,
  "aggs": {
    "brand_buckets": {
      "terms": {
        "field": "brand"
      }
    }
  }
}
```

1. **管道聚合示例** ：

- 计算 `brand_buckets` 中每个品牌的文档数量的百分比：

```json
GET /items/_search
{
  "size": 0,
  "aggs": {
    "brand_buckets": {
      "terms": {
        "field": "brand"
      },
      "aggs": {
        "percentage_of_total": {
          "bucket_script": {
            "buckets_path": {
              "total": "_count",
              "brand_count": "doc_count"
            },
            "script": "params.brand_count / params.total * 100"
          }
        }
      }
    }
  }
}
```

这些聚合类型可以根据您的具体需求进行组合和嵌套，以实现复杂的数据分析任务。如果您需要了解更多关于特定聚合类型的详细信息，请随时告诉我。
