# 3、远程调用

<span style="color: rgb(38, 38, 38)"></span>**<span style="color: rgb(38, 38, 38)">RPC（</span>****<span style="color: rgb(18, 18, 18)">Remote Procedure Call</span>****<span style="color: rgb(38, 38, 38)">）：远程过程调用</span>**<span style="color: rgb(38, 38, 38)"></span>

![](https://pub-ccd5622eabb54b4a81678003778ddce1.r2.dev/PicGo/f48a2aead2a74d96f4cb4c72ab2ce15c73549950ac90e26a946b3e7b370a7c63.png)

**本地过程调用**： a()； b()； a() { b()；}： 不同方法都在**同一个JVM运行，a方法中调用b方法。**

**远程过程调用**<span style="color: rgb(38, 38, 38)">：（A服务跑在A机器中，B服务跑在B机器中,C服务跑在C机器中）</span>

- 服务提供者：B服务
- 服务消费者：A服务
- 通过连接对方服务器进行请求\响应交互，来实现调用效果

API/SDK的区别是什么？

- api：接口（ Application Programming Interface ）应用编程入口（有时是本地接口，但大多时候是外部接口）

- 远程提供功能； 提供远程服务的情况下必须满足对应的要求。

- sdk：工具包（ Software Development Kit ）软件开发工具包

- 导入jar包，直接调用功能即可

> ***<span style="color: rgb(48, 54, 63)">开发过程中</span>****<span style="color: rgb(48, 54, 63)">，我们经常需要调用别人写的功能（要调用不同JVM上运行的方法）</span>*
> - *<span style="color: rgb(48, 54, 63)">如果是</span>* ***<span style="color: rgb(48, 54, 63)">内部</span>*** *<span style="color: rgb(48, 54, 63)">微服务，可以通过</span>* ***<span style="color: rgb(48, 54, 63)">依赖cloud</span>*** *<span style="color: rgb(48, 54, 63)">、</span>* ***<span style="color: rgb(48, 54, 63)">注册中心、openfeign</span>*** *<span style="color: rgb(48, 54, 63)">等进行调用</span>*
> - *<span style="color: rgb(48, 54, 63)">如果是</span>* ***<span style="color: rgb(48, 54, 63)">外部</span>*** *<span style="color: rgb(48, 54, 63)">暴露的，可以</span>* ***<span style="color: rgb(48, 54, 63)">发送 http 请求、或遵循外部协议</span>*** *<span style="color: rgb(48, 54, 63)">进行调用（就像aliyun上的服务器不在团队的开发集群中，不能使用内部微服务的方式）</span>*
> *<span style="color: rgb(48, 54, 63)">SpringBoot 整合提供了很多方式进行远程调用</span>*

## <span style="color: rgb(48, 54, 63)">1. WebClient</span>

> 非阻塞、响应式HTTP客户端，使用HTTP协议的方式发出请求。与之对应有Mysql客户端，使用mysql的方式发请求。

需要导入响应式web的依赖

```xml
 <dependency>
            <groupId>org.springframework.boot</groupId>
            <artifactId>spring-boot-starter-webflux</artifactId>
</dependency>
```

```java
 private static Mono<String> getByWebClient(String city) {
        //1、创建WebClient（HTTP客户端或者叫web客户端）
        //这种是直接写死url,如果是GET请求要在url中添加参数，则直接定义第二种空参创建方式。
//       WebClient client = WebClient.create("https://ali-weather.showapi.com/area-to-weather-date");
        WebClient client = WebClient.create();

        //2、准备数据（Map的params是给".uri"里面赋值参数使用）
        Map<String,String> params = new HashMap<>();
        params.put("area", city);
        //3、定义发请求行为  CompletableFuture
        Mono<String> mono = client.get()
                //定义url中的参数
                .uri("https://ali-weather.showapi.com/area-to-weather-date?area={area}", params)
                //定义响应的内容类型
                .accept(MediaType.APPLICATION_JSON)
                //设置请求头参数
                .header("Authorization", "APPCODE 93b7e19861a24c519a7548b17dc16d75") //定义请求头
                //发送请求
                .retrieve()
                //将响应体中的内容以String类型赋值给Mono,Mono是响应web中的类型，Mono是发布者，谁想要该内容就将该内容发送给它。
                .bodyToMono(String.class);
                //.block() 这种手动让它阻塞的方式不适用了，只能异步
        return mono;
    }
```

## 2. HTTP Interface

### <span style="color: rgb(48, 54, 63)">2.1 导入依赖</span>

> 根WebClient一样，也是响应式编程。需要导入响应式web依赖。

```xml
<dependency>
    <groupId>org.springframework.boot</groupId>
    <artifactId>spring-boot-starter-webflux</artifactId>
</dependency>
```

### <span style="color: var(--lakex-editor-text-color)">2.2 定义接口</span>

```java
public interface WeatherInterface {
    @GetExchange(url = "https://ali-weather.showapi.com/area-to-weather-date",accept = "application/json")
    Mono<String> getWeather(@RequestParam("area") String city);
}
```

> @GetExchange：向该url发送get请求。
> accept：接受的响应体是json的
> @RequestParam：就是url中的参数，是?area=city，没试过restful风格对不对。
> - 该注解在Control中表示接收数据的名称。但在Http Interface中表示给出的url的参数。
> 返回值：Mono&lt;String&gt;，响应式编程不允许阻塞式的单独返回String类型。

```java
@Autowired
WeatherInterface weatherInterface;

public Mono<String> weather(String city){
//远程调用阿里云API

//        Mono<String> mono = getByWebClient(city);


Mono<String> weather = weatherInterface.getWeather(city);

return weather;
}
```

> - 在service对应的实现该api的类下调用weatherInterface.getWeather(city);获取最终api的返回值。
> 以后直接在WeatherController中调用WeatherService.weather方法即可获取结果。
> - weatherInterface：weatherInterface接口生成的对应的代理对象。（下面会说如何生成的）

```java
@Configuration //最好起名为 AliyunApiConfiguration
public class AliyunApiConfiguration {

    @Bean
    HttpServiceProxyFactory httpServiceProxyFactory(@Value("${aliyun.appcode}") String appCode){
        //1、创建客户端
        WebClient client = WebClient.builder()
                .defaultHeader("Authorization","APPCODE "+appCode)
                .codecs(clientCodecConfigurer -> {
                    clientCodecConfigurer
                            .defaultCodecs()
                            .maxInMemorySize(256*1024*1024);
                    //响应数据量太大有可能会超出BufferSize，所以这里设置的大一点
                })
                .build();
        //2、创建工厂
        HttpServiceProxyFactory factory = HttpServiceProxyFactory
                .builder(WebClientAdapter.forClient(client)).build();
        return factory;
    }

    @Bean
    WeatherInterface weatherInterface(HttpServiceProxyFactory httpServiceProxyFactory){
        //3、获取代理对象
        WeatherInterface weatherInterface = httpServiceProxyFactory.createClient(WeatherInterface.class);
        return weatherInterface;
    }
}
```

> - httpServiceProxyFactory：该工厂可以根据httpInterface接口生成代理对象。
> - 生成的代理对象放在IOC容器中，方便service--WeatherService中依赖注入。
> - @Value("${aliyun.appcode}")：将购买的appCode认证码设置在application.properties中。
> - defaultHeader("Authorization","APPCODE "+appCode)：购买的api都是同一个appCode,就不用在httpInterface方法中设置在请求头里面
