### **一、学习指引**

> 一起将Java代码构建成本地可执行文件吧！

学过Java的小伙伴都知道，运行Java程序前，我们写的Java代码会由Java编译器编译成字节码，运行在JVM中，由JVM将其翻译成机器码。整个过程是需要JVM参与的，也就是说，Java程序是需要运行在JVM之上的。

GraalVM提供了预编译技术，能够提前将Java代码直接编译成本机可执行的二进制文件，也就是使得Java程序在运行时能够摒弃JVM，和C/C++一样通过编译器直接将代码编译成机器代码，然直接后运行。

### **四、构建Native Image**

> 看看如何构建Native Image

本节主要介绍如何使用GraalVM的native-image插件将Java程序打包成二进制文件。

#### **4.1 编写Java代码**

这里，编写一个简单的Java代码，如下所示。

```go
public class HelloSpring {
    public static void main(String[] args) {
        System.out.println("Hello Spring6");
    }
}
```

#### **4.2 构建Native Image**

**（1）打开Native Tools Command Prompt**

在系统的开始菜单中打开Visual Studio 2022的Native Tools Command Prompt。

![](https://pub-ccd5622eabb54b4a81678003778ddce1.r2.dev/PicGo/1efeca8db45625c4e7575d1305e1115540191ce759a6ef40f10a229c2cd1d587.png)

打开后如下图所示。

![](https://pub-ccd5622eabb54b4a81678003778ddce1.r2.dev/PicGo/2397aaf627a9fe766e1b9b566a202e3ebf15100903541905ca1dadd2e5ccd8f0.png)

**（2）编译**[HelloSpring.java](http://HelloSpring.java)**文件**

将目录切换到[HelloSpring.java](http://HelloSpring.java)文件所在的目录，输入javac -encoding UTF-8[HelloSpring.java](http://HelloSpring.java)命令编译[HelloSpring.java](http://HelloSpring.java)文件。

![](https://pub-ccd5622eabb54b4a81678003778ddce1.r2.dev/PicGo/8d642480982b587e92b62d2d8cdaeb4b74dcfbc8e01188185a3ab699b0416fb3.png)

**（3）构建执行文件**

使用native-image插件构建二进制可执行文件，输出的命令为native-image HelloSpring。

![](https://pub-ccd5622eabb54b4a81678003778ddce1.r2.dev/PicGo/78bd8001accb4386812b65dcbcc66d16ac92b4573d358cc6486630d3655f3759.png)

构建完之后所在目录的文件如下所示。

![](https://pub-ccd5622eabb54b4a81678003778ddce1.r2.dev/PicGo/14e207a4f074e9f81db77238d435355c3948eb1111bd0ae6f736b8ed015b147d.png)

可以看到，目录中多出来一个11M左右大小的[hellospring.exe](http://hellospring.exe)文件，这个文件就是使用native-image构建出来的可执行二进制文件。文件中是包含了SVM和JDK各种库后的大小，虽然相比C/C++的二进制文件来说体积偏大，但是对比完整的JVM来说，已经是非常小了。

#### **4.3 运行可执行文件**

直接出入[hellospring.exe](http://hellospring.exe)即可运行可执行文件，并打印出 Hello Spring6的日志。

![](https://pub-ccd5622eabb54b4a81678003778ddce1.r2.dev/PicGo/581688b340886eb12ce4710941969f287919bfddd8e7c8c2e7bb7f6d8e7b917d.png)

结果与直接使用java命令运行的结果一致。

![](https://pub-ccd5622eabb54b4a81678003778ddce1.r2.dev/PicGo/e51a902be02de145bbaae0c86f60e730bbe5ee0111041abee87bf32ba9ac4ac7.png)

至此，成功使用GraalVM的native-image插件将Java代码构建成可执行二进制文件。

### **五、总结**

> 如何构建Native Image介绍完了，我们一起总结下吧！

本章，主要是介绍了如何构建Native Image，首先，介绍了如何安装GraalVM环境，随后介绍了如何安装C++编译环境。最后开始动手编写代码，构建可执行二进制文件。

相比于使用JVM运行，Native Image的速度要快上不少，CPU的占用也更低一些，从官方提供的各类实验数据也可以看出Native Image对于启动速度和内存占用带来的提升是非常显著的。
