### **一、学习指引**

> AOP拦截器链，你真的彻底了解过吗？

Spring中的AOP在底层执行的过程中，本质上是以一个拦截器链的形式执行每个标注了通知注解（@Before、@After、@AfterReturning、@AfterThrowing和@Around）的方法，本章，就一起彻底搞懂Spring底层构建AOP拦截器链的过程。

**注意：本章会以第22章的案例程序为基础解析切入点表达式的源码时序图和源码执行流程。**

```go
@Nullable
protected Object resolveBeforeInstantiation(String beanName, RootBeanDefinition mbd) {
    Object bean = null;
    if (!Boolean.FALSE.equals(mbd.beforeInstantiationResolved)) {
        if (!mbd.isSynthetic() && hasInstantiationAwareBeanPostProcessors()) {
            Class<?> targetType = determineTargetType(beanName, mbd);
            if (targetType != null) {
                bean = applyBeanPostProcessorsBeforeInstantiation(targetType, beanName);
                if (bean != null) {
                    bean = applyBeanPostProcessorsAfterInitialization(bean, beanName);
                }
            }
        }
        mbd.beforeInstantiationResolved = (bean != null);
    }
    return bean;
}
```

@Override

（11）解析ReflectiveAspectJAdvisorFactory类的getAdvisorMethods(Class&lt;?&gt; aspectClass)方法

源码详见：[org.springframework.aop.aspectj.annotation.ReflectiveAspectJAdvisorFactory#getAdvisorMethods](http://org.springframework.aop.aspectj.annotation.ReflectiveAspectJAdvisorFactory#getAdvisorMethods)(Class&lt;?&gt; aspectClass)。

```go
private List<Method> getAdvisorMethods(Class<?> aspectClass) {
    List<Method> methods = new ArrayList<>();
    ReflectionUtils.doWithMethods(aspectClass, methods::add, adviceMethodFilter);
    if (methods.size() > 1) {
        methods.sort(adviceMethodComparator);
    }
    return methods;
}
```

可以看到，在ReflectiveAspectJAdvisorFactory类的getAdvisorMethods()方法中，会过滤到标注了@Pointcut注解的方法。

过滤到标注了@Pointcut注解的方法的规则就是adviceMethodFilter过滤器提供的。adviceMethodFilter的源码详见：[org.springframework.aop.aspectj.annotation.ReflectiveAspectJAdvisorFactory#adviceMethodFilter](http://org.springframework.aop.aspectj.annotation.ReflectiveAspectJAdvisorFactory#adviceMethodFilter)。

```go
// Exclude @Pointcut methods
private static final MethodFilter adviceMethodFilter = ReflectionUtils.USER_DECLARED_METHODS
    .and(method -> (AnnotationUtils.getAnnotation(method, Pointcut.class) == null));
```

可以看到，adviceMethodFilter过滤器的规则就是过滤掉切面类中标注了@Pointcut注解的方法。

随后，在ReflectiveAspectJAdvisorFactory类的getAdvisorMethods()方法中，如果过滤后的方法列表大于1，则为方法列表中的方法进行排序，排序所使用的比较器为adviceMethodComparator。

有关adviceMethodComparator的源码详见：[org.springframework.aop.aspectj.annotation.ReflectiveAspectJAdvisorFactory#adviceMethodComparator](http://org.springframework.aop.aspectj.annotation.ReflectiveAspectJAdvisorFactory#adviceMethodComparator)。

```go
private static final Comparator<Method> adviceMethodComparator;
static {
    Comparator<Method> adviceKindComparator = new ConvertingComparator<>(
        new InstanceComparator<>(
            Around.class, Before.class, After.class, AfterReturning.class, AfterThrowing.class),
        (Converter<Method, Annotation>) method -> {
            AspectJAnnotation<?> ann = AbstractAspectJAdvisorFactory.findAspectJAnnotationOnMethod(method);
            return (ann != null ? ann.getAnnotation() : null);
        });
    Comparator<Method> methodNameComparator = new ConvertingComparator<>(Method::getName);
    adviceMethodComparator = adviceKindComparator.thenComparing(methodNameComparator);
}
```

可以看到，adviceMethodComparator是在ReflectiveAspectJAdvisorFactory类的静态代码块中赋值的，并且在静态代码块中，调用了AbstractAspectJAdvisorFactory类的findAspectJAnnotationOnMethod()方法来获取方法的注解信息。

（12）解析AbstractAspectJAdvisorFactory类的findAspectJAnnotationOnMethod(Method method))方法

源码详见：[org.springframework.aop.aspectj.annotation.AbstractAspectJAdvisorFactory#findAspectJAnnotationOnMethod](http://org.springframework.aop.aspectj.annotation.AbstractAspectJAdvisorFactory#findAspectJAnnotationOnMethod)(Method method)。

```go
@Nullable
protected static AspectJAnnotation<?> findAspectJAnnotationOnMethod(Method method) {
    for (Class<?> clazz : ASPECTJ_ANNOTATION_CLASSES) {

        if (foundAnnotation != null) {

        }

    return null;
}
```

可以看到，在AbstractAspectJAdvisorFactory类的findAspectJAnnotationOnMethod()方法中，会遍历ASPECTJ_ANNOTATION_CLASSES数组，对遍历出的每一个clazz对象调用findAnnotation()方法获取其方法上的注解，如果获取到的注解信息不为null，则返回注解信息。否则，继续下一次循环。直到循环结束仍未获取到注解信息，则返回null。

这里，ASPECTJ_ANNOTATION_CLASSES的源码详见：[org.springframework.aop.aspectj.annotation.AbstractAspectJAdvisorFactory#ASPECTJ_ANNOTATION_CLASSES](http://org.springframework.aop.aspectj.annotation.AbstractAspectJAdvisorFactory#ASPECTJ_ANNOTATION_CLASSES)。

源码详见：[org.springframework.aop.aspectj.annotation.AbstractAspectJAdvisorFactory#validate](http://org.springframework.aop.aspectj.annotation.AbstractAspectJAdvisorFactory#validate)(Class&lt;?&gt; aspectClass)。

​

    if (!ajType.isAspect()) {

可以看到，在AbstractAspectJAdvisorFactory类的validate()方法中，具体校验的规则如下所示。

2. 当前类未标注@Aspect注解，则抛出NotAnAtAspectException异常。

3. 当前类关联的kind信息是PerClauseKind.PERCFLOW或者PerClauseKind.PERCFLOWBELOW，都会抛出AopConfigException信息。

（16）返回BeanFactoryAspectJAdvisorsBuilder类的buildAspectJAdvisors()方法。
