# 相关注解

### JavaWeb-&gt;注解

#### fruitAddServlet extends HttpServlet

Servlet需要在web.xml中：

```xml
<servlet>
  <servlet-name>Demo03Servlet</servlet-name>
  <servlet-class>com.atguigu.servlets.Demo03Servlet</servlet-class>
</servlet>
<servlet-mapping>
  <servlet-name>Demo03Servlet</servlet-name>
  <url-pattern>/demo03</url-pattern>
</servlet-mapping>
```

使用@WebServlet("/add.do")可以省略。

//Servlet从3.0版本开始支持注解方式的注册

//后面将增删改查变为一个类的方法@WebServlet("/fruit.do")变为fruit

//再后面使用dispatcherservlet使用@WebServlet("*.do")，通配符*来建立唯一一个servlet.

（1）这时，applicationContext.xml中注册FruitController。

（2）在dispatcherservlet中读取InputStream inputStream =getClass().getClassLoader().getResourceAsStream("applicationContext.xml");

（3）ClassPathXmlApplicationContext中进行IOC(控制反转)，将实例的生命周期，控制权改变

### Spring5相关注解

（1）JavaWeb最初是使用DispathcerServlet来代替许多类的Servlet，如FruitServlet,使用FruitController，但是FruitServlet在web.xml中注册，系统会自动创造实例。所以FruitController就需要自定义的applicationContext.xml里面注册，以便在DispatcherServlet的init方法中进行专门读取然后通过反射进行实例化。这时的Service和Dao都是new 出来的。

（2）后来自定义一个ClassPathXmlApplicationContext专门初始化IOC容器以及依赖注入，不在DispatcherServlet的init方法中操作，但是还要在init方法中调用ClassPathXmlApplicationContext，这时的Service和Dao都是先注册，再依赖注入。

（3）监听拥有后，调用ClassPathXmlApplicationContext就在监听开始时完成。

（4）Spring5框架已经定义好ClassPathXmlApplicationContext类，当调用

```java
//ApplicationContext context =
//                new ClassPathXmlApplicationContext("bean4.xml");
ClassPathXmlApplicationContext context =
new ClassPathXmlApplicationContext("bean4.xml");
```

以上方法即可初始化IOC容器以及依赖注入。其中bean4.xml相当于JavaWeb中的applicationContext.xml。

（5）使用注解

@Component

@Service

@Controller

@Repository

*上面四个注解功能是一样的，都可以用来创建bean实例

```plain
<!-- 开启注解扫描 -->
<context:component-scan base-package="com.atguigu.spring5.aopanno"></context:component-scan>
```

就可以进行IOC初始化，使用注解前提需要aop.jar包,aop还有一个作用就是给某个类方法使用前后增加切面（代理），可以xml实现也可以注解实现。可以用到之前学到的反射代理，达到一个代理类可以代理许多类的效果，不用分别为其创造代理类。

(6)使用配置类来代替xml文件和注解扫描，以后非自定义类也在配置类中进行初始化

```plain
@Configuration  //作为配置类，替代xml配置文件
@ComponentScan(basePackages = {"com.atguigu"})
public class SpringConfig {

}
```
