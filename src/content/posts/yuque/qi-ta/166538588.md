# VsCode安装文档

### VS Code 安装文档

#### 一、下载

进入VS Code官网：https://code.visualstudio.com，点击DownLoad for Windows下载windows版本

![](https://pub-ccd5622eabb54b4a81678003778ddce1.r2.dev/PicGo/11d5fc64c3e1a8603b2b974a83f1e379476fe5eba36a15929c2143412387f3d6.png)

当然也可以点击旁边的箭头，下载Windows版本 或 Mac OS 版本

![](https://pub-ccd5622eabb54b4a81678003778ddce1.r2.dev/PicGo/40291fe7a103a3444ee7afece0ff8e553f799fbf23dd9d532535167efd742036.png)

- 备注：

- Stable：稳定版
- Insiders：内测版

注意：上述下载软件安装包的过程，大家可以不用操作，因为在提供的课程资料中，已经为大家准备好了安装包 。

#### 二、安装

双击安装包，选择我同意此协议，再点击下一步

![](https://pub-ccd5622eabb54b4a81678003778ddce1.r2.dev/PicGo/01f49f532c9ae8fb900ca97570b93f2bf878fcfc4eb25c87466f5dfccc701514.png)

选择安装路径（也可以使用默认值: C:\Users\super\AppData\Local\Programs\Microsoft VS Code），点击下一步。

![](https://pub-ccd5622eabb54b4a81678003778ddce1.r2.dev/PicGo/3823bf2996e1ebf2ccabc7e86a48bf9e650f834be218ffc7b818611608489ec9.png)

继续点击下一步

![](https://pub-ccd5622eabb54b4a81678003778ddce1.r2.dev/PicGo/cce99e8af431d51f0b54553c3bbc8cd2c0aa551a9e4f9452cc61be8b137d9f7c.png)

可以勾选创建桌面快捷方式，如果不想使用vscode作为代码默认打开方式，可以取消将code注册为受支持的文件类型的编辑器，点击下一步

![](https://pub-ccd5622eabb54b4a81678003778ddce1.r2.dev/PicGo/8c7efb9684555f197373a6c64e9ba596de4162dda2028a59bc3a2147ccd207d8.png)

点击安装，开始安装

![](https://pub-ccd5622eabb54b4a81678003778ddce1.r2.dev/PicGo/250a49419b32f5683cf97476425247c644a842e4a5547951fe43e73aa7e62a32.png)

![](https://pub-ccd5622eabb54b4a81678003778ddce1.r2.dev/PicGo/0293f8055cc241a5a8737b8b119c41de754c703fe178a8a7c0216dba037f6c7c.png)

![](https://pub-ccd5622eabb54b4a81678003778ddce1.r2.dev/PicGo/03c1c5aea6a9701cb44e2959f19b7d1f3d13c190ac57dc9d9a737189af0688b5.png)

安装完成，运行VS Code。

![](https://pub-ccd5622eabb54b4a81678003778ddce1.r2.dev/PicGo/2034f507924651bc34a169d2c16fac84a5849ef4961383b2aace4c57c367be9d.png)

点击左下角的 "设置" -&gt; "主题" -&gt; "主题颜色"，然后可以根据自己的喜好，选择喜欢的主题颜色。

![](https://pub-ccd5622eabb54b4a81678003778ddce1.r2.dev/PicGo/012667d9db3430568fe188707022af2dd515e0bfec74bf104acb2f739033faa6.png)

#### 三、VS Code插件安装

![](https://pub-ccd5622eabb54b4a81678003778ddce1.r2.dev/PicGo/f2a7283298bbe5207344bc8daf926f9da4fe8f4e5d6b64a4259acf536035cd4e.png)

VS Code提供了非常丰富的插件功能，根据你的需要，安装对应的插件可以大大提高开发效率。

完成前端开发，常见插件介绍：

##### 1、Chinese (Simplified) Language Pack

适用于 VS Code 的中文（简体）语言包

![](https://pub-ccd5622eabb54b4a81678003778ddce1.r2.dev/PicGo/1c4d6cb65db1a065b4721b7e091a6250761c30ede7243b13311a1f2d85ac3dac.png)

##### 2、HTML CSS Support

在编写样式表的时候，自动补全功能大大缩减了编写时间。

![](https://pub-ccd5622eabb54b4a81678003778ddce1.r2.dev/PicGo/6155cdf38e5bda0cc2de8b85959d2823d021e972a9df73a11f2ded0c8bca0c4b.png)

##### 3、JavaScript (ES6) code snippets

支持ES6语法提示

![](https://pub-ccd5622eabb54b4a81678003778ddce1.r2.dev/PicGo/7933b109828f4d7d3ff41c1db1f2d3223c8a1cecf34eaff6af4518190efb6f44.png)

##### 4、Mithril Emmet

一个能大幅度提高前端开发效率的一个工具，用于补全代码

![](https://pub-ccd5622eabb54b4a81678003778ddce1.r2.dev/PicGo/c6491b26acb6e07cd4d1606f5442ea2bc66e5a4bd5031c10de3dd1ac19b1b058.png)

##### 5、Path Intellisense

路径提示插件

![](https://pub-ccd5622eabb54b4a81678003778ddce1.r2.dev/PicGo/c1179426021c928744646bdf377568a540721ceb32e4bfc177d3fde62b4c0823.png)

##### 6、Vue 3 Snippets

在 Vue 2 或者 Vue 3 开发中提供代码片段，语法高亮和格式化的 VS Code 插件，能极大提高你的开发效率。

![](https://pub-ccd5622eabb54b4a81678003778ddce1.r2.dev/PicGo/ec3734194c17ddb16d1dc3ad5925a79b755cf5e02e4cb8506020ff3dd393d6ce.png)

##### 7、Auto Close Tag

自动闭合HTML/XML标签

![](https://pub-ccd5622eabb54b4a81678003778ddce1.r2.dev/PicGo/91c22549456a32eed1418416ea79c4b3f755742921e522ea1eb5b7f137fa4580.png)

##### 8、Auto Rename Tag

自动完成另一侧标签的同步修改

![](https://pub-ccd5622eabb54b4a81678003778ddce1.r2.dev/PicGo/b4dc71210608fc1412632f0e9b50d3a348fc76aa66d85184ab13452e41a8edf3.png)

##### 9、open in browser

vscode不像IDE一样能够直接在浏览器中打开html，而该插件支持快捷键与鼠标右键快速在浏览器中打开html文件，支持自定义打开指定的浏览器，包括：Firefox，Chrome，Opera，IE以及Safari

![](https://pub-ccd5622eabb54b4a81678003778ddce1.r2.dev/PicGo/6b63e6b95f840a1222074687610ddf30d0ce038eb4639392e912f01e4d2517fd.png)

##### 10、Live Server

一个具有实时加载功能的小型服务器，也就是说我们可以在项目中实时用live-server作为一个实时服务器实时查看开发的网页或项目效果。

![](https://pub-ccd5622eabb54b4a81678003778ddce1.r2.dev/PicGo/085dbe8192974e1923d04b01ead0e073ceff9276d79451f0942bbe9bd6c78353.png)

##### 11、Vue Language Features (Volar)

一个专门为 Vue 3 构建的语言支持插件。它基于@vue/reactivity按需计算一切，实现原生 TypeScript 语言服务级别的性能。

![](https://pub-ccd5622eabb54b4a81678003778ddce1.r2.dev/PicGo/a14c4cf479077e081c08340331125a7b79ac2c356e74c924dfcfb66e8965635b.png)

##### 12、TypeScript Vue Plugin (Volar)

TypeScript Vue Plugin是一个对Vue.js框架进行扩展的插件，它允许开发者使用TypeScript语言编写Vue组件和应用程序，并提供了更好的类型检查和编辑器支持。通过使用TypeScript Vue Plugin，开发者可以在编写Vue应用时获得更好的开发体验和代码可维护性。

![](https://pub-ccd5622eabb54b4a81678003778ddce1.r2.dev/PicGo/be5c23378521ffaca6c5cd330682c80cc8946b2c69a4f18dea45e913260065c8.png)

##### 13、File Utils

File Utils插件,可以方便快捷的来创建、复制、移动、重命名文件和目录。

![](https://pub-ccd5622eabb54b4a81678003778ddce1.r2.dev/PicGo/e1f0b517e4e8f9d7bfce2349c66294297669b4657486ae28e24fc9b8e8e620ba.png)

##### 14、IntelliJ IDEA Keybindings

安装VSCode的插件 IntelliJ IDEA Keybindings 即可在VSCode中使用IDEA的快捷键。

![](https://pub-ccd5622eabb54b4a81678003778ddce1.r2.dev/PicGo/d16eb03ba3927c7e5397d7eef9d4a6c813d463dc18476f6f41e4a3215931c1b2.png)

#### 四、VS Code 配置

打开配置面板，根据自己的喜好，可以修改字体、背景样式等偏好设置

![](https://pub-ccd5622eabb54b4a81678003778ddce1.r2.dev/PicGo/0090e6af4c3b38e9cafca1962883f8b56d6189c1134ba718f8ea7e3d18affc3c.png)
