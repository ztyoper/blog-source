# Git安装

## 第2章 Git 安装

官网地址：https://git-scm.com/

查看GNU 协议，可以直接点击下一步。

选择Git安装位置，要求是非中文并且没有空格的目录，然后下一步。

![image.png](https://pub-ccd5622eabb54b4a81678003778ddce1.r2.dev/PicGo/39c3512da25f07738dfa99d5155a1aa144c0c8fe3dea02f64f4180b3bdb06b10.png)

![image.png](https://pub-ccd5622eabb54b4a81678003778ddce1.r2.dev/PicGo/e19d3406bb497dd2608767fb1d58cbdbdaf7fec2986ad03d5000d5e154c0780c.png)

Git 选项配置，推荐默认设置，然后下一步。

![image.png](https://pub-ccd5622eabb54b4a81678003778ddce1.r2.dev/PicGo/b69162aaf6ab98d33a43344f2ce9a5f2d494acadded4d188fcc03a175e33efd4.png)

Git安装目录名，不用修改，直接点击下一步。

![image.png](https://pub-ccd5622eabb54b4a81678003778ddce1.r2.dev/PicGo/4b3db61a793967edb6e93f14e45b560e8e999ed03ae24e9f3701c73bba2e8244.png)

Git 的默认编辑器，建议使用默认的 Vim 编辑器，然后点击下一步。

![image.png](https://pub-ccd5622eabb54b4a81678003778ddce1.r2.dev/PicGo/93f1c455916817e6241deab74e2dee542c5066e81fc339ff93ba2d1e1437df7c.png)

默认分支名设置，选择让Git决定，分支名默认为master，下一步。

![image.png](https://pub-ccd5622eabb54b4a81678003778ddce1.r2.dev/PicGo/b669a0dc1855d4e064a4dda7770a2270ee826a25e8b2ab3d8854e38f9bfcc3e6.png)

修改Git 的环境变量，选第一个，不修改环境变量，只在Git Bash 里使用Git。

![image.png](https://pub-ccd5622eabb54b4a81678003778ddce1.r2.dev/PicGo/66a9a86f9f878459a68b4a8ffe5496db7cd2507cbb5e551d22a37b912ad29d01.png)

选择后台客户端连接协议，选默认值OpenSSL，然后下一步。

![image.png](https://pub-ccd5622eabb54b4a81678003778ddce1.r2.dev/PicGo/9f16e594d5511bea53c5c6203609d97c34fc364744b1950faa848e8f933d61da.png)

配置Git文件的行末换行符，Windows使用CRLF，Linux使用LF，选择第一个自动

转换，然后继续下一步。

![image.png](https://pub-ccd5622eabb54b4a81678003778ddce1.r2.dev/PicGo/46d19ca6c8a1530d675a8af6c5bffbcf7680e67fa473086b2d4fdc84185d01a6.png)

选择Git终端类型，选择默认的Git Bash终端，然后继续下一步。

![image.png](https://pub-ccd5622eabb54b4a81678003778ddce1.r2.dev/PicGo/65fe7afe7ad119986a0c8b63e835b714b819148f52b610c183698b474ea5ce04.png)

选择Git pull合并的模式，选择默认，然后下一步。

![image.png](https://pub-ccd5622eabb54b4a81678003778ddce1.r2.dev/PicGo/c77b98749256924ca920a959712cffae5c041cf280dc4e071a1d8b9bb41f38c5.png)

选择Git的凭据管理器，选择默认的跨平台的凭据管理器，然后下一步。

![image.png](https://pub-ccd5622eabb54b4a81678003778ddce1.r2.dev/PicGo/0c00bf658a3658185274c82cbebec47670321a88457be5fecf91d527e04402ea.png)

其他配置，选择默认设置，然后下一步。

![image.png](https://pub-ccd5622eabb54b4a81678003778ddce1.r2.dev/PicGo/dfaed156c9d8c37f1eecd6d7846707bc094c6663232438a27c5f15966c5b961d.png)

实验室功能，技术还不成熟，有已知的 bug，不要勾选，然后点击右下角的 Install按钮，开始安装Git。

![image.png](https://pub-ccd5622eabb54b4a81678003778ddce1.r2.dev/PicGo/d0ab39d7b5b6373b4cc2505f81392fa76fe7f40c33fa25c0bb3a50a60f46c6fb.png)

点击Finsh按钮，Git安装成功！

![image.png](https://pub-ccd5622eabb54b4a81678003778ddce1.r2.dev/PicGo/1b9fcc396e03b2f8a3132fae70a06ffbda84aeebcfa0f58e1c37e2fdd1337453.png)右键任意位置，在右键菜单里选择Git Bash Here 即可打开 Git Bash 命令行终端。

![image.png](https://pub-ccd5622eabb54b4a81678003778ddce1.r2.dev/PicGo/fc03f40c28fd38f27736cc28bae83c17305e02308a4adc4b4c92552e161f47ca.png)

在 Git Bash 终端里输入 git --version 查看 git 版本，如图所示，说明Git 安装成功。

![image.png](https://pub-ccd5622eabb54b4a81678003778ddce1.r2.dev/PicGo/622d52923d0373b6465e328cd80f1a2067f10e70bf38da0c45b85880a1332e62.png)
