# 安装Docker

大家学习中如果碰到困难，可以加入**黑马智学伴侣**寻求帮助。

本安装教程参考Docker官方文档，地址如下：

https://docs.docker.com/engine/install/centos/

## 1.卸载旧版

首先如果系统中已经存在旧的Docker，则先卸载：

```plain
yum remove docker \
    docker-client \
    docker-client-latest \
    docker-common \
    docker-latest \
    docker-latest-logrotate \
    docker-logrotate \
    docker-engine \
    docker-selinux
```

## 2.配置Docker的yum库

首先要安装一个yum工具

```plain
sudo yum install -y yum-utils device-mapper-persistent-data lvm2
```

安装成功后，执行命令，配置Docker的yum源（已更新为阿里云源）：

```plain
sudo yum-config-manager --add-repo https://mirrors.aliyun.com/docker-ce/linux/centos/docker-ce.repo

sudo sed -i 's+download.docker.com+mirrors.aliyun.com/docker-ce+' /etc/yum.repos.d/docker-ce.repo
```

更新yum，建立缓存

```plain
sudo yum makecache fast
```

## 3.安装Docker

最后，执行命令，安装Docker

```plain
yum install -y docker-ce docker-ce-cli containerd.io docker-buildx-plugin docker-compose-plugin
```

## 4.启动和校验

```plain
# 启动Docker
systemctl start docker

# 停止Docker
systemctl stop docker

# 重启
systemctl restart docker

# 设置开机自启
systemctl enable docker

# 执行docker ps命令，如果不报错，说明安装启动成功
docker ps
```

## 5.配置镜像加速

镜像地址可能会变更，如果失效可以百度找最新的docker镜像。

配置镜像步骤如下：

```plain
# 创建目录
mkdir -p /etc/docker

# 复制内容
tee /etc/docker/daemon.json <<-'EOF'
{
    "registry-mirrors": [
        "http://hub-mirror.c.163.com",
        "https://mirrors.tuna.tsinghua.edu.cn",
        "http://mirrors.sohu.com",
        "https://ustc-edu-cn.mirror.aliyuncs.com",
        "https://ccr.ccs.tencentyun.com",
        "https://docker.m.daocloud.io",
        "https://docker.awsl9527.cn"
    ]
}
EOF

# 重新加载配置
systemctl daemon-reload

# 重启Docker
systemctl restart docker
```

## 5.配置镜像加速(<span style="color: rgb(216,57,49)">阿里云已停用</span>）

这里以阿里云镜像加速为例。

### 5.1.注册阿里云账号

首先访问阿里云网站:

[https://www.aliyun.com/](https://www.aliyun.com/)

注册一个账号。

### 5.2.开通镜像服务

在首页的产品中，找到阿里云的**容器镜像服务**：

![](https://pub-ccd5622eabb54b4a81678003778ddce1.r2.dev/PicGo/79bbf596da54531de8e18f3363c2069ee97b56fd04c6a429226f28b4fa1d564d.png)

点击后进入控制台：

![](https://pub-ccd5622eabb54b4a81678003778ddce1.r2.dev/PicGo/6cbdedecd4c7a10392e7eb446e7aa0ac71abe21ae15f03071c0c720c64730868.png)

首次可能需要选择立刻开通，然后进入控制台。

### 5.3.配置镜像加速

找到**镜像工具**下的**镜像****加速器**：

![](https://pub-ccd5622eabb54b4a81678003778ddce1.r2.dev/PicGo/4b85cacb5ea1e5b2a4d72a488dbf6bf57b4ff7ddea9ea358bf3a90ed204794b0.png)

页面向下滚动，即可找到配置的文档说明：

![](https://pub-ccd5622eabb54b4a81678003778ddce1.r2.dev/PicGo/6cfd8fb2d06d16da56fd600a34058814a1cee4242f8efd036bf0c7807c93ed81.png)

具体命令如下：

```plain
# 创建目录
mkdir -p /etc/docker

# 复制内容，注意把其中的镜像加速地址改成你自己的
tee /etc/docker/daemon.json <<-'EOF'
{
  "registry-mirrors": ["https://xxxx.mirror.aliyuncs.com"]
}
EOF

# 重新加载配置
systemctl daemon-reload

# 重启Docker
systemctl restart docker
```
