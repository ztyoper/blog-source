# Linux软件部署

## 第五章06-Tomcats安装部署【单机软件】

### 1.JDK的安装部署

> 找到可以下载的`jdk`版本

```xml
apt search openjdk
```

> 下载jdk-19

```xml
apt -y install openjdk-19-jdk
```

> 一般放在`usr/lib/`下面，这个`jdk`放在了`/usr/lib/jvm/java-19-openjdk-amd64`

![image.png](https://pub-ccd5622eabb54b4a81678003778ddce1.r2.dev/PicGo/85dfb2abaa147a735bffd9331e201567d0b076c727d62d2312d300e2dfee88ea.png)

> 配置`JAVA_HOME`环境变量到`PATH`路径中。

```xml
vim /etc/profile 配置PATH路径

export JAVA_HOME=/usr/lib/jvm/java-19-openjdk-amd64
export PATH=$PATH:$JAVA_HOME/bin
```

> 使`profile`文件生效，这一步尤为重要

```xml
source /etc/profile
```

> 查看是否配置成功

```xml
java -version
```
