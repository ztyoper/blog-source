# Linux-Ubuntu目录解释

/etc是放配置文件的

/opt是放第三方软件包的

/mnt是挂载windows文件，root权限都不能访问

/apt是RPM包软件管理器，用于自动化安装配置Linux软件，并可以自动解决依赖问题

/usr

lib：系统默认的软件包安装目录

bin：命令的程序文件存放地

### 1.环境配置说明

#### 1、第一种配置环境的方法

/opt/java/jdk jdk是软链接，PATH路径添加的是jdk

/opt/java/下有各种java的版本。想用哪一个版本了，就删除jdk软链接。然后重新创建 ln -s 想用的jdk版本 jdk

缺点：每一装一个新的环境的时候，需要配置/etc/profile文件。添加PATH变量路径。

#### 2、第二种配置环境的方法

直接apt -y install 下载软件包，并安装软件

apt会控制该软件需要的依赖。软件会直接配置在/usr/bin目录下。不用配置/etc/profile

如果需要切换版本就使用update alternative

具体使用方式：[https://www.yuque.com/u25965979/ntvlcr/tx9nroy6g11dm8h7#NCIHT](https://www.yuque.com/u25965979/ntvlcr/tx9nroy6g11dm8h7#NCIHT)

缺点：不像第一种方式。只用配置一次/etc/profile文件。而是配置多个-slave子文件。不然切换环境版本时，只切换了.java 没有奇幻.javac

优点：下载方便
