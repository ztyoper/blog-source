# Linux熟练

## 第四章01-各类小技巧快捷键

### 1.ctrl+c

> 1. 某些程序的运行，如果想要强制停止它，可以使用快捷键ctrl+c
> 2. 命令输入错误，也可以通过快捷键ctrl+C,退出当前输入，重新输入

### 2.ctrl+d

> 1. 可以通过快捷键：ctrl+d,退出账户的登录
> 2. 或者退出某些特定程序的专属页面,如pyhton的解释器
> 3. 不能退出vi/vim

### 3.history命令

> 1. 查看命令历史记录
> 2. 可以通过： `！` 命令前缀，自动执行上一次匹配前缀的字母。如：输入 `!p回车` ，会自下而上地查询第一个首字母是p开头的命令。一般用于短期记得到的命令查询。

### 4.ctrl+r

> 可以通过快捷键：Ctrl+r,输入内容去匹配历史命令
> 如果搜索到的内容是你需要的，那么：回车键可以直接执行。键盘左右键，可以得到此命令（不执行）
> 可以一直按ctrl + r 进行多次查询

### 5.光标快速移动

> ctrl+a,跳到命令开头
> ctrl +e,跳到命令结尾
> ctrl+键盘左键，向左跳一个单词
> ctrl+键盘右键，向右跳一个单词

### 6.清屏

> 通过快捷键ctrl+L,可以清空终端内容
> 或通过命令clear得到同样效果

## 第四章-07-配置Linux固定IP地址

### 1.为什么需要固定IP

> 当前我们虚拟机的LiUx操作系统，其IP地址是通过DHCP服务获取的。DHCP:动态获取IP地址，即每次重启设备后都会获取一次，可能导致IP地址频繁变更
> 原因1：办公电脑P地址变化无所谓，但是我们要远程连接到LUX系统，如果P地址经常变化我们就要频繁修改适配很麻烦
> 原因2：在刚刚我们配置了虚拟机P地址和主机名的映射，如果P频繁更改，我们也需要频繁更新映射关系。
> 综上所述，我们需要P地址固定下来，不要变化了。

## 第四章09-端口

### 1.端口的定义

> 端口，是设备与外界通讯交流的出入口。端口可以分为：物理端口和虚拟端口两类
> 物理端口：又可称之为接口，是可见的端口，如USB接口，RJ45网口，HDM端口等
> 虚拟端口：是指计算机内部的端口，是不可见的，是用来操作系统和外部进行交互使用的

### 8.网络端口占用查看

sudo lsof -i TCP:9800[指令解读](https://www.yuque.com/u25965979/ntvlcr/parygazageb6u07t#sOqs5)

`netstat -tanlp`命令的每个字符代表的全称和含义如下：

- `netstat` : Network Statistics（网络统计），用于显示网络连接、路由表、接口统计等信息。
- `-t` : TCP (Transmission Control Protocol) connections only. 显示 TCP 连接。
- `-a` : All connections and listening ports. 显示所有连接和监听端口。
- `-n` : Numeric addresses. 显示 IP 地址和端口号，而不是主机名和服务名。
- `-l` : Listening ports. 显示正在监听的端口。
- `-p` : Show process ID and name of the program to which each socket belongs. 显示每个套接字所属的进程 ID 和程序名称。

总结起来，`netstat -tanlp`命令用于显示所有 TCP 连接及其状态，列出所有监听的端口，并以数字格式显示地址和端口，最后显示与每个连接相关联的进程 ID 和程序名称。

## 第四章-16-update-alternative

> update-alternatives<span style="color: rgb(64, 64, 64)">命令用于处理 Linux 系统中软件版本的切换，使其多版本共存。alternatives 的管理目录 /etc/alternatives</span>。

### 1、<span style="color: rgb(64, 64, 64)">alternatives 管理方式</span>

```bash
root@3511:/#  ls -l /usr/bin/java
lrwxrwxrwx 1 root root 22 Jan 31 11:27 /usr/bin/java -> /etc/alternatives/java
root@3511:/# ls -l /etc/alternatives/java
lrwxrwxrwx 1 root root 43 Jan 31 11:30 /etc/alternatives/java -> /usr/lib/jvm/java-19-openjdk-amd64/bin/java
```

`java`这个可执行命令实际是一个链接，指向了`/etc/alternatives/java`。而这个也是一个链接，指向了`/usr/lib/jvm/java-19-openjdk-amd64/bin/java`，这才是最终的可执行文件。`alternatives`实际上是通过软链接的方式对版本进行管理。

### <span style="color: rgb(64, 64, 64)">语法</span>

```bash
$ update-alternatives --help
用法：update-alternatives [<选项> ...] <命令>

命令：
  --install <链接> <名称> <路径> <优先级>
    [--slave <链接> <名称> <路径>] ...
                           在系统中加入一组候选项。
  --remove <名称> <路径>   从 <名称> 替换组中去除 <路径> 项。
  --remove-all <名称>      从替换系统中删除 <名称> 替换组。
  --auto <名称>            将 <名称> 的主链接切换到自动模式。
  --display <名称>         显示关于 <名称> 替换组的信息。
  --query <名称>           机器可读版的 --display <名称>.
  --list <名称>            列出 <名称> 替换组中所有的可用候选项。
  --get-selections         列出主要候选项名称以及它们的状态。
  --set-selections         从标准输入中读入候选项的状态。
  --config <名称>          列出 <名称> 替换组中的可选项，并就使用其中哪一个，征询用户的意见。
  --set <名称> <路径>      将 <路径> 设置为 <名称> 的候选项。
  --all                    对所有可选项一一调用 --config 命令。

<链接> 是指向 /etc/alternatives/<名称> 的符号链接。(如 /usr/bin/pager)
<名称> 是该链接替换组的主控名。(如 pager)
<路径> 是候选项目标文件的位置。(如 /usr/bin/less)
<优先级> 是一个整数，在自动模式下，这个数字越高的选项，其优先级也就越高。
..........
```

### **<span style="color: rgb(64, 64, 64)">实例</span>**

#### 1、<span style="color: rgb(64, 64, 64)">display 参数显示关于 java 替换组的信息</span>

```bash
root@3511:/# update-alternatives --display java

  link best version is /usr/lib/jvm/java-19-openjdk-amd64/bin/java
  link currently points to /usr/lib/jvm/java-19-openjdk-amd64/bin/java
  link java is /usr/bin/java
  slave java.1.gz is /usr/share/man/man1/java.1.gz
/usr/lib/jvm/java-17-openjdk-amd64/bin/java - priority 1711
  slave java.1.gz: /usr/lib/jvm/java-17-openjdk-amd64/man/man1/java.1.gz
/usr/lib/jvm/java-19-openjdk-amd64/bin/java - priority 1911
  slave java.1.gz: /usr/lib/jvm/java-19-openjdk-amd64/man/man1/java.1.gz
```

#### 2、<span style="color: rgb(64, 64, 64)">选择候选项</span>

```bash
There are 2 choices for the alternative java (providing /usr/bin/java).

  Selection    Path                                         Priority   Status
------------------------------------------------------------
* 0            /usr/lib/jvm/java-19-openjdk-amd64/bin/java   1911      auto mode
  1            /usr/lib/jvm/java-17-openjdk-amd64/bin/java   1711      manual mode
  2            /usr/lib/jvm/java-19-openjdk-amd64/bin/java   1911      manual mode

```

#### 3、<span style="color: rgb(64, 64, 64)">install 参数用于添加一个命令的link值</span>

```bash
# 添加 python link
$ update-alternatives --install /usr/bin/java java /usr/lib/jvm/graalvm-jdk-17.0.10+11.1 1811

# 第一个参数: --install 表示向update-alternatives注册服务名。
# 第二个参数: 注册最终地址，成功后将会把命令在这个固定的目的地址做真实命令的软链，以后管理就是管理这个软链；
# 第三个参数: 服务名，以后管理时以它为关联依据。
# 第四个参数: 被管理的命令绝对路径。
# 第五个参数: 优先级，数字越大优先级越高。
```

```bash
root@3511:/usr/lib# update-alternatives --config java
There are 3 choices for the alternative java (providing /usr/bin/java).

  Selection    Path                                         Priority   Status
------------------------------------------------------------
  0            /usr/lib/jvm/java-19-openjdk-amd64/bin/java   1911      auto mode
  1            /usr/lib/jvm/graalvm-jdk-17.0.10+11.1         1811      manual mode
* 2            /usr/lib/jvm/java-17-openjdk-amd64/bin/java   1711      manual mode
  3            /usr/lib/jvm/java-19-openjdk-amd64/bin/java   1911      manual mode

Press <enter> to keep the current choice[*], or type selection number: 1
update-alternatives: using /usr/lib/jvm/graalvm-jdk-17.0.10+11.1 to provide /usr/bin/java (java) in manual mode
```

#### 4、<span style="color: rgb(64, 64, 64)">remove 参数用于删除一个命令的link值，其附带的slave也将一起删除</span>

```bash
$ update-alternatives –remove python /usr/lib/jvm/java-19-openjdk-amd64/bin/java
```

#### 5、<span style="color: rgb(77, 77, 77)">auto</span><span style="color: rgb(64, 64, 64)">参数用于使用默认（自动）模式</span>

在上述输出中，auto mode 和 manual mode 是与软件包选择（selection）相关的模式。这些模式用于指定系统当前所使用的软件包。

- auto mode 表示软件包是由系统自动选择的默认选项。当有多个版本的软件包可供选择时，系统会自动选择其中一个作为默认安装。
- manual mode 表示软件包是用户手动选择的选项。当用户在安装或更新软件包时，可以手动选择特定的软件包版本。

在你提供的输出中，java-19-openjdk-amd64 被列为 auto mode，这意味着系统将其设置为默认的 Java 版本。而 graalvm-jdk-17.0.10+11.1 和 java-17-openjdk-amd64 则被列为 manual mode，表示这些版本是用户手动选择的。

```bash
update-alternatives --auto java 使用默认（自动）模式：也就是jdk-19 ,状态也就是相当于default的作用。
```

#### 6、slave<span style="color: rgb(64, 64, 64)">参数用于同步多个软件的版本</span>

<span style="color: rgb(77, 77, 77)">一般 gcc 和 g++ 版本须一致，使用</span><span style="color: rgb(199, 37, 78)">--slave</span><span style="color: rgb(77, 77, 77)">可以使得改变 gcc 的默认版本时自动改变 g++ 的版本.</span>

```bash
$ sudo update-alternatives --install /usr/bin/gcc gcc /usr/bin/gcc-4.4 44 --slave /usr/bin/g++ g++ /usr/bin/g++-4.4

$ sudo update-alternatives --install /usr/bin/gcc gcc /usr/bin/gcc-5 54 --slave /usr/bin/g++ g++ /usr/bin/g++-5
```
