# CMD和ENTRYPOINT

<span style="color: rgb(36, 41, 47)">ENTRYPOINT</span><span style="color: rgb(36, 41, 47)">和</span><span style="color: rgb(36, 41, 47)">CMD</span><span style="color: rgb(36, 41, 47)">都是用来定义 Docker 容器启动时执行的命令，它们之间的主要区别在于如何使用和组合。</span>

1. **<span style="color: rgb(36, 41, 47)">CMD</span>** ：

- CMD 用于指定容器启动时要执行的命令。如果 Dockerfile 中存在多个 CMD 指令，只有最后一个会生效。
- 如果在运行容器时指定了要执行的命令，那么这些命令将会覆盖 CMD 中指定的命令。

<span style="color: rgb(36, 41, 47)">示例：</span>

```plain
DockerfileCopy CodeFROM openjdk:11
COPY myapp.jar /myapp.jar
CMD ["java", "-jar", "/myapp.jar"]
```

<span style="color: rgb(36, 41, 47)">运行容器时可以覆盖</span><span style="color: rgb(36, 41, 47)">CMD</span><span style="color: rgb(36, 41, 47)">中的命令：</span>

```plain
bashCopy Codedocker run my-image java -version
```

2. **<span style="color: rgb(36, 41, 47)">ENTRYPOINT</span>** ：

- ENTRYPOINT 用于设置容器启动时执行的命令。与 CMD 不同的是，不会被覆盖，而是作为默认的执行命令。
- 如果在运行容器时指定了要执行的命令，这些命令会被追加到 ENTRYPOINT 命令的后面执行。

<span style="color: rgb(36, 41, 47)">示例：</span>

```plain
DockerfileCopy CodeFROM openjdk:11
COPY myapp.jar /myapp.jar
ENTRYPOINT ["java", "-jar", "/myapp.jar"]
```

<span style="color: rgb(36, 41, 47)">运行容器时可以追加参数到</span><span style="color: rgb(36, 41, 47)">ENTRYPOINT</span><span style="color: rgb(36, 41, 47)">的命令后面：</span>

```plain
bashCopy Codedocker run my-image -Xms512m
```

<span style="color: rgb(36, 41, 47)">综上所述，</span><span style="color: rgb(36, 41, 47)">CMD</span><span style="color: rgb(36, 41, 47)">用于提供默认的容器执行命令，并且可以在运行容器时被覆盖，而</span><span style="color: rgb(36, 41, 47)">ENTRYPOINT</span><span style="color: rgb(36, 41, 47)">用于指定容器的默认执行命令，并且在运行容器时提供的命令会被追加到</span><span style="color: rgb(36, 41, 47)">ENTRYPOINT</span><span style="color: rgb(36, 41, 47)">命令的后面执行。通常情况下，你可以将可变的命令参数放在</span><span style="color: rgb(36, 41, 47)">CMD</span><span style="color: rgb(36, 41, 47)">中，而将固定的执行命令放在</span><span style="color: rgb(36, 41, 47)">ENTRYPOINT</span><span style="color: rgb(36, 41, 47)">中。</span>
