# 一些部署期间出现的问题

#### 1、部署Nginx时，直接Exited

> 查看是否是nginx.conf配置错误，可能代理IP地址，多了端口号 webserver = localhost:8080 proxy = http://webserver:8080多余

> root@Inspiron:/home/ztyoper/workspace_idea/hmall# docker logs mysql
> 2024-07-28 00:03:24+08:00 [Note] [Entrypoint]: Entrypoint script for MySQL Server 8.0.27-1debian10 started.
> 2024-07-28 00:03:24+08:00 [Note] [Entrypoint]: Switching to dedicated user 'mysql'
> 2024-07-28 00:03:24+08:00 [Note] [Entrypoint]: Entrypoint script for MySQL Server 8.0.27-1debian10 started.
> mysqld: [Warning] World-writable config file '/etc/mysql/my.cnf' is ignored.
> mysqld: Error on realpath() on '/var/lib/mysql-files' (Error 2 - No such file or directory)
> 2024-07-27T16:03:24.555627Z 0 [ERROR] [MY-010095] [Server] Failed to access directory for --secure-file-priv. Please make sure that directory exists and is accessible by MySQL Server. Supplied value : /var/lib/mysql-files
> 2024-07-27T16:03:24.555649Z 0 [ERROR] [MY-010119] [Server] Aborting

```yaml
  mysql:
    image: mysql
    container_name: mysql
    ports:
      - "3306:3306"
    environment:
      TZ: Asia/Shanghai
      MYSQL_ROOT_PASSWORD: zyz140128
    volumes:
      - "./mysql/conf:/etc/mysql/conf.d"
      - "./mysql/data:/var/lib/mysql"
      - "./mysql/init:/docker-entrypoint-initdb.d"
      - "./mysql/mysql-files:/var/lib/mysql-files"

    networks:
      - hm-net
```

> 添加一条映射即可，自定义的路径，这个路径可以被访问，/var/lib/mysql-files貌似不能被访问到， chmod -R 777 /var/lib/ 耗时太久

#### 4、mysql 部署错误

> Error response from daemon: driver failed programming external connectivity on endpoint mysql (9da5512513966cbeb419a39e41411dfc2f1708417afafddec111e867e5577b6c): Error starting userland proxy: listen tcp4 0.0.0.0:3306: bind: address already in use端口占用错误

> 开启代理的方式是隧道穿透，因此主机占用了3306端口，修改成13306:3306即可。
