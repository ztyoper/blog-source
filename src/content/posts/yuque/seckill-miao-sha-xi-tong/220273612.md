### **一、前言**

在前面的文章中，完成了对秒杀系统中秒杀商品业务的后端接口开发，总体上秒杀商品相关的功能比较简单。光有后端接口还不行，咱也不能让运营和用户去直接调用秒杀商品的接口吧？所以，还要为运营和用户开发前端页面，以便于运营和用户能够方便的操作秒杀系统。

### **二、本章诉求**

对于秒杀系统而言，运营人员能够在登录系统后，对秒杀商品进行管理，能够在运营端发布商品、查看商品、上线商品和下线商品等。本章，就简单实现运营端对于秒杀商品的管理功能。

### **三、运营端流程设计**

运营人员在登录系统后，在运营端管理秒杀商品时，在系统业务层面会有一定的逻辑流程，如图19-1所示。

![](https://pub-ccd5622eabb54b4a81678003778ddce1.r2.dev/PicGo/f8999965af7f7322f90ffe0d44deac53a7ce7b57f4a43eaf46a6977af4a0e3a6.png)

在运营端，只有秒杀活动处于发布和上线状态时，并且秒杀活动没有结束，才能在秒杀活动页面进入发布秒杀商品页面。另外，运营人员在运营端能够查看秒杀商品列表、发布秒杀商品和变更秒杀商品状态。其中，发布商品时，要遵循一定的业务逻辑，主要交互逻辑如下所示。

（1）发布商品时，如果秒杀活动已经结束，则提示秒杀活动结束不能添加商品，否则进行下一步。

（2）如果商品名称为空，则提示商品名称不能为空，否则进行下一步。

（3）如果商品原价为空，则提示商品原价不能为空，否则进行下一步。

（4）如果商品原价小于或者等于0，则提示商品原价不能小于或者等于0，否则进行下一步。

（5）如果商品秒杀价格为空，则提示商品秒杀价格不能为空，否则进行下一步。

（6）如果商品秒杀价格小于或者等于0，则提示商品秒杀价格不能小于或者等于0，否则进行下一步。

（7）如果商品秒杀价格大于商品原价格，则提示商品秒杀价格不能大于商品原价格，否则进行下一步。

（8）如果商品库存为空，则提示商品库存不能为空，否则进行下一步。

（9）如果商品库存小于或者等于0，则提示商品库存不能小于或者等于0，否则进行下一步。

（10）如果限购个数为空，则提示限购个数不能为空，否则进行下一步。

（11）如果限购个数小于或者等于0，则提示限购个数不能小于或者等于0，否则进行下一步。

（12）如果商品秒杀为空，则提示商品秒杀不能为空，否则进行下一步。

（13）如果活动id为空，则提示未获取到活动编号，否则进行下一步。

（14）提交商品信息，后端返回添加商品的结果数据后，整个添加活动的流程结束。

```go
function reloadDom() {
```

可以看到，在reloadDom()方法中，核心逻辑就是遍历g_goodsList数组来填充id为container的HTML元素。

在reloadDom()方法中，会调用getStatus()方法来根据后端返回的不同状态来显示不同的状态文本信息，如下所示。

```go
function getStatus(status){
    if (status == 0){
        return "已发布";
    }else if (status == 1){
        return "已上线";
    }else if (status == -1){
        return "已下线";
    }
}
```

可以看到，状态值为0对应已发布，状态值为1对应上线，状态值为-1对应下线。

在reloadDom()方法中，也会调用showButton()方法来根据不同的状态展示不同的按钮。showButton()方法的源码如下所示。

```go
function showButton(itemVO){
    var innerHtml = "";
    if(itemVO.status == 0){
        innerHtml += "<input type='button' value='上线' onclick='onlineGoods(" + itemVO.id + ")'/>";
    }else if (itemVO.status == 1){
        innerHtml += "<input type='button' value='下线' onclick='offlineGoods(" + itemVO.id + ")'/>";
    }
    return innerHtml;
}
```

可以看到，当商品状态为发布时，显示上线商品按钮，当商品状态为上线时，显示下线商品按钮，当商品状态为下线时，不显示任何按钮。

点击上线按钮，会调用onlineGoods()方法，如下所示。

```go
function onlineGoods(activityId){
    $.ajax({
        type:"GET",
        headers:{
            "access-token": get(common_localstorage_key)
        },
        data: { "status": 1, "id": activityId},
        url:"http://"+g_host+"/goods/updateStatus",
        xhrFields: {withCredentials: true},
        success:function (data) {
            if (data.code == 1001) {
                alert("上线成功");
                showGoodsList();
            }else if (data.code == 2012){
                alert("请登录后操作")
                window.location.href = "login.html";
            }
            else {
                alert("上线活动失败");
            }
        },
        error:function (data) {
            alert("上线活动失败");
        }
    })
}
```

可以看到，点击上线按钮时，会调用修改秒杀商品状态的接口，将状态传递为1来实现。

```go
function submitGoods(data){
    var id = $(data).attr("data-id");
    var endTime = $(data).attr("data-end-time");
    if (currentTime() > endTime){
        alert("秒杀活动已经结束，不能发布商品");
        return;
    }
    window.location.href="create_goods.html?activityId=" + id;
}
```

可以看到，在submitGoods()方法中，会校验当前时间与秒杀活动结束时间，如果当前时间晚于秒杀活动结束时间，说明秒杀活动已经结束，提示秒杀活动已经结束，不能发布商品。否则，跳转到发布商品页面。
