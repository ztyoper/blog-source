### **一、前言**

在前面的文章中，完成了对秒杀系统后端接口的开发，总体上秒杀活动相关的功能比较简单。光有后端接口还不行，总不能让运营和用户去直接调用秒杀活动的接口吧？所以，还要为运营和用户开发前端页面，以便于运营和用户能够方便的操作秒杀系统。

### **二、本章诉求**

对于秒杀系统而言，运营人员能够在登录系统后，对秒杀活动进行管理，能够在运营端查看活动列表、添加活动、上线活动、下线活动、通过活动发布商品和查看商品等。本章，就简单实现运营端对于秒杀活动的管理功能。

### **三、运营端流程设计**

运营人员在登录系统后，在运营端管理秒杀活动时，在系统业务层面会有一定的逻辑流程，如图15-1所示。

![](https://pub-ccd5622eabb54b4a81678003778ddce1.r2.dev/PicGo/c452cb5303050afc197c3af80e56dca3e326fcf555bd9e669d0de8d4638213b8.png)

可以看到，在运营人员登录系统后，能够查看秒杀活动列表、添加秒杀活动和变更秒杀活动状态。其中，添加活动时，要遵循一定的业务逻辑，主要交互逻辑如下所示。

（1）添加活动时，如果活动名称为空，则提示活动名称不能为空，否则进行下一步。

（2）如果开始时间为空，则提示开始时间不能为空，否则进行下一步。

（3）如果结束时间为空，则提示结束时间不能为空，否则进行下一步。

（4）如果开始时间晚于结束时间，则提示开始时间不能晚于结束时间，否则进行下一步。

（5）如果开始时间早于当前时间，则提示开始时间不能早于当前时间，否则进行下一步。

（6）如果结束时间早于当前时间，则提示结束时间不能早于当前时间，否则进行下一步。

（7）如果活动描述为空，则提示活动描述不能为空，否则进行下一步。

（8）提交活动信息，后端返回添加活动的结果数据后，整个添加活动的流程结束。

**（2）填充秒杀活动列表**

使用js调用后端获取秒杀活动列表的接口，并将获取到的数据填充到页面，核心代码如下所示。

```go
// 定义全局活动数组信息
var g_activityList = [];
jQuery(document).ready(function () {
    getActivityList();
})
​
//获取活动列表
function getActivityList(){
    $.ajax({
        type:"GET",
        headers:{
            "access-token": get(common_localstorage_key)
        },
        url:"http://"+g_host+"/activity/getSeckillActivityList",
        xhrFields: {withCredentials: true},
        success:function (data) {
            if (data.code == 1001) {
                g_activityList = data.data;
                reloadDom();
            }else if (data.code == 2012){
                alert("请登录后操作")
                window.location.href = "login.html";
            }
            else {
                alert("获取活动信息失败");
            }
        },
        error:function (data) {
            alert("获取活动信息失败");
        }
    })
}
```

可以看到，首先定义了一个g_activityList全局数组，在页面加载时调用getActivityList()方法来获取秒杀活动列表。这里使用的是Ajax来获取秒杀活动列表，会将登录时获取到的Token放到请求头中一起发送给后端接口。如果后端返回的状态码为1001，说明正确执行了业务逻辑，此时将后端返回的data字段数据赋值给全局数组g_activityList，并调用reloadDom()方法重载页面的Dom元素。

reloadDom()方法的源码如下所示。

```go
function reloadDom() {
    $("#container").html('')
    for (var i = 0; i < g_activityList.length; i ++){
        var itemVO = g_activityList[i];
        var dom = "<tr id='activityDetail"+ itemVO.id +"'>" +
            "<td>"+ itemVO.id +"</td>" +
            "<td>"+ itemVO.activityName +"</td>" +
            "<td>"+ itemVO.startTime +"</td>" +
            "<td>"+ itemVO.endTime +"</td>" +
            "<td>"+ getStatus(itemVO.status) +"</td>" +
            "<td>"+ itemVO.activityDesc +"</td>" +
            "<td>"+ showButton(itemVO) +"</td>" +
            "</tr>";
        $("#container").append($(dom));
    }
}
```

可以看到，在reloadDom()方法中，核心逻辑就是遍历g_activityList数组来填充id为container的HTML元素。

在reloadDom()方法中，会调用getStatus()方法来根据后端返回的不同状态来显示不同的状态文本信息，如下所示。

```go
function getStatus(status){
    if (status == 0){
        return "已发布";
    }else if (status == 1){
        return "上线";
    }else if (status == -1){
        return "下线";
    }
}
```

可以看到，状态值为0对应已发布，状态值为1对应上线，状态值为-1对应下线。

在reloadDom()方法中，也会调用showButton()方法来根据不同的状态展示不同的按钮。showButton()方法的源码如下所示。

```go
function showButton(itemVO){
    var innerHtml = "";
    if(itemVO.status == 0){
        innerHtml += "<input type='button' data-id='"+ itemVO.id +"' data-start-time='"+ itemVO.startTime +"' data-end-time='"+ itemVO.endTime +"' value='发布商品' onclick='submitGoods(this)'/>" +
            "<input type='button' value='查看商品' onclick='getGoods(" + itemVO.id + ")'/>" +
            "<input type='button' value='上线' onclick='onlineActivity(" + itemVO.id + ")'/>";
    }else if (itemVO.status == 1){
        innerHtml += "<input type='button' data-id='"+ itemVO.id +"' data-start-time='"+ itemVO.startTime +"' data-end-time='"+ itemVO.endTime +"' value='发布商品' onclick='submitGoods(this)'/>" +
            "<input type='button' value='查看商品' onclick='getGoods(" + itemVO.id + ")'/>" +
            "<input type='button' value='下线' onclick='offlineActivity(" + itemVO.id + ")'/>";
    }else {
        innerHtml += "<input type='button' value='查看商品' onclick='getGoods(" + itemVO.id + ")'/>"
    }
    return innerHtml;
}
```

可以看到，如果秒杀活动处于发布状态，则显示的按钮为：发布商品、查看商品和上线，如果秒杀活动处于上线状态，则显示的按钮为发布商品、查看商品和下线，如果秒杀活动处于下线状态，则显示的按钮为查看商品。
