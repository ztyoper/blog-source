# R2 图片迁移 Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 将现有语雀图片通过用户已配置的 PicGo 上传到 R2，验证后替换博客引用并保留原图备份。

**Architecture:** PicGo 本地 HTTP 服务分批上传；下载逐图校验 SHA-256 后记录可恢复进度。复用 Markdown AST 链接改写器，仅修改真实引用。公开映射供后续导入复用，原图移到忽略的本地备份目录。

**Tech Stack:** Node.js 24、PicGo HTTP API、mdast、Astro、pnpm。

**Spec:** 用户本次批量上传请求及提供的桶地址。

## Global Constraints

- 桶地址：https://pub-ccd5622eabb54b4a81678003778ddce1.r2.dev
- 不读取或输出上传凭据；使用已配置的 PicGo 服务。
- 不修改语雀导出目录、不删除原图、不提交或推送代码。
- 原文代码、公式、外部链接及缺失图片占位引用保留。

## Review Focus

- 上传失败或链接内容不一致时不得替换引用或移走原图。
- 中断恢复必须校验来源哈希，防止错误复用上传记录。
- 保留用户已编辑文章，更新导入清单时不抹掉编辑保护。
- 再次导入不得恢复为本地图片或再次复制 1.6 GB 至 public。
- 映射路径必须严格验证，不接受越界、任意域名或不匹配文件名。
